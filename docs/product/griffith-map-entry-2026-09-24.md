# 格里菲斯场景接入地图

用户要求将已重建的场景放进 Journey，在地图选择地标后的详情卡增加入口，并使用农场同款操控，不需要种植。Journey 0.16.33 的洛杉矶地图现在可从“格里菲斯天文台”卡片点击“进入场景”。其他地标仍按现有信息卡展示。

场景使用原来的角色外观和 24 个重建模型，作为本地游览实例压在地图上。进入后隐藏原生地图，场景接管相机、环境和不透明背景；点击左上返回或系统返回，恢复原地图中心、缩放、朝向和选中卡片。连续点击入口不会重复压栈。角色行走不触发农场命令、迁移、奖励或线上空间加入；本次不包含多人地标空间。

操控直接复用农场 `modules/farm/scene_pan.gd`：点击行走，超过相同拖动阈值后平移镜头；松手后惯性衰减，新触摸立即止住惯性；双指以手势中心缩放，沿用 0.8–1.4 倍缩放与边缘回弹。多指结束后的剩余手指不会误走，拖动过程中越过按钮仍能正常结束，切后台会取消手势。镜头自由平移且不自动跟随角色，角色离屏时出现同款边缘头像和方向提示，点击后平滑回到角色。总览按钮切换场景全景。

每次进入创建独立导航地图，等待区域完成同步后接受行走；退出释放该地图。主台阶、西平台和咖啡露台保持连通。输入、模型和导航代码均置于正式场景目录；诊断观察器只存在于测试包。

## 尺寸与体积

这些尺寸使用游戏中的米，场景是美术缩比例，并非天文台的真实地理占地。

| 项目 | 尺寸 |
| --- | --- |
| 山坡与外围地形范围 | 约 44 × 54 米 |
| 可行走区域的外接范围 | 24.25 × 17.75 米 |
| 扣除建筑、植被和障碍后的导航水平面积 | 140.375 平方米 |
| 24 个 GLB 源文件 | 16,610,048 字节，约 16.6 MB |
| APK 内压缩后的模型 | 7,230,143 字节，约 7.2 MB |
| 最终 APK | 178,303,532 字节，约 178.3 MB |
| 相比 0.16.32 的 APK 增量 | 7,333,575 字节，约 7.3 MB |

测量来源为 `layout.json` 的地形边界、导航顶点／多边形，以及最终 APK 的 ZIP 成员。原先描述的约 26 × 19 米是美术预览镜头中心范围，实际可行走外接范围以上表为准。
