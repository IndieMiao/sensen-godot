# 矿井默认最大视野

用户在真机检查 0.16.40 后要求：进入矿井默认使用最大视野，保留双指缩放。

新矿井实例、轮次或楼层进入时，缩放从原来的 1.0 改为现有范围下限 **0.8**，即最远的稳定视角。相同设备上的默认可见宽度增加 **25%**；常用竖屏由 6m 变为 7.5m，小型竖屏由 7.2m 变为 9m。原有 0.8–1.4 缩放范围、双指操作和越界回弹继续可用。

相机仍对准服务端确认的入场位置。玩家手动缩放或平移后，同层状态刷新、重连期间的临时空场景、暂停恢复及前后台切换保留其视角；进入新楼层或另一矿井实例才重新使用最大视野。头像回中仅移动镜头中心，不改变缩放。

实现让 `ScenePan.reset()` 接受可选初始缩放，矿井传入 `min_zoom`；其他场景无参数调用的默认值仍为 1.0。地形、碰撞、采矿和战斗规则、存档与服务端契约不受此相机调整影响。

本决策替代 [2026-09-24 近景规则](mine-camera-2026-09-24.md)中的默认缩放值，其自由平移、焦点缩放和联机入场规则继续适用。
