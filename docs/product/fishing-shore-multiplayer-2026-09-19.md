# SGODOT-129：沿岸自由钓鱼与多人表现

> **资料范围（2026-10-05 清理）**：当前玩法、数值、操作与分期统一以 [玩法方案 v2](gameplay-plan-v2-2026-10-02.md) 为准。保留权威岸线/落点验证与远端钓具同步原理；农场访客钓鱼、四鱼旧规则、300人/暂存等为旧实现合同，不定义 v2 玩法。

用户于 2026-09-19 要求取消固定钓点，支持水边任意位置和多人在线。

- 池塘、湖泊与河流代表水域，不再代表固定站位。点击水面选择落点；已经在可站立岸边且距离合适时保留角色的精确位置，否则寻找可到达的附近岸边。农场「钓鱼」快捷按钮选择最近的可达岸线。
- 删除固定钓台与标牌。河流端部使用与碰撞、抛竿校验一致的圆弧边界。保留薄钓鱼条、抛竿／提竿／收线按钮、人物持竿动作与现有水面材质。
- 岸边有效距离 1.25 m，抛竿距离 0.45–4 m，单次钓鱼离开起点 0.6 m 后失效。服务端以实时房间中的位置、导航和水域形状校验；不接受客户端提交的站位作为权威位置。选点不要求贴合网格中心。
- 已获准进入的农场访客可以钓鱼，鱼获进入访客自己的背包。访问控制仍在房间加入阶段执行，访客不获得修改主人田地、库存和装饰的权限。鱼获互不抢占，无独占钓台。
- HTTP 提交成功后的钓鱼状态驱动联机表现。附近最多八个详细人物同步抛竿、咬钩、拉杆、鱼线、浮漂和确认鱼获；远处沿用简化人物和持竿动作。现有每区域 300 人上限保持。
- 客户端只上报有当前钓鱼序号的收线按压和鱼位置表现提示，无法通过 WebSocket 开始钓鱼或产生奖励。公共消息不包含随机种子、连接令牌、背包、钱包和未捕获鱼的身份。
- 后进入者自动收到当前附近钓鱼状态；离岸、超时、取消、退出、断线与详细人物池复用都会收回远端钓具。换衣、换场景与自己的摄像机／HUD不被远端动作改写。
- 四级鱼、价值、难度、服务端时间／输入轨迹校验、溢出背包及幂等结算延续原规则。

领域版本为 24。23→24 迁移只更新领域／内容版本元数据，保留完整状态 JSON、命令历史、作物 ID 与成熟时间、物品、矿洞、组队及语音配置。旧客户端省略落点时仍根据实际岸边计算默认水中落点；旧存档已有钓鱼可取消并重新抛竿。

可观察结果是玩家在不同岸边位置发起抛竿、两位玩家同时可见且鱼获独立。若选点不可达或结算位置失效，提示重选／重抛，不传送、不吞鱼、不修改他人存档。自然玩家难度和经济接受度仍属于 SGODOT-129 的后续观察范围。
