# Journey 全界面 UI 改版 · 2026-09-21

本轮按用户六张参考重做原生 Godot 客户端界面。图 6 提供游戏化风格，图 5 提供背包结构；用户要求通过 Sensenjoy API 重新设计，减少 UI 占屏并聚合信息。客户端版本为 0.16.10 / 2026092106；发布及真机事实见 [QA 记录](../qa/game-ui-2026-09-21.md)。

## 行为

- 农场取消角色 dead/hard 安全框和自动追随，拖动后保持自由视角。允许角色离开画面，点击右侧实际装扮头像，以 0.34 秒缓动回到角色当前位置；手动拖动可打断回位。保持原缩放、阴影与近远裁剪适配。
- 顶部收为 44px 信息行与聚合目标条；底部为 52px 行走/种地、当前行动、背包入口。种子只在种地模式展开。点击农场标题进入钓鱼、摊位及可用时的重新选址入口。
- 背包保留上方 3D 场景，使用固定页签/关闭、104px 物品详情条、搜索/分类/排序、五列物品网格。拆分、合并、丢弃留在详情中；丢弃仍需确认。材质用途显示“去制作/去料理”，不新增原规则不存在的物品使用效果。
- 人物页使用真实保存装扮，左右各三个装备槽，选槽后聚合更换/卸下/详情操作；原六槽、实例 ID、属性、料理效果和服务器命令不变。隐藏或挂起的预览停止绘制；头像在不可见时延后装配和 GPU 回读。
- 原有城市、地图、选址/迁居、附近玩家、居民、制作/料理、聚会、摆放、矿井、钓鱼、队伍/语音、换装、加载/确认/错误、旧存档界面及合照都使用同一套游戏化素材和控件规则。
- 弹层通过统一可见性注册隐藏联机/语音悬浮入口并拦截世界输入，弹层关闭后恢复。打开面板不终止联机或语音会话。初始布局和安全区改变会重排联机按钮。

## 视觉与来源

Sensenjoy `gpt-image-2` 生成三张设计板以及面板、按钮和城市插画；保留提示词、实际尺寸、哈希和派生处理记录。小控件使用同一素材的适配版本，避免九宫格边缘相交。奶油白内面、蓝紫边框、青绿主按钮、紫色选中页签配合 Nunito / Noto Sans SC。63 个 Phosphor 库图标与原 Lucide 回退、物品/作物美术并存，许可文本包含在 APK 中。

现有 3D 地理地形、作物、房屋、植被、水面、人物及矿井继续实时渲染。概念图中的固定人物位置、示意 NPC、价格、食谱或设置不作为新增功能；实际界面使用真实存档及已实现规则。

设计来源：[设计记录](../design/game-ui-2026-09-21/README.md)。视觉对照与修正历史：[design-qa.md](../../design-qa.md)。
