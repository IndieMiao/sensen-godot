# 道具系统对比：我的世界、波西亚、星露谷与牧场物语

> **资料范围（2026-10-05 清理）**：当前玩法、数值、操作与分期统一以 [玩法方案 v2](gameplay-plan-v2-2026-10-02.md) 为准。仅保留竞品比较与历史假设，项目建议不自动采用。

- 日期：2026-09-11。
- 承接：[资源、料理与建造框架调研](farming-games-systems-research-2026-09-11.md)。
- 延伸：[星露谷与我的世界怪物系统对比](monster-systems-comparison-2026-09-11.md)。
- 范围：物品分类、取得、加工、用途、品质与装备、消耗和世界交互。牧场物语仍分别考察《重聚矿石镇》《橄榄镇与希望的大地》。
- 我的世界口径：原版生存模式，以 Java/基岩版共有的基础机制为主；自动合成器以 Java 1.21 官方发布说明作为已存在机制的证据，不把 1.21 称为当前最新版。创造模式的无限资源、模组、数据包和服务器自定义商店不进入经济对比。
- 状态：资料研究与设计分析，不修改项目规则、存档或玩法方案 v2 的实施顺序。此次没有进行竞品实机验证，不比较版本敏感的道具总数。

## 1. 核心区别

| 游戏 | 道具的主要地位 | 玩家通常围绕道具问什么 |
| --- | --- | --- |
| 重聚矿石镇 | 农牧产物、生活材料、礼物与劳动工具 | 卖掉、留着做菜、送人，还是投入农场升级 |
| 橄榄镇 | 农场产物、加工材料、设施与布置物 | 原料先加工什么，先修哪处设施，设备摆在哪里 |
| 波西亚时光 | 工程材料、零件、装配成果与角色装备 | 哪个订单需要它，缺哪道加工，先升级什么生产能力 |
| 星露谷物语 | 连接生产、探索、关系和解锁的多用途物品 | 直接出售、加工、献祭、做设备，还是支持下一次探索 |
| 我的世界 | 可持有、使用、合成、放置并参与世界规则的构件 | 能做成什么，放到哪里，与什么组合能完成我的目标 |

这是侧重的归纳，不是互斥分类。例如星露谷也有可放置设备，波西亚也有礼物，我的世界也有货币用途的绿宝石。

## 3. 从获得到使用的流程

| 游戏 | 获得与加工 | 主要开放条件 | 道具最终去向 |
| --- | --- | --- | --- |
| 波西亚 | 采集、矿掘、探索、种养、购买；原料加工和装配 | 图纸、设备、材料、任务进度 | 订单交付、自用设备、装备、工程、出售和社交 |
| 重聚矿石镇 | 购种、种养、采集、钓鱼、挖矿；部分加工和料理 | 季节、工具经验与等级、厨房厨具、食谱 | 出货、料理、赠礼、升级和收集 |
| 星露谷 | 多种生产与探索；工作制作、机器加工、料理 | 技能、配方、工具、建筑和区域 | 现金、消耗、设备、献祭、关系和表达 |
| 橄榄镇 | 清地采集、种养；加工器转换与制作 | 技能、材料、工具、修复进度 | 加工商品、设施、工具、小镇请求和布置 |
| 我的世界 | 破坏方块、种养、掉落、探索宝箱、交易；合成、烧炼、酿造等 | 对应材料、工具、加工设施，以及能否到达来源地点 | 使用、消耗、装备、放置、再合成、交换和储存 |

我的世界的配方书帮助发现和执行合成；默认生存规则下，许多基础合成可以在玩家知道配方且材料齐全时直接完成。它没有普遍要求“和某位 NPC 关系达标才学会配方”的规则。部分配方接受一组可替代材料，例如工作台可以使用不同木种的木板；配方是否有替代项要逐项定义。[C1]

## 4. 我的世界为什么值得单独比较

### 4.1 物品与世界之间可以转换

大量方块在背包里是可堆叠物品，放置后成为有位置和状态的世界方块。玩家可以用它们搭墙、铺路、围水、建房，或者组合设施。[C2]

但“放置后再挖掉”并不保证总能原样收回。工具、附魔和方块类型可能影响掉落物，例如精准采集会改变某些方块的取得方式。不能把整个系统理解成无成本地撤销所有操作。[C1]

### 4.2 普通材料就有多个功能方向

以铁锭为例，它能进入工具和装备，也能进入桶、剪刀、漏斗、铁轨、铁砧等物品。不同去向分别关系到开采、防护、流体搬运、收集、物流、交通或装备处理。

这些用途不是同一项任务的不同交付数量。玩家想做自动生产、出门探索或扩建基地，会自然需要不同的合成结果。这里列用途关系，不给出版本敏感的完整配方树。

相比之下，波西亚的材料常由具体工程需求组织；星露谷的材料跨越设备、社区收集和角色成长；牧场物语的产物更多在现金、料理、赠礼和农牧升级之间分配。

### 4.3 功能设施可以由玩家组合出来

我的世界既有固定功能方块，也允许玩家把多个部件组成更大的装置。官方 Java 1.21 文档明确记录：合成器接受红石脉冲进行合成，可以与漏斗、投掷器和比较器交互。[C3]

因此可以形成这种结构：

`原料储存 -> 物品输送 -> 加工或自动合成 -> 成品收集`

完整布置还需要处理朝向、输入配比、信号和输出空间。装置是玩家利用规则搭出来的，不一定存在一个叫“自动工厂”的预制建筑按钮。不同版本的红石、加载和实体行为会影响具体方案，本文不提供跨版本机器搭建保证。

### 4.4 生存会持续消耗一部分道具价值

常见工具、武器和盔甲有耐久；食物维持饥饿与行动续航，部分消耗品支持战斗或探索。装备附魔、维修等进一步影响物品价值与使用方式。默认规则下死亡还涉及携带物掉落等风险；游戏规则可以改变这些行为。

但这不等于“所有道具最后都靠损坏消耗”。建筑规模、路线、物流、装饰和玩家自设工程同样可以产生材料需求。附魔与维修也可能降低更换装备的频率。

### 4.5 交易是一条路径，不是全部价值的终点

绿宝石承担村民等交易中的货币角色。[C4] 但原版没有一个面向所有物品、统一无限收购的通用出货箱。玩家也可以直接用材料完成自己的建筑和装置目标，而不用先把它们全部变成钱。

创造模式直接提供无限资源，因此属于另一套体验；不能拿它来评价生存模式中的材料稀缺性。[C2]

## 5. 品质、工具、装备和消耗的差异

| 维度 | 波西亚 | 重聚矿石镇 | 星露谷 | 橄榄镇 | 我的世界 |
| --- | --- | --- | --- | --- | --- |
| 农产品品质 | 本文不套用其他游戏的星级规则 | 作物星级和农牧产品等级影响价值 | 部分物品分普通、银、金、铱品质 | 农产品等使用品质区分 | 普通农产品没有普遍的星级品质体系 |
| 工具成长 | 更好的材料、工具和相关能力 | 工具经验、矿石和钱支持升级 | 工具升级，后期还有附魔 | 材料和金币升级工具，技能开放能力 | 工具材质、附魔及对应采掘能力 |
| 战斗装备 | 武器、服装、饰品和属性 | 无常规战斗装备线 | 武器、鞋、戒指；后期可锻造、附魔和组合戒指 | 无同级别战斗装备线 | 武器、盔甲、盾、附魔和耐久管理 |
| 料理价值 | 恢复、行动支持和社交 | 恢复、赠礼、收集，也可出售 | 恢复和增益；很多菜不适合单纯赚差价 | 生活生产，做菜占游戏内时间 | 主要支持生存续航；药水另有临时效果 |
| 持续消耗来源 | 委托、制造、工程、生活与探索 | 购种、照料、食用、礼物和投资 | 种子、消耗品、赠礼、订单、设备扩张等 | 再生产、加工、设施扩张和请求 | 食物、耗材、部分装备损耗，以及自行扩大建设与装置规模 |

星露谷武器和工具的附魔、锻造，与作物的品质是不同机制。我的世界装备的材质、附魔和耐久，也不应被简化为一个覆盖所有道具的“稀有度”。[S5]

这些维度应分别设计：同一个物品定义可以拥有不同实例状态，原料也可以只需要种类与数量。没有必要为了统一界面而给木料、食物、工具都加一条同样的品质或耐久条。

## 6. 同一类道具，分别在解决什么问题

| 道具例子 | 游戏里的实际意义 | 对比得到的设计启示 |
| --- | --- | --- |
| 矿石，重聚矿石镇 | 与工具经验、金币一起换取劳动效率 | 基础材料可以靠升级用途保留价值，而不必卖得很贵 |
| 酒桶，星露谷 | 消耗跨系统材料，提供持续加工产能 | 制作设备以后，种植量和原料去向可能跟着改变 |
| 工程零件，波西亚 | 连接采集、加工设备、装配和具体工程 | 道具用途应能帮助玩家反推生产计划 |
| 木材加工器，橄榄镇 | 把采集物转成设施需要的建材 | 加工应带来可辨认的后果，同时核对取放操作负担 |
| 桶，我的世界 | 把液体收集、移动和重新放置 | 道具可以增加一种操作能力，不必只提升一个数值 |
| 漏斗与合成器，我的世界 | 参与物品输送和按信号合成 | 部件间可组合的规则能支持玩家自己的工程 |
| 火把，我的世界 | 提供光照，辅助探索并在适用条件下降低敌对生物生成风险 | 简单道具也能同时具有环境、行动和布置价值 |

火把不对所有敌对生物或生成方式提供绝对保护；这里借鉴的是照明与世界规则的关系。[C5]

## 7. 对当前项目的建议

本节是候选设计，不新增开发承诺，也不覆盖本地化优先和已有双地域样板范围。

### 7.1 分类时同时记录“是什么”和“能做什么”

展示分类可以用：原料、农产品、加工品、料理、工具、装备、设施、装饰、特殊物品。行为能力另行记录：可食用、可赠礼、可出售、可交易、可投入工程、可放置、可操作、可收回。

当前花箱已经可以陈列、修复或用于特定小聚，正是“一种物品有多种行为”的已有基础。新增用途仍需要明确消耗规则，避免同一份库存同时处于背包、陈列和交易状态。

### 7.2 最值得学的是少量功能之间的组合

我的世界的启示是：一种道具能改变玩家的操作或场景规则，几种道具组合以后又产生新的用途。对本项目，先让构件、设施和通路之间有一条可验证的关系，成本比照搬方块世界和红石系统小得多。

已有 GDD 中的构件可以用于留种设施、修路或后续景观作品。可优先核对这些现有候选用途，是否使玩家在相同库存下选择不同的下一步。研究道具不构成增加武器、耐久、生存惩罚或复杂机器的必要性证明。

### 7.3 一份道具定义应能回答的问题

| 项目 | 要明确的内容 |
| --- | --- |
| 来源 | 从哪里取得，前置是什么，如何再次取得 |
| 生产 | 投入、设施、操作和时间，是否允许替代原料 |
| 用途 | 直接使用、生产投入、关系、建设、交易或表达 |
| 实例差异 | 是否真的需要品质、耐久、附魔或其他实例状态 |
| 世界形态 | 能否放置，放置后有什么实际功能 |
| 返回规则 | 收回返成品还是原料；消耗、销毁和替换如何处理 |
| 库存归属 | 背包、陈列、工程投入和交易托管是否互斥计数 |
| 后续目标 | 首次交付后，为何还需要再取得或再制作 |
