# 农场人工鱼塘移除

2026-09-25，用户明确要求移除农场内鱼塘。本轮将农场人工鱼塘及其钓鱼入口退役，保留地图系统钓鱼点和真实地理水域。

农场不再创建鱼塘水面、石岸、荷叶、浮漂面板或 `Go fishing` 操作；地面 shader 不再绘制人工椭圆湿岸，场景中的水面点击也不再进入钓鱼。原塘位成为可行走、开垦和摆放的地面，房屋、矿井、作物、摆件和角色位置不变。

新建及新搬迁请求使用生成版本 3，沿用 32 米／40×40 格／0.8 米格边与 160 米地理选区，设施搜索不再要求放得下鱼塘。保留旧生成配方用于历史数据重现；旧版本请求经过当前 API 保存时也会去掉人工塘。全水、荒漠、不完整地理等拒绝规则继续生效，不通过填平真实水域改善选址。

已有地理农场仅把明确标记为 `id=pond` 的人工水域转换为土壤，删除废弃的池边锚点，更新地形 ID 与校验和；真实 OSM 水域、所有其他区域、非池塘锚点、地理来源及外观类型保持。地形 ID 从规范化栅格计算，不受 PostgreSQL JSONB 字段排序影响。旧模板释放 47 格；实际海岸样本也释放 47 格，同时保留全部 628 格真实水域。

服务端领域升至 **28**，内容版本为 **761deabf2a207d3e**。显式迁移保持作物坐标、成熟时间、装备、库存、钱包、矿井和搬迁资格；仅取消未完成的农场抛竿，不发鱼、不扣物品。旧搬迁预览及派生访客缓存失效，防止把旧塘重新带入场景。历史命令和建场回执保留。数据或版本不符时拒绝或整批回滚。

这是待配套发布的客户端／服务端变更。当前手机仍是已验证的 0.16.39 美术更新，生产仍未执行本轮迁移。不能把新客户端单独当成旧后端上的完整移除结果；发布时须协调领域 28、数据迁移和兼容客户端。
