# Sensen 街角四季｜简版 PRD

日期：2026-09-10 · 用途：合伙人讨论与后续产品方向对齐

当前版本基线：9 月 10 日合伙人公网预览版。第 2 节描述已实现功能；其余章节描述产品目标与规划，不代表已经上线。

## 1. 产品定位

**一款以真实街区为基础、有空间距离感的地图种田经营游戏：玩家经营自己的农场，探索不同地域，通过生产与交换成长，和社区一起建设地图。**

融合《星露谷物语》的种植、生活与居民关系，以及《波西亚时光》的采集、制作与建设成长。面向喜欢经营、探索、收集和合作建造的玩家，既支持短时间完成一件事，也支持持续经营长期目标。

核心差异化是：**真实地理影响当地能生产什么、能解锁什么，以及值得与谁交换。** 玩家对地图的记忆来自走过的路线、认识的人和共同改变的地方。

## 2. 当前版本已具备什么

| 模块 | 已实现内容 |
| --- | --- |
| 农场经营 | 3D 农场、种植与照料、分钟级成熟、收获、买卖、料理、制作及布置；已更新农场模型、地面材质与光影 |
| 地图与街区 | 真实地图展示与农场选址、可步行的 3D 街区、农场/苗圃/小馆/庭院入口、资源采集与路线选择 |
| NPC 与成长 | 三名居民，支持交谈、委托、赠礼与故事推进；已有居民活动、小型设施修复、能力解锁和目标追踪 |
| 联网与存档 | 公网登录、持久存档、覆盖安装保留原线上身份；可查看附近农场并访问开放的农场 |

当前 3D 街道来自随包的地图道路蓝图，NPC 使用预设内容和行为。**AI 地域生成、玩家间物品交换、多玩家共享地标建设尚未上线。** 现有设施和街边变化主要记录在个人存档中。

本次发布已验证联网、存档迁移、采集、委托追踪和种植收获闭环；完整街区/NPC 真机流程未在本次重跑。自然玩家的持续乐趣和长期留存仍需验证。

## 3. 核心玩法循环

`地图发现机会 → 规划路线与生产 → 种植/采集 → 料理/制作 → NPC 交付或玩家交换 → 解锁能力与区域 → 参与建设，发现下一轮机会`

玩家持续面对三个选择：这一轮生产什么，产物用于自己成长还是交换，以及接下来探索哪片区域。成长成果应直接改变可做的事、可去的地方或场景外观。

短期目标是一份收获、一次制作或一项委托；中期目标是一种新能力、一条新路线或一段居民故事；长期目标是跨地域经营和社区共同成就。

## 4. 核心方向与远景功能

### 真实地图与距离感

真实道路、水系、地形和街区关系逐步成为可玩空间的依据。农场、资源点、居民和设施具有稳定位置，远近、连接与通路影响探索顺序和产物往来。

玩家先熟悉自己的街角，再探索邻近街区和其他地域。已探索区域可逐步获得快捷往返能力，保留首次发现与路线规划的价值。默认通过游戏内移动体验距离，不要求现实出门或长时间赶路。

### AI 驱动的地域差异

结合真实地理数据，由 AI 辅助理解气候、植被、水系和地形，生成符合当地特征的作物、材料、配方、居民需求与解锁主题。地理事实来自数据，AI 在游戏规则内组织内容。

例如，河湖地区偏向水生植物和编织材料，林地偏向木材和林下作物，山地偏向矿石和耐寒作物。这些是设计示例，具体品类与地域划分待验证。

各地域拥有有价值的特色与用途；基础经营都能持续进行。产出和解锁受统一平衡规则约束，同一地域的内容保持稳定，不因反复生成而随意改变。

### 玩家生产与交换

不同地域形成互补的生产链。**中高阶任务、配方和关键解锁需要来自多个地域的产物，玩家交换成为核心获取途径。** 玩家可以发展种植、加工、制作等专长，并成为其他玩家需要的供应者。

优先考虑异步求购、供给订单和社区集市，让双方无需同时在线。交付前能看清交换物、数量和用途；基础经营可以独立推进，高阶成长通过跨地域交换与合作展开。

### 社区共建与地标

社区围绕地图上的公共工程协作，分阶段投入不同地域的材料、加工品和作品。完成后，所有成员能看到共享的地标变化，并获得新设施用途、探索入口或共同成就。

个人贡献留下可见记录，社区成果持续存在。地标可包括公共温室、河岸花园、观景设施等；具体选题结合地域特征确定。

## 5. 一个完整的远景体验

河畔玩家用当地芦苇制作编织构件，山地玩家用矿石制作金属部件。双方交换产物，分别完成温室设备和进阶工具的解锁。

新的能力让他们探索更多区域、生产更复杂的物品。随后，多个地域的玩家把各自产物投入社区观景地标：施工阶段在地图上逐步可见，建成后开放新探索路线，并记录社区成就与个人贡献。

由此形成长期成长：**基础经营 → 加工与制作 → 地域专长 → 跨区域协作 → 更高层级能力与社区建设**。每次升级都带来新的生产方式、探索范围或合作角色，并引出下一阶段目标。

## 6. 推进顺序与验证重点

**2026-09-10 阶段决定：**用户已采纳[下一阶段行动蓝图](next-stage-action-blueprint-2026-09-10.md)，具体设计见[地域经营与成长 GDD v0.1](regional-growth-gdd-2026-09-10.md)。先收敛成长与资源取舍，再通过小样板验证；2–3 日是设计工作窗口，不是研发交付承诺。

| 阶段 | 建设重点 | 需要证明的玩家价值 |
| --- | --- | --- |
| 当前：2–3 日紧凑设计 | 成长图、资源流向图、样板验收表；投资顺序与低供给路径推演 | 每项能力改变后续选择，两种投资都有用途，关键路径不循环锁死 |
| 下一步：双地域经营样板 | 两个互补地域、各一条特色生产链、异步交换与能力/通路变化；手工基准后检查 AI 候选 | 玩家能解释地域区别，为自己的目标生产和交换，并实际使用解锁成果 |
| 随后：第二、第三轮观察 | 4–6 名目标玩家探索性观察；新存档与中期测试存档分开 | 没有首通奖励后，仍有有理由的生产、用途或路线变化 |
| 依据证据扩张 | 个人循环成立后验证一项共享工程，再逐步扩大区域与能力层级 | 自然首会话 60–90 分钟、后续自发回访，以及被共同感知的地图变化 |

明确操作阻塞、存档连续性和可恢复操作贯穿迭代。60–90 分钟不作为当前不断追加细节和固定内容的排期目标。样板中的跨地域材料保持必要；真人交换优先，个人关键成长预留成本较高的 NPC 替代，避免低活跃期只剩等待供货。具体成本与玩家接受度仍待验证。

每一阶段先验证玩法闭环与真实玩家体验，再扩大地域、内容和系统规模；AI 生成量和任务数量不能代替乐趣验证。本文的远景与新 GDD 规则不因规划交付而成为已上线能力。
