# NPC / POI 会议结论写回规则草案（2026-10-03）

适用范围：玩法方案 v2 的「NPC、POI 与经济」章（前半 9.1–9.9）、旅行章「到达必须兑现」、界面清单章 NPC / MAP 各行，以及待拍板章的 NPC / POI 五问。本稿只改规则，不改价目、额度数字与委托模板（这些沿用原章后半）。所有用户可见文案英文；下文物品 / 实体一律给 id + 中文 / 英文名。

## 0 结论先行

1. **功能 NPC 的供给单位从「0.5° 网格格」改为「城市据点组 Outpost Group」**：每组 = Market + Tackle Shop + Travel Post + Tea Stand 四柜台围一个小广场，由系统按世界种子一次性生成、全服一致、永不漂移；一座城市按规模分档生成 1–6 组；没有城市的陆地格每格仍生成 1 组「荒野据点组」做保底。
2. **同功能多实例 = 名字不同、外观不同、功能完全相同**：组名与掌柜名牌从气候带名字池派生；玩家在本城任一组买到的东西、价目、库存口径一模一样；**所有日额度都按账号（或账号 × 城市簇）计，不按实例计**，多组不等于多份库存、多份回收、多块委托板。
3. **POI 降为试验性视觉层**：地图上的真实 POI 图标只负责"让世界看起来丰富"，无交互、无内容、不参与任何门禁与成就；原来挂在 POI 上的四样东西全部搬家——印章挂城市簇、特产柜挂本城据点组 1 的 Market、角色 NPC 住据点组、事件在据点组广场或鱼塘举行。POI 只保留两样：亮灯视觉，以及日后运营活动时可被服务端临时点亮为紫 ★ 事件场地的接口。
4. **角色 NPC（Resident）全部住进据点组**：每组 1–2 位——信使 Pip 在每一组都在（新手引导永远找得到他），每组另有 0–1 位按城市属性（沿海 / 大河 / 高地 / 规模档）从 12 人名册按固定顺位选出的城市角色；旅行商人 Mira 到访时额外出现在组 1。多城同时、好感按角色累计、赠餐每日 1 份合计等规则不变。
5. **到达保底不降反升**：每座城市簇至少 1 组四柜台齐全的据点组 + 至少 1 口新手鱼塘，且组 1 与新手塘步行距离 ≤ 800 m，"落地三件事"（钓当地鱼、进据点、盖章）在一段步行内完成。
6. **公平口径不变**：任何家格玩家到技能满级与 Homestead Lv10 的天数差 ≤ 10%；大城市多出来的仍然只是"看见谁、聊什么、集什么章"，不多一件产能。
7. **需要确认的只有分档数字与数据口径**（人口 / 建成区阈值、组数上限 6、簇人口按哪个口径、组名用行政区名还是词池）；规则骨架按会议结论已定。

## 1 会议结论 → 规则映射

| 会议结论（原话要点） | 原规则 | 新规则 | 状态 |
|---|---|---|---|
| 功能性 NPC 由系统固定生成、对每个玩家一致 | 已是：按 0.5° 网格确定性生成，全服一致 | 保留"系统生成、全服一致、冻结"；生成单位改为据点组 | 已定（会议） |
| 按所在城市合理分布 | 每个陆地格恒 1 处 Market，Tackle / Travel 按格坐标奇偶与整除规则散布 | 以城市簇为单位分档生成 1–6 组；无城市的陆地格每格 1 组荒野据点组 | 已定（会议），阈值待确认 |
| 城市区域大时同功能 NPC 可以有多个，名字不同 | 同格多据点合并为一处据点群；功能 NPC 只有岗位名、无个人名 | 一城多组；组名与掌柜名牌各自不同（名字池按气候带）；功能 NPC 仍无好感、无故事、台词模板化 | 已定（会议） |
| 任一实例享受相同功能与共享日额度 | 日库存"按格按日"（同一玩家在不同 Market 的日库存独立） | 全部日额度改为账号级或账号 × 城市簇级；同城所有组共用同一份额度与同一块委托板 | 新增（防多实例刷） |
| POI 是试验性功能，暂无实际功能意义 | 真实 POI 承载地标印章、特产柜、角色住址、事件场地 | POI 只做视觉；四样内容全部改挂据点组 / 城市簇 / 鱼塘 | 已定（会议） |
| 后期可能加运营活动 | POI 可做事件场地 | 保留"服务端可临时把任一 POI 点亮为紫 ★ 事件场地"的接口，原型阶段不实现 | 预留 |

## 2 功能 NPC 与据点组：固定生成、全服一致

### 2.1 据点组定义

| 项 | 规则 |
|---|---|
| id / 名称 | `outpost_group` 据点组 / Outpost Group |
| 组成 | 四柜台齐全，缺一不生成：`outpost_market` 集市 / Market、`outpost_tackle` 渔具铺 / Tackle Shop、`outpost_travel` 驿站 / Travel Post、`outpost_tea` 茶座 / Tea Stand（茶座从 Market 内部拆出为独立小摊，功能与 3 杯 / 日口径不变） |
| 岗位 | `npc_market_keeper` 集市掌柜 / Market Keeper、`npc_tackle_keeper` 渔具老板 / Tackle Keeper、`npc_post_clerk` 驿站职员 / Post Clerk、`npc_tea_host` 茶座主人 / Tea Host，每组各 1 名；外观与名牌按组种子派生 |
| 公共设施 | `board_market` 集市委托板 / Market Board（内容按城市簇共享，见 2.6）、茶座小桌、护照盖章台 |
| 场景 | 约 40 m × 40 m 小广场，四栋建筑围合；每组一个公共实时房间，同房玩家互相可见、可发起共做委托 |
| 皮肤 | 4 气候带 × 3 地形 = 12 套建筑皮肤不变；一城多组共用同一套皮肤，靠组名、招牌文字与掌柜外观区分 |
| 一致性 | 位置、组数、组名、皮肤、岗位外观与名牌由世界种子 + 城市簇 id（或格 id）派生，服务端生成一次后冻结；后续版本只允许新增组，不删除、不搬迁 |
| 原据点类型的"散布规则"（格坐标奇偶 / 整除、沿海格必有 Tackle 等） | **全部删除**；四柜台永远成组出现 |

### 2.2 城市分档 → 组数

城市单位沿用旅行章的「城市簇」（全球约 1.25 万簇：1.5 万人口以上城市按 30 km 半径贪心合并）。组数取「人口档」与「建成区面积档」中的较大者，上限 6。

| 档 | 簇人口 | 建成区面积 | 组数 | 典型城市（人口 / 面积为约数，待地图数据核对） |
|---|---|---|---|---|
| S | < 50 万 | < 150 km² | 1 | 特罗姆瑟 7.7 万、雷克雅未克 14 万、檀香山 35 万、雅库茨克 35 万 |
| M1 | 50–150 万 | 150–600 km² | 2 | 丹佛 71 万、哥本哈根 65 万、奥克兰（新西兰）145 万 |
| M2 | 150–300 万 | 600–1,200 km² | 3 | 旧金山–奥克兰簇约 170 万、维也纳 200 万、布里斯班 260 万 |
| L1 | 300–800 万 | 1,200–2,000 km² | 4 | 新加坡 590 万、柏林 370 万、悉尼 530 万 |
| L2 | 800–1,500 万 | 2,000–3,000 km² | 5 | 伦敦 890 万、杭州（建成区）约 900 万、曼谷 1,100 万 |
| L3 | > 1,500 万 | > 3,000 km² | 6 | 上海约 2,480 万、东京–横滨簇约 3,700 万、洛杉矶（面积档 6,300 km² 触顶）、北京约 2,100 万 |

说明：
- 面积档的作用是给"人口不算最多但摊得很开"的城市（洛杉矶、休斯敦）补组，避免郊区玩家离最近一组 20 km 以上。
- 组数只在生成时计算一次；城市人口数据日后变化不触发重算。
- 任务给出的粗档「< 50 万 1 组、50–300 万 2–3 组、> 300 万 4–6 组」与本表一致，本表只是把 2–3 与 4–6 拆成可执行的子档。

### 2.3 荒野据点组（无城市的陆地格）

| 项 | 规则 |
|---|---|
| id / 名称 | `outpost_wild` 荒野据点组 / Wilderness Outpost（仍是一个完整的 `outpost_group`，只是落点与命名走荒野规则） |
| 生成条件 | 0.5° 网格格内含陆地，且格内没有任何城市簇生成的据点组 → 该格生成 1 组 |
| 落点 | 格内最大聚居点外 1–2 km；无聚居点则格中心最近的陆地点；避开水体 50 m |
| 命名 | 地貌词 + 柜台：Tundra Market / Taiga Tackle Shop / Steppe Travel Post / Dune Tea Stand / Savanna · Rainforest · Highland · Reef · Coast 同理；格内有 ≥ 1 万人口城镇则用「<城镇名> Market」 |
| 角色 | Pip + Granny Wu（见第 4 节） |
| 规模 | 全球陆地格约 7–8 万，扣除含城市簇据点组的格后约 6 万组；纯数据，无人访问时零成本 |
| 作用 | 保证极地 / 沙漠 / 无人海岛上的农场也有家组据点，与原方案"无 POI 也有据点"的保底完全等价 |

### 2.4 落点规则（按城市簇）

| 序 | 规则 | 理由 |
|---|---|---|
| 1 | **组 1 = 中心组**：落在簇中心（人口最多城市的市中心）外 1–2 km，且与本簇新手鱼塘的距离 ≤ 800 m；两者冲突时以鱼塘为准，组 1 挪到鱼塘一侧 | 到达三件事一段步行内完成 |
| 2 | **组 2…N 均匀分布到建成区**：按 1 km 人口密度格取密度最高的 N−1 个中心点，要求两两间距 ≥ 3 km、距组 1 ≥ 5 km、尽量落在不同的 0.5° 网格格 | 覆盖郊区农场；避免 6 组挤在市中心 |
| 3 | **优先靠近鱼塘**：候选点 1.5 km 内有系统鱼塘时，落点挪到该鱼塘岸边 ≤ 800 m 处 | 钓完就能卖、能买蚯蚓 |
| 4 | **避水避坡**：落点距水体 ≥ 50 m、取格内坡度最缓的陆地点 | 场景可建 |
| 5 | **与农场的距离**：据点组落点先于一切玩家农场冻结；玩家选址时距任一据点组中心 ≥ 300 m 为禁建区（选址界面灰显并写 "Too close to an outpost"） | 农场不堵广场；据点不被私人内容包围 |
| 6 | **冻结**：全部落点服务端生成一次写入世界数据；地图数据更新不触发搬迁 | 全服一致，不漂移 |

### 2.5 命名与外观

| 对象 | 规则 | 示例 |
|---|---|---|
| 组名（组 1） | 「<城市名> + 柜台」 | Shanghai Market / Shanghai Tackle Shop / Shanghai Travel Post / Shanghai Tea Stand |
| 组名（组 2…N） | 优先地图数据里的区级行政区英文名；无则从本气候带词池取不重复的一个词：tropical = Palm · Reef · Monsoon · Mango · Lagoon · Coral · Banyan · Breeze；subtropical = Bamboo · Camphor · Lotus · Osmanthus · Tea Hill · Magnolia · Pagoda · Harbour；temperate = Oak · Maple · Mill · Meadow · Chestnut · Willow · Bridge · Orchard；cool = Birch · Pine · Fjord · Frost · Spruce · Moss · Lantern · Reindeer | Pudong Market（行政区）/ Shanghai Lotus Market（词池）|

### 2.6 多实例同功能：共享额度与共享板

原则：**多一组 = 多一个地点，不多一份东西。** 所有额度键里没有"组"。

| 额度 / 内容 | 键 | 说明 |
|---|---|---|
| 地区种子日库存 | 账号 × 气候带 × 日 | 同一气候带所有 Market（跨城也算）共享一份 |
| 树苗、果木肥、亮片、蚯蚓日库存 | 账号 × 日 | 全球所有据点共享 |
| 鱼竿、鱼笼 | 账号一次性 | 买过即有 |
| 地区配方卡 | 账号 × 气候带 | 每带一张，买过即有 |
| 据点收鱼（地板价） | 账号 × 日 | 全球共享 |
| 异城特产回收 60 / 日 | 账号 × 城市簇 × 日 | 上海 6 组共用同一个 60 |
| 茶 / 咖啡 3 杯 | 账号 × 日 | 全球共享 |
| 旅行许可 2 / 周、长途票 1 / 周 | 账号 × 周 | 全球共享 |
| 集市委托板 2 槽 | 账号 × 城市簇 | 同城所有组显示**同一块板**的同两条实例；交付地点写 "Deliver at any Shanghai outpost" |
| 系统委托每日 ≤ 6 份 | 账号 × 日 | 不变 |
| 据点章 `stamp_outpost` 据点章 / Outpost Stamp | 账号 × 据点组首访 | 纯收藏进护照「Outposts」页，不进任何门禁与成就计数；护照显示 "Outposts · Shanghai 2/6" |
| 首访礼 2 枚地区种子 | 账号 × 城市簇 | 不变 |
| 常客口径「当地交付每日 1 次」 | 账号 × 城市簇 × 日 | 不变；在哪一组交付都算同一次 |
| 赠餐 1 份 | 账号 × 日 | 所有角色、所有组合计 |
| 每日首谈 +2 好感 | 账号 × 角色 × 日 | Pip 在 6 组出现，一天只算 1 次 |
| 探索委托「Stamp Run」 | 实例指定一处据点组 | 目标改为"本城另一组或邻城任一组"，给多组一个被访问的理由 |

### 2.7 家组据点与旅行成本

| 项 | 规则 |
|---|---|
| id / 名称 | `home_outpost` 家组据点 / Home Outpost（原「家格据点 Home Outposts」改名，功能等价） |
| 定义 | 距家农场最近的一组据点组（城市组或荒野组皆可） |
| 成本 | 往返永久 0 体力 0 金币、按 Trip 1 Local 处理 |
| 同城其他组 | 农场所在城市簇内的所有组按旅行章"同城 = Trip 1"同样免费、即时；所以上海玩家 6 组全免费，与"只免一组"没有区别 |
| 荒野家组 | 农场在无城市格：家组 = 本格荒野据点组；最近城市的组按 Trip 档计价（最近 3 城永远 Trip 1 免费） |
| 变更 | 只在农场搬迁时重算一次 |

### 2.9 边际递减与公平口径（不变，口径收紧）

第二组对同一玩家没有任何新增产能：同带种子共用一份日额度，回收共用一个 60，茶共用 3 杯，板共用一块。上海玩家 6 组与特罗姆瑟玩家 1 组买到、卖出、接到的东西一样多。**大城市多出来的全部是地点、名字、掌柜脸、角色与氛围**；任何家格到技能满级与 Homestead Lv10 的天数差 ≤ 10% 的要求不变。

## 3 POI：试验性视觉层

### 3.1 新定位与保留 / 删除清单

| 项 | 原 | 新 | 状态 |
|---|---|---|---|
| 定位 | 第三层供给：承载额外内容 | **试验性视觉层**：只为让周围世界看起来丰富，无玩法功能、不进任何门禁与成就 | 已定（会议） |
| 地图图标 | 按瓦片数据的两级类别映射显示 | 保留；已探索城全彩亮灯，未探索城灰剪影 | 保留 |
| 点击 | 弹 POI 明细（名字、类型、3D 场景入口） | 弹一张只读名片（名字 + 类型图标），无按钮、无进入；或完全无交互（待确认） | 降级 |
| 3D 场景 | 一级场景 Outpost "含真实 POI 场地" | 删除；POI 没有场景 | 删除 |
| 引导标记 | POI 上方绿 ✓ / 金 ! / 青 ◆ / 紫 ★ / 灰 🔒 | 五种标记只挂据点组、鱼塘、农场；POI 上不出现 | 删除 |
| 事件接口 | 集市 POI 周末市集、地标节日 | 预留：服务端可把任一 POI 临时标为 `event_venue` 事件场地 / Event Venue 并点亮紫 ★，活动期内有一张活动卡；原型阶段不实现 | 预留 |
| 迷雾 | 未探索城 POI 灰剪影不可点；探索后可点 | 不变（只是可点后弹的东西变成名片） | 保留 |
| 数据原则 | 不按店名猜用途、无名不上图、内容挂"城市 + POI 类型" | 前两条保留（图标映射仍然需要）；第三条作废（POI 不再挂内容）；"Old Kai moved to the pier" 这类改挂文案删除 | 部分保留 |

### 3.2 原挂 POI 内容的新归属
