## 1 烹饪等级三模型对照

### 1.1 评分表（每格一句话 + 1–5 分，5 = 最好；"UI 复杂度 / 实现量 / 红队破绽数"5 = 最少）

| 维度 | A 熟练度 XP 轨 | B 厨房材料 + 金币 + 门禁 | C 并入 Homestead |
|---|---|---|---|
| 成长感 | 每次开火都是进度，10 级 10 件新东西 **5** | 4 次升级有仪式，但等级是"买"来的，做 500 道与做 28 道同一级 **3** | 没有烹饪自己的数字，Hearth / Kitchen / Great Kitchen 只是门牌 **2** |

### 1.2 分数接近，胜负由两条硬标准决定

| 硬标准（来自会议） | A | B | C |
|---|---|---|---|
| "烹饪也应有等级"——等级要由**做菜**决定 | 是 | 否（由石头、金币与"会做多少种"决定） | 否（由 Homestead 的金币决定） |

## 2 裁决：A+ ——Cooking XP 轨决定食材槽，Homestead 保留灶口

### 2.1 一句话分工与五条边界

**农场决定厨房有多大，技能决定你的手能做什么。**

| 边界 | 定稿 |
|---|---|
| Cooking 管什么 | 投料槽 2 / 3 / 4 / 5（Lv1 / 3 / 6 / 9）、火候金区加宽（稳手 I / II）、做菜便利（Cook Again / Queue ×2 / Double Clue / Cook All）、行囊 +1、专用器具配方可见（P2）、Buff 强化（P3） |
| Homestead 管什么（不动） | 灶口 1 / 2 / 3（Lv1 / 4 / 8）、调味架储物（Lv2，四种调味料各 30 份不占背包）、保温柜 6 / 12（Lv3 / 8）、大锅 Double（Lv6）、名厨招牌（Lv10） |
| Cooking 不做的事 | 不消耗体力；不计入 Homestead 技能和（仍是 Farming + Fishing ≥ 2N − 1）；不设每日 XP 封顶（只留防脚本 3,000）；不是任何其他系统的前置 |
| HUD | **头像外圈维持双色**（Farming / Fishing）；Cooking 等级与槽位点显示在厨房面板顶栏 `Cooking Lv4 · ●●●○○`，技能页加第三张卡，出锅飘字写轨名。若原型测试显示玩家察觉不到 Cooking 在长，再升级为三段环 |
| 命名 | 技能轨 `cooking` 烹饪 Cooking；等级 Cooking Lv1 … Lv10；页类别 `page_signature` 签名页 Signature（4 槽）/ `page_feast` 盛宴页 Feast（5 槽）；称号 `title_star_chef` 星级厨师 Star Chef |

### 2.3 XP 来源表（三道闸：同页递减、稀有度等级差、防脚本）

| 来源 | XP（全额） | 受等级差 | 规则 |
|---|---|---|---|
| 做成 Common / Fine / Rare / Legendary 菜 | **4 / 8 / 16 / 32** | 是 | **同一页每日第 1 锅 100%、第 2 锅 50%（向上取整）、第 3 锅起 0**；04:00 日切重置；大锅 Double 出 2 份按 1 锅计 |
| 做成 4 槽签名页 / 5 槽盛宴页 | **44 / 60** | 是 | 同上 |
| 火候品质 | Good ×1.25、Perfect ×1.5，向下取整 | 乘在等级差与同页递减之后 | Common Good 5；Fine Good 10；Rare Good 20 / Perfect 24；Legendary Good 40 / Perfect 48；签名 Good 55；盛宴 Good 75 / Perfect 90 |
| 首次做成一道菜 | **10 / 20 / 40 / 80**；签名 80、盛宴 120 | 否 | **全部由 Farming / Fishing 移交 Cooking**；56 页合计 2,460；原"归内容等级最高原料所在轨"规则只保留给 Cookbook 排序 |
| 首次做出黑暗料理 `dish_mystery` 黑暗料理 Mystery Dish | 10 | 否 | 之后永远 0 |
| 一道菜 Cooked ≥ 10（Mastered；Lv5 起 ≥ 7） | +15 一次性 | 否 | 56 页上限 840 |
| 吃 / 赠 / 交委托 / 买配方卡 / 品尝 / 翻 Cookbook | 0 | — | 不付原料的动作不给 XP |
| 防脚本上限 | 每日 3,000（一次性不计） | — | 重度极端日 12 锅盛宴 Perfect = 1,080，碰不到 |

**为什么"同页每日 100 / 50 / 0"是对的闸**：① 它复用玩家已经知道的进食递减数字，不需要新教学；② 正常节奏不受影响——30 分钟玩家一天 6–7 道菜本来就是 5–6 个不同页（正餐三道不同菜 + 夜宵 + 赠礼 + 实验），重度 10–12 道里重复的只有"存给明天"的 1–2 份；③ 它把红队算的"25 条鲫鱼 = 25 次 XP"压成 4 + 2 + 0 = 6 XP，"把所有鱼做成菜去回收"失去意义，鱼的售价不再归零；④ 一个 Lv4 玩家把已知 22 页各做一遍理论上可拿约 170 XP，但要 22 份分属十几种类的主料，现实上限约 10–14 页 / 日，与方案本来假设的 90–145 XP / 日吻合。
