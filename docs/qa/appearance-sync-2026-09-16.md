# 多人装扮同步修复：0.10.2

2026-09-16，用户在联机测试中反馈“未同步对方的服装”。此前远端完整角色固定装配默认套装，
协议中也没有实际衣柜配置；不是位置同步延迟。

## 实现

- 新客户端在街区、农场、矿井入场时发布本机已保存的 14 槽装扮。服务器用相同的部件目录和
  剔除名单校验部件/槽位，只接受外观 ID；不接受资源路径、战斗数值或替他人换装。
- 初始名单、加入通知和换层名单包含实际装扮。保存换装后向同层广播变更，重复配置不重复广播。
  客户端合并更新到每秒一次，服务器限制到至少 500 ms 一次，位置二进制包保持原大小。
- 复用近处角色模型时应用对应玩家的最新服装、发型、鞋子和配饰，移除已卸下的可选部件；
  等待装配时隐藏旧服装，避免上一个玩家的配饰残留。远端装扮不写入本人衣柜。
- 本人农场/街区/矿井中的角色也跟随成功保存的换装更新。矿井断线恢复成功后清除旧连接错误提示。
- 保留最近 8 人完整骨骼、其余简化人形的渲染分级。远处人形不显示全部服装细节；靠近进入完整模型名额时
  使用最新装扮。衣柜仍在本机保存，重连重新发布；本轮没有引入跨设备云衣柜或修改装备属性/归属。
