# 农场水面与岸景对齐 · 2026-09-22

用户提供真机池塘截图，指出水面与芦苇、岸石错位。本轮修正只涉及客户端水域视觉：`modules/farm/farm_terrain_mask.gd` 和 `modules/fishing/water_shore.gd`。未更改钓鱼判定、导航、碰撞、地形存档、真实地理多边形或服务端。

## 原因与修正

主要原因是地理水层重复绘制了偏移半格的人工鱼塘。`FishingWater` 的网格、水面 shader 和岸景均使用实际池塘中心 `(6.4, -26.4)`、半径 `(3.84, 2.48)`；但 `FarmTerrainMask` 对所有椭圆额外加了 `(0.5, 0.5)` 格中心偏移。40×40、0.8m 格的保存农场因此在 `GeographicWater` 出现向东/北各 0.4m 的第二层水面，超出岸景边缘。修正只让水域椭圆使用原水面中心，其他地形椭圆、道路和真实地理多边形沿用原采样。

岸景同时存在轻度内缩：以 95.5%–98.5% 缩小椭圆撒点，并把径向方向当作椭圆法线；远岸大石又向塘内退。现在沿实际水面椭圆生成，使用椭圆梯度得到法线，以固定米数微调岸石和植物。石组跨过水岸线，芦苇/细草根处于干岸边；保留原材质、密度、远岸较大石组及东/南岸低石，不添加碰撞。河流装饰分支未变。平面反射的镜像平面和遮罩没有造成这次坐标偏差，无需修改。
