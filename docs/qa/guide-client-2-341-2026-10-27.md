## 当前实现

- `P0Guide` 读取服务端已解析的 marks / pip，不解析英文，不在客户端推进步骤。农场门、升级牌、据点板与居民状态按当前目标过滤；其他城市的同名居民不会亮引导标记。资源 Ready、普通设施图标、作物事实、Mailbox Parcel 计数及 HUD 红点不在过滤范围。
- 农场 Pip 复用现有造型，scale 0.88，在首畦左前方的通路上，无新增碰撞。WIP 的 head / visible_head / at 已改成显式类型。首次取景包含角色、Pip 和两块教学田，保持既有镜头角度与缩放；只影响进入引导的初始取景，不在后续步骤自动移动相机。
- Pip 初次进入视野播放现有 `emote_wave` 一遍后回 idle；现有资源一周期为 0.533 秒，未改变动画资产或速度。只有服务端 pip.bang 为真才挂 !；点模型、名字或徽标打开既有居民对话条，农场不出 Request。显式 `_reply` 优先于 pip.line，为 C3 补发答话保留位置。
- NPC 复用 36 px StatusBadge，保留原名字条：当前目标新委托 !、已能交付 ✓（341 ec56d336）、送礼 ♥。徽标继承名字条画布位置，点击区包含徽标。普通名牌、谈话高亮与面板遮挡规则保留。
- 教学田使用已有浅绿格框；按服务端实际格号生成，S2 不额外亮第三块脚前格，不限制其他格劳作。播下后收掉教学格框；服务端指定且实际仍为 sown 的教学田挂现有水滴图标的 28 px StatusBadge，浇水回包改为 growing 后收起。水滴避让 Pip 名字条，不改其位置或点击区；无目标、引导结束、面板/放置/离场或画外时不显示。原文将待浇徽标写成“既有显示”不准确，详末节核实。
- 已接 typed button：sow / water / harvest / location / cast / quickbar:seed_lettuce / request / gift / cook（携带 page），以及 object=stove、item=dish_fish_soup。GuidePulse 沿用 600 ms 单次光圈，围绕可见按钮而非额外触区；生菜复用格闪。一个运行时内同一服务端步骤、同一目标最多两次，补救往返、控件重建或逐帧刷新不补充次数；不可用 / 不在视口的目标不闪。不会自动打开面板、切配方或选礼物。
- 引导结束立即收掉引导标记、格框与脉动；已在场的 Pip 模型留到离场，suspend / leave 清理，结束后的再次进入不生成。未实现 C3 的补钓 / 补发反馈、通知软提示或平台桥。
