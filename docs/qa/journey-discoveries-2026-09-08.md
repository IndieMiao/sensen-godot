# 手工作品、地点发现与持续补给

日期：2026-09-08。基于当前工作区继续修改。目标是让第一轮制作之后，作品能够改变地图地点的用途，并影响下一轮资源选择。

## 已实现

| 地点 | 玩家投入与准入 | 持续用途 |
| --- | --- | --- |
| 苗圃石窝 Lantern hollow | 修通侧径后，安装一件手工石灯 | 每次苗圃探索任选 3 石料或 3 木料 |
| 庭院编织园 Weaving garden | 摆下初始花箱并认识小馆主理人后，安装一件新制作的花箱 | 每次庭院探索任选 3 芦苇或 2 生菜种子 |
| 小馆厨房花园 Kitchen garden | 首次共同用餐并制作过石灯后，安装一件手工喷泉 | 每次小馆探索任选 1 胡萝卜 + 1 生菜，或 1 洋甘菊；花卉仍需已解锁 |

新物件在首次制作花箱后出现在 3D 场景中；点击后角色跑到物件旁，再打开该地点的上下文面板。安装留下实际作品和已修复地物；领取后资源或植被减少，下一条本地点路线开始后恢复。

安装消耗真实手工库存，不能消耗初始庭院花箱或直接扣掉陈列物。陈列中的物件需先收回。安装事实只发放一次，重复安装、陈旧序列、未知物件和未满足准入均拒绝；不额外发首通金币。

每地点每轮只能领取一个选项；重新进入、重启、更换请求键或刷新其他地点均不重置。完成本地点普通采集点后可开始下一轮。新补给不是刷新路线的必做条件，未领取时允许主动进入下一轮；不会累积多次补给。种子进入绑定种子库存，保留既有种植和交易规则。

玩家可以追踪一个待修复地点，随时取消或替换。持久目标会依次指向缺少的材料、工作台、已陈列作品的收回地点或安装地点。已有可领取的新材料来源优先进入推荐；安装后自动清除追踪。地图的小状态文字显示当前缺口或可执行动作，保留原有稳定锚点，不增加大卡片。三个修复点加入旅程目标列表。

新面板在 360×640 中直接显示安装、追踪和两个补给选项。旧设施的陈列管理仍需要滚动；这部分没有宣称完成场景化。

## 玩法判断与下一轮

已证实的是规则和操作闭环：手工作品存在出售、陈列、安装的用途取舍；安装以后可以在原地点取得新的资源组合，并选择这一轮的用途。这里的选择由测试人员主动覆盖，不能当作自然玩家自发改变策略的证据。

这仍然只有三个固定修复点和固定补给组合。地图坐标及二级场景未使用真实街区道路拓扑；修复也没有打开新的可行走区域。不要把功能测试通过写成持续好玩或留存改善。

下一轮优先验证：

1. 让未玩过的新玩家从空存档自然体验首小时，记录第一次不知道去哪、第一次被迫等待、自主换目标和主动离开的原因。
2. 观察补给是否成为压过种植的最佳刷钱路线，检查每分钟投入产出；继续围绕新用途和选择调整，避免仅堆叠奖励。
3. 把陈列物的选中、收回与换位接到场景物件，减少旧面板滚动；补上人物实际使用新设施的反馈。
4. 把至少一条修复连接落实为可行走路线变化，让地图空间影响选择；当前三个固定地点不能替代这一步。
