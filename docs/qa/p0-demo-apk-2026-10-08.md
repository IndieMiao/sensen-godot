# P0 内部演示包 com.sensen.p0demo（SGODOT-232 D2，2026-10-08）

**结论**：P0 演示包能用一条命令构建。冷启动直接进 P0、落在农场首畦旁，连包内写好的服务地址，不再靠 adb 写启动标记，也不靠 adb reverse。**只做内部演示**：对外分发要用户批准（AGENTS.md 规定对外只发 Journey 一个包）。

## 构建

```sh
tools/p0/build_demo_apk.sh --server https://<host>/preview/p0/v1 [--key <演示口令>] [--code N] [--name p0-0.1.N]
```

- **导出预设 `Android P0`**（export_presets.cfg preset.2）：
  - feature `p0`；包名 `com.sensen.p0demo`；显示名 `P0 Demo`；版本自成一套（versionCode 1，versionName `p0-0.1.0`）；
  - 显式打开 INTERNET 权限：Journey 正式包靠 WebView 插件的清单带进这个权限，新装的构建模板里没有。
- **服务地址与口令**：脚本把它们写进 `assets/p0/demo_server.json`（已 gitignore），只在这次导出时存在，导出后连同 export_presets.cfg 一起还原。
  - P0Session 读服务地址的顺序：`user://p0_server.txt` > `P0_SERVER_URL` > 包内文件 > 本机默认。
  - 有口令时作为请求头 `x-p0-key` 发送，供 D1 的服务端校验。
- **带 p0 feature 时 Journey 的 Net 不启动**：以前的 P0 Proto 会顺带登录 Journey 线上服务（10-05 记录过 NO_FARM）。
- **adb 隔离**：Godot 导出结束时会停掉它连的 adb 服务（`shutdown_adb_on_exit`）。脚本把 adb 指到私有端口 `P0_ADB_PORT`（默认 5071）。实测导出后被停掉的是 5071 上我自己的 adb，没有碰 5037 或其他会话的端口。
- **校验结果**写入 `output/p0-demo/build.json`：包名、版本、证书 SHA-256、包内服务地址是否一致、口令是否写入（不打印口令）、APK SHA-256。

## 本轮验证（本机 Mac、自己的 AVD）

| 项 | 结果 |
|---|---|
| 构建 | `--server http://10.0.2.2:3152/v1`，APK 145 MB。aapt：`com.sensen.p0demo` / 1 / `p0-0.1.0` / `P0 Demo`；包内有 `uses-permission INTERNET`、`assets/p0/demo_server.json` 和 `p0_content.json` |
| 签名 | debug keystore，证书 SHA-256 `38771d94…8515673`。与原 p0proto 同一证书，但包名不同，可以和用户手机上的 p0proto 并存 |
| 模拟器 | 新建的 AVD `Mengtian_P0`（2 GB 内存，宿主 GPU 渲染），端口 emulator-5594，adb 用 5071 |
| 冷启动 | 第一次构建打开的是 P0 地图（`P0_TIMING attach P0Map`）。随后按 A-03 把 `p0_boot` 的默认入口改成农场，复测进 `P0Farm`：落在首畦旁，快捷栏小萝卜 ×20 已选中、生菜 ×10，主行动键 `Sow · Walk to a plot` |
| 连服 | 本机 3152 上我自己起的 P0 服务收到新玩家（180 金币、200 体力）。Godot 日志无报错 |
| 发现并修复 | ① 包里没有 INTERNET 权限：socket 打不开，已在预设中打开。② 启动时连接失败会在 UI 建好之前弹提示，导致空指针：首次刷新改为 deferred。③ 默认入口改为农场 |
| 收尾 | 模拟器用 `adb -s emulator-5594 emu kill` 关闭；服务按记录的 PID 关闭；5071 上的 adb 已停 |

截图在 `output/mengtian/d2-run/`：`launch.png`、`launch2.png` 是地图入口（模拟器上原生 Mapbox 底图不渲染，透出了桌面），`launch3.png` 是农场入口。顶部「Viewing full screen」是安卓系统首次全屏提示，不是游戏界面。
