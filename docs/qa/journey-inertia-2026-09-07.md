# 二级场景惯性与边界回弹验收

日期：2026-09-07。对应用户追加的自己农场与他人空间拖动、缩放惯性和边界回弹要求。接续[上一轮镜头与入口交互](journey-pan-2026-09-07.md)。

后续已修复[地图抽屉重叠及关闭交互](journey-map-drawer-2026-09-07.md)，当前安装包以该记录为准。

## 实现

- 农场、访客农场和旅程地点共用 `modules/farm/scene_pan.gd`。单指拖动后镜头按松手速度继续减速；再次按下立即接管镜头，按住停顿再松开不会沿用旧速度。
- 平移常规边界为半径 1.6 米，越界拖动有递增阻力，最多额外拉伸 0.55 米，松手后平滑回到边界。
- 双指缩放范围为默认取景的 0.8–1.4 倍，带缩放惯性和弹性越界。尽量保持两指中心对应的地面位置，接近平移边界时受边界约束。
- 双指操作不触发农活、人物移动或物件点击；抬起一指后，剩余手指不会被当成新的点击。普通活动面板、切换场景和应用失焦会取消相机手势。
- 布置模式保留单指拖家具和一次撤销整段拖动；空地拖动使用镜头惯性。拖家具时加入第二指，会取消本次家具草稿移动并接入相机缩放。
- 桌面支持鼠标拖动、滚轮和原生放大手势。惯性与弹簧使用最多 1/120 秒积分子步，覆盖 30/60/120 Hz 一致性与长帧稳定性。

## Android 输入修正

项目启用了 Android 原生缩放手势。真机检查发现 Godot 会用 `InputEventMagnifyGesture` 替代原始双指拖动事件，因此仅处理原始触点距离会导致真机缩放无效。最终实现按平台输入模式接入原生缩放，并防止重复缩放和松手后的尾随事件。

原生识别器有最小指间距离和移动阈值。最终 APK 的两次窄距离尝试虽收到双指事件，但没有达到系统缩放阈值，不计为缩放成功；扩大指间距离后的放大、缩小及回弹均有实际相机轨迹。早期未修正输入路径的证据位于 `output/journey-inertia/evidence/`，最终包证据位于 `verified/`。
