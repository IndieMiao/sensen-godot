# 场景陈列、侧径与居民交互

日期：2026-09-08。接续地点发现版本，优先修复 3D 操作与连续游玩中的具体断点。

真机后续：已在 vivo V2509A 验证主要链路，详见[真机记录](journey-physical-v6-2026-09-08.md)。短间距缩小识别和后台 Vulkan 表面丢失日志仍单列待定位，没有将模拟器通过扩大为全部真机行为无问题。

## 实现

- 三个地点的手工作品可以直接点实物。角色跑到可达位置后，打开该物件的收回或替换操作；替换复用服务端原有原子命令，旧件返还背包。
- 设施标题旁提供布置入口。布置时才显示空陈列位，点击位置选择已有作品；支持拖动镜头、完成按钮和系统返回。普通探索不增加空位标记，也不再给每件作品常驻浮标。
- 删除陈列位置下拉框及旧的长列表，避免从下拉框起手滑动时误开菜单。三处设施、空位、已有作品面板在 360×640 和 390×844 中无需滚动即可操作。
- 工作台改成三行配方，各自显示库存、材料、制作和交付操作。修复了第二个制作按钮在小屏中被挤出可视区域的问题；未解锁条件和缺料禁用仍保留。
- 苗圃侧径现在具有实际路障和步道。修复前阻断通行，修复后新增井旁的可走区域；角色可以进入采集点，并跑到出口前往庭院。使用已有 `side_path` 事实，旧存档立即呈现对应状态。
- 小馆来访的苗圃管理员可以独立交谈，使用她自己的故事、请求和赠礼资格。人物转向玩家；居民站位和小馆前桌座椅加入寻路避让，并调整居民位置保留操作通道。
- 交互接近点检查实际可达路径，避免选到家具之间隔离的空格。保留点到点跑步、速度 3.75、稳定标记锚点、透明度避让以及镜头惯性和回弹。

没有修改服务端数值、内容哈希或存档结构。领域版本仍为 6，内容版本仍为 `f3b34951f855daec`。

## 验证

- 最终 Godot 原生回归 38 项通过：旅程、居民到访避让、侧径连通、地图标记、移动及镜头手势。
- 服务端现有陈列和发现专项 13 项通过，覆盖原子替换、库存及领取规则。
- 原生渲染检查覆盖三个地点、两种尺寸、满陈列与空位、设施及工作台面板。检查场景像素非空、所有操作点可达、接近位置避开居民、实物点选不会选错物件、按钮位于面板可视区域、返回可退出布置。
- 模拟器用真实触控完成三处陈列的摆放和收回、石灯与花箱替换、侧径采集及前往庭院、两名小馆居民交谈、沙拉制作、工作台制作、农场移动与镜头操作、地图抽屉打开及关闭。
- 对每次陈列变更核对“背包 + 全部陈列位”的物品总数，制作按真实材料扣除；重启前后核对旅程、库存与金币。详细操作数量、版本和回执以 `verification.json` 为准。
- 实测庭院缩放出现约 1.45 的弹性超出后回到 1.4；农场缩放松手后继续变化，拖动没有移动角色或改变存档。

最终证据：94 条操作或截图记录，其中 89 次触控有回执；版本 73 → 92。12 次陈列命令物品总数守恒，1 次制作扣料正确，5 次跨启动记录保持旅程与库存一致。549 条移动中的跑步采样确认动画时间推进、配置速度为 3.75。一次未发生缩放的触控另按下文记录，不计为缩放验证通过。

最终构建日志没有脚本错误或崩溃；仍有既有的 `xr/shaders/enabled` 配置警告。最后一版重新验证了小馆陈列收回、摆放、退出，以及座椅外的接近位置。

本轮过程中发现并修复的失败：小屏第三个陈列选项裁切、苗圃设施末项裁切、工作台配方需要滚动、人物站位重叠、加入避让后的部分操作点不可达，以及 QA 观察器读取空动画产生报错。最终渲染检查和原生回归均重新通过。

一次窄间距双指操作收到触控回执但没有缩放，扩大间距重试后生效，不能把第一次计为缩放通过。控制器另有屏幕边界、旧锚点不可见、旧工作台按钮不可见的预检拒绝，未发送对应输入。反复重启触发本地登录频控 HTTP 429；重启本地测试服务后恢复，未更改频控规则或重置存档。

## 玩法边界

已验证的是操作与规则闭环：玩家能把作品从陈列收回用于其他用途，制作和修复会留下可见结果，侧径确实改变局部可走区域。这个变化减少了菜单操作，并让已有修复事实具有空间反馈。

以下仍未完成，不能把测试通过等同于整体玩法已经好玩：

1. 新玩家从空存档自然体验首小时，确认目标理解、被迫等待、自主探索和主动离开的原因。本轮使用成熟开发存档，没有验证 60–90 分钟的首日内容或留存。
2. 地图仍是三个固定地点；这次实现的是苗圃二级场景内的一条通路及出口，不是真实街区道路拓扑，也没有完成多条路线之间的经营取舍。
3. 居民现在能独立交互和避让，但仍是状态决定的固定站位；走动、使用设施和行为回应尚需继续设计。
4. 对补给、种植、料理和制作进行实际每分钟产出比较，验证有没有压过其他玩法的单一刷取路线；本轮未以猜测调整收益。

后续优先把这条已能顺畅操作的循环交给新玩家，再依据卡点和资源选择扩展地图路线与居民活动。
