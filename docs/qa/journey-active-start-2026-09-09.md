# 新存档开局试玩与农场交互修复

日期：2026-09-09（上海时间）。本轮继续“60–90 分钟主动游玩、模拟器验证玩法与交互、强化 3D 表现”的 Goal。只使用模拟器与 Godot，没有操作真机。本轮完成了开局问题的发现与修复，整体 Goal 保持 active。

## 试玩发现与修复

从空数据库正常选择上海、老城并创建农场，通过界面完成一块田的清理、翻土、播种、浇水，认识苗圃管理员、采集木料、开启苗圃路线、修复工作台，再回田收获。没有补发资源、修改时间或发送测试玩法指令。

1. **推荐胡萝卜，点地块却种萝卜。** 首次收获后主按钮显示 `Sow 1 Carrot`，直接点 3D 地块仍读取旧的 `selected_crop = R`。存档版本 11→12 确认消耗萝卜种子，浇水后倒计时三分钟。现在推荐作物同步到可见种子选择，地块和主按钮使用同一选择；手动选择仍优先，正在执行的队列不会因推荐更新或种子耗尽而中途换作物。
2. **背包按钮意外带离农场。** `Harvest and supplies` 实际执行“前往下一个目标”，本次把玩家带到小馆。现在在农场内打开库存，展示种子、收获、预留数量、材料、料理与库存手工作品。复用已有抽屉和滚动容器，读取服务端状态，关闭或返回后恢复场景，不产生玩法命令。
3. **劳作结束后种子选项没有立即恢复。** HUD 在解除忙碌标记前刷新种子行，导致按钮已恢复而种子仍被隐藏或禁用。调整刷新顺序，使其与主操作同时恢复。

实现涉及 `scenes/farm/farm.gd`、`farm_hud.gd`、`life_sheet.gd` 与 `scenes/place/journey_activity_panel.gd`。没有修改经济、成熟时间、服务端命令、领域版本或存档结构。

## 时间口径与玩法结论

本次是熟悉实现的开发者试玩，不是陌生玩家盲测。发现错误后暂停试玩计时，修复、构建、回归验证及后续经过的时间均不能计入首会话主动内容。

- 正常界面试玩记录区间为 UTC `16:02:03.329–16:02:29.000` 与 `16:05:47.403–16:11:48.212`，共 386.48 秒，约 6 分 26 秒。
- 这两个区间有 25 次成功输入，固定截图等待共 50 秒；此外仍包含模型判断、工具往返、控件查找及汇报时间。**386.48 秒是区间总长，不是有效主动游玩时长。** 不以减去 50 秒的结果代替主动时长。
- 首次安装、系统提示、上下文切换与全部开发停顿排除在外。暂停期间作物自然成熟，此后的回归记录不能拼接成一次连续的新玩家体验。
- 在这一小段中，首块田生长时能认识居民、获取材料、修好工作台，并收到田外成熟提醒；尚未观察到所有有意义行动耗尽的情况。这只说明走过的开局路线可衔接，不能推断慢速或快速玩家也不会等待。
- 苗圃的“探索路线”仍主要是同一场景的资源点补充，地图选择和空间变化较弱。首见居民同时展示重复委托，是否分散主目标需要陌生玩家验证，目前属于设计疑点。

后续优先继续完整的新存档或明确分段的开发者试玩，记录最早的目标混乱、强制等待、重复采集和自主改选；再检查第一顿饭之后的两轮循环。60–90 分钟主动内容、陌生玩家继续意愿和留存改善均未验收。

## Android 兼容提示

本轮 QA 包在 Android 37 模拟器安装后出现 **16 KB page-size compatibility** 提示，确认后可运行。系统列出 `libgodot_android.so`、`libmapbox-maps.so`、`libmapbox-common.so`、`libc++_shared.so`，其中两项 Mapbox 库明确报告 LOAD segment 未对齐。

这是已确认的 QA 包兼容性问题，尚未修复，应在下一次分发前检查导出模板与原生依赖，并单独验证实际发布 APK。不能据此断言合伙人此前收到的 APK 同样失败。没有选择永久隐藏提示。
