# 地图二级面板统一与尺寸检查

2026-09-22，用户确认紧凑UI比例后要求继续。本轮将已确认的白色/浅绿样式推广到地图地点列表、邻居面板和NPC卡片，保持地图及游戏数据契约。

## 结果

- 邻居面板移除紫色厚边，合并重复的页签/人数标题；卡片改为118×48、浅绿选中态。选择后显示真实农场缩略图、作物摘要和44px高的拜访入口。常规手机上列表为108逻辑像素高，含选中预览时170px高，底栏上方保留8px间距。
- NPC卡片显示居民当前交谈/交付状态，拜访按钮收为104×44触摸区域，浅绿可见面保持紧凑；角色头像在缓存完成后更新。
- 地点列表使用对应的彩色地标素材，保留44px行触摸高度。修正按钮文字色对彩色素材的意外染色，正常/悬停/按下保持素材原色。
- 地点列表、地点/NPC资料和邻居面板互斥；邻居展开时底部“邻居”高亮，关闭后恢复“地图”。旧缓存农场尚无journey数据时也能看到关闭按钮。
- 屏幕尺寸与地图朝向参与POI查询视野标识，缩放/旋转/窗口改变后更新实际视口数据。
