# 五层新手矿坑验证

日期：2026-09-14。分支：`farm-dev`。本地实现与验证完成，已导出并安装独立 Android 本地测试包；未部署线上、未提交或推送。

## 实现

- 自己的农场可直接点矿坑入口，角色跑近后进入；访客不能操作其他农场的矿坑。
- 五层各六块矿石，走近开采后由服务端确认掉落，清完本层才能下楼。
- 第五层首次清完永久开启第一层与第五层电梯。完成后回农场可主动开始下一轮。
- 每块固定一份石料，额外铜矿石/岩盐/无额外材料的权重为 35/25/40。
- 铜矿石用于铜箍木箱，岩盐和萝卜、生菜用于蔬菜汤。接入既有工作台、陈列、厨房、库存和摊位。
- 离开和重启保留矿石领取记录；断网可返回农场，未确认命令保留以便恢复，不能重复领取材料。
- 新材料缺省为零。领域版本为 `15`，结构版本保持 `1`；旧存档需按既有显式规则迁移后使用新服务。

## R3 通关后再次入矿修复

用户反馈五层全部完成后再次进入矿坑卡住。直接读取当前真机画面确认：
服务端为 `run=2`、`floor=0`，五层均已采完；客户端却显示一个没有交互对象的矿坑。
原因是已完成状态绕过了正常入矿请求，移动也被 `floor == 0` 条件禁止。

修复后再次访问会正常入矿：全部五层采完时，顺序确认 `restart_mine` 与 `enter_mine`，
使用权威回包里的新轮次；只采完部分楼层（包括仅第五层）则继续原轮。
第一层的主动重开改为独立文字按钮。重连会先解决原幂等请求，再接续尚未完成的入矿，
退出时的状态更新不会触发自动重入。库存、电梯与其他农场成长保持。

## R5 随机矿石与模型点击

矿石间距至少 1.8 米，距出生点、梯子、电梯至少 1.6 米；有限重试后有安全回退。
