# 街道建设与居民委托

- 日期：2026-09-08。
- 范围：重复委托的持久建设反馈、街道居民互动及本地验证。
- 环境：Godot 4.7.2 Mobile / Compatibility，Android 模拟器 `127.0.0.1:5561`、独立 ADB `5038`。未操作真机。
- 产品方向：[以好玩为先](https://github.com/IndieMiao/sensen-godot/blob/25b7a8a6e0574f9b0c4c97f480238e98d5d9985c/docs/product/fun-first-rework-2026-09-07.md)。60–90 分钟自然新玩家主动体验仍未验收。

## 实现

六种已有委托分别推进街道的叶菜床、花盆、休息角、收获架、午餐桌和茶具。每种有三个可见阶段，成功交付才增加建设记录；原有材料成本与金币报酬保持。达到第三阶段后仍可接单获得报酬，模型不再叠加。这是有限的世界改造，没有引入无限生成的任务或新资源经济。

街道增加三个路旁工作区。三名居民在道路上跑到工作位置，浇水、修缮或备餐，再返回。玩家移动或交谈时居民暂停，玩家寻路会排除其占用位置，居民移动也检查与玩家和其他居民的间距。工作区和活动位置避开地点入口、补给及侧径；七套随包布局均有覆盖。

点击居民后，角色靠近并打开当前委托，交付成功关闭面板，镜头展示建设成果，居民作出场景回应。缺少原料时可前往农场、苗圃或小馆。街道与原地点共用委托序号和建设记录；地图地点提示在更优先机会耗尽后显示街道工作或建设进度。

领域版本升为 9，内容版本为 `0721530400b2c717`，状态结构版本仍为 1。新增的可选 `journey.contributions` 不从旧请求序号回填，因为序号包含跳过请求。旧存档须显式迁移，迁移只更新版本元数据，保留全部存档和历史命令。

## 检查发现与修复

- 默认网格的两名居民初始站位过近，阻塞彼此寻路：增加站位间距，避开其他居民的工作终点。
- 一套布局的活动位置靠农场入口太近，初始角色阻断路线：工作位置距入口至少 2.4 米，居民往返路线避开初始落脚点。
- 街区相机距离超过角色默认休眠阈值，导致显示 `run` 等动画名称但骨骼时间停住：玩家和居民采用适合街区相机的 50 / 80 米活动距离。新增原生动画时间推进检查，并在最终 APK 上采集实播数据。此前 APK 的状态交付证据仍有效，但不能用来证明动画正常。
- 通用餐桌模型自带杯子与花朵，会在首次沙拉交付后提前显示茶具：改为独立桌面，仅按对应交付记录生成餐盘和茶具。
- 一处居民停留点靠近采集点，人物名与材料文字叠在一起：工作点和停留点距采集点至少 2.4 米，不引入避让重排；七套布局补测后通过。

## 模拟器闭环

从上一轮完整版本 180 存档副本开始，没有补材料、清档或改时间。最终版本 195，15 次权威状态变更：

1. 街道完成两次木料交付，休息角依次出现长椅、第一盆花；中间换请求不增加建设。
2. 苗圃缺料入口带角色回到农场。随后从已有育苗床取得一份洋甘菊，换为花卉请求，在街道交付，花盆进度达到 1/3。
3. 街道料理缺料入口进入小馆。开启该地点的新路线，在已修复的厨房花园选择胡萝卜和生菜，备餐台做出沙拉，再到街道交付，餐桌进度达到 1/3。
4. 在原庭院与修缮师交谈、换请求并完成第三次木料交付，返回街道看到休息角 3/3，验证跨场景共享记录。
5. 覆盖安装最终 APK 后，再完成一次木料交付，金币照常增加，休息角保持 3/3。

最终库存：420 金币、14 木料、8 石料、3 芦苇，建设记录为 `{benches: 3, flowers: 1, picnic: 1}`。六次成功交付、四次换请求；其他变更来自育苗床、路线、花园收获、料理和原场景交谈。

本轮走通的是已有成熟设施下的重复用途，不是新存档自然成熟或完整首会话时长测试。

## 玩法仍需优化

- 委托现在让世界留下成果，但仍是每个居民两种固定请求。完成全部阶段后，报酬继续，新的能力、资源取舍和空间用途不足。
- 居民有可打断的短活动，但尚没有跨地点日常、独立需求变化或更丰富的共同生活事件。休息角和餐桌目前主要提供建设与作业反馈，尚不能自由坐下、使用全部家具。
- 某些布局步行绕路较长，地点缩景和路边活动的辨识度仍可提高。地图直接进入地点继续可用；后续应增加途中有价值的选择，而非靠路程拉长游玩时间。
- 地图仍基于随包蓝图，不是任意地区在线拓扑。60–90 分钟主动体验、教学理解和自然新玩家继续意愿仍待验证，长期 goal 保持 active。
