## Android 与真机

隔离 HTTP 账号在 emulator-5560 完成 29 次真实触控：角色离屏与头像回位、行走/种地、五列背包、滚动取消物品点击、六槽人物/装备选择、委托、购买三颗种子、队伍面板、服务器抛竿/咬钩/收线与退出。日志无脚本、解析、编译或着色器错误。测试账号与公共玩家完全分开。

V2509A (`10AFAF162200319`) 先以相同 UI 源码的临时只读观察包完成 17 次触控，覆盖真实底图、当前农场、角色离屏/回位、背包/人物/委托、摊位/种子视图与队伍。没有出售、购种、吃料理、更换装备、钓鱼结算或迁居等公共存档命令。观察包随后由最终无观察器包覆盖。

最终签名包再次冷启动，进入真实地图、自己的农场、打开背包并关闭，截图已检查。五个原文件逐字节一致：安装身份、农场选择、城市选择、UI 状态、实际装扮。公共 GET 比较农场身份、version、地形、定位、迁居状态以及全部非 `clock` 状态一致；保留 **47 个已开垦地块（46 格已翻土、1 格在种植）、10 个背包堆叠**、钱包、装备及成长时间。迁居状态仍为 `available=false / used=true`，未重置机会。

模拟器上也安装并回读最终普通包，冷启动登录、城市页、五文件及原有农场状态通过；此项不冒称正式包完整玩法验收。所有 app 会话经 `tools/android/run_test.sh`，结束后目标应用已停止，模拟器继续运行。模拟器更新曾遇到空间不足，21 个旧 QA 录像先完整归档到主机并逐个核对哈希，再移走设备上的相同副本；未卸载应用、清除存档或修改存储阈值。
