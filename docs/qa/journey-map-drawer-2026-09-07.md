# 地图抽屉重叠与关闭修复

日期：2026-09-07。根据用户当前连接的 vivo V2509A 地图画面定位并修复。

## 问题与修复

`NearbyPanel` 和旅程工具栏独立贴在安全区底边，地点列表第三行与工具栏重叠。原来的附近按钮再次点击可以收起，但打开后没有状态变化，抽屉没有独立关闭入口，系统返回也未消费抽屉状态。

- 抽屉为工具栏实际高度预留空间，二者间隔 8 逻辑像素；内容改变或屏幕尺寸改变时重新布局。
- 限制抽屉高度，内容超高时内部滚动。页签和 44×44 的关闭按钮固定在顶部，保持可用。
- 增加右上角关闭按钮；底部附近按钮展开后显示向下箭头和选中状态。
- 点地图空白或按 Android 系统返回可关闭抽屉，该次操作不会进入地点、触发地图双击缩放或退出应用。
- 关闭及重新打开时清理遗留地图手势，收起后恢复地图地点标记。
