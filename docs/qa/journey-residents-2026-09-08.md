# 居民使用设施与主动种植选择

日期：2026-09-08。继续推进“60–90 分钟主动游玩、模拟器验证玩法与交互、强化 3D 表现”的目标。本轮让已完成的工程得到居民的场景回应，并修复自动推荐覆盖手动种植选择的问题，不代表整体目标完成。

## 实现

- 苗圃育苗工程完成后，管理员定期跑到育苗床照料；认识小馆主理人后，主理人会整理备餐台；茶露台完成后，来访管理员会到露台停留；庭院种花后，修缮师会到存档中的花箱位置照料。活动按已有事实开放，每次完成并返回后再接下一项。
- 露台招待接入专属反馈：成功交付才在后方茶桌显示对应的茶或沙拉，两名居民跑到桌边、面向料理回应，再返回。成功提示明确写出收入。餐盘八秒后隐藏，普通前方餐桌的交付仍可使用。
- 所有活动复用点到点跑步，移动速度 3.75；玩家移动、交谈、打开操作面板或布置时让出交互。续行时重新规划，逐段校验与玩家、其他居民的距离；被阻挡时等待重试，不穿过人物或传送。
- 人物身体点击区域与标记跟随实际位置。已完成露台的后方桌边区域可走，两张桌子、椅子与棚柱保持阻挡。
- 修复模拟器实际发现的问题：胡萝卜生长时手动选择生菜，主按钮仍显示居民任务，无法通过主按钮播种。现在显式选择和成功买入的种子优先于自动工程、故事与探索推荐；收获、照料和首次收获引导仍优先。播种成功或所选种子耗尽后解除该意图，自动切换的种子不会冒充玩家选择。

主要实现：`modules/farm/resident_moment.gd`、`modules/farm/resident_cast.gd`、`scenes/place/journey_place.gd`、`scenes/place/journey_activity_panel.gd`、`modules/farm/next_step.gd`、`scenes/farm/farm.gd`。本轮没有更改服务端命令、经济数值、领域版本或存档结构；居民日常活动不会产生资源或奖励。

## 玩法审查与后续

这轮让“我建好的地方有人使用”成为可见结果，并让玩家手动种什么的选择生效。日常活动仍是短暂、按顺序触发的场景行为，没有实现坐下、进食或独立居民日程；照料复用现有动作，尚无配套浇水壶道具。不能据此宣称居民系统或场景表现已充分完成。

下一轮优先处理第二、第三轮探索的选择深度，让地点补给、已修复连接和居民需求改变目的地与材料用途，而非反复点击同样的资源点。随后从新存档观察陌生玩家的首次迷路、等待、主动改选和重复劳动比例，再按最早出现的无聊点调整。真实街区道路拓扑仍未进入可玩循环。

本轮接续已有存档，操作者熟悉实现且包含开发停顿，不能算作自然玩家的 60–90 分钟主动体验验证。Goal 保持 active。
