# SGODOT-341：0.2.14 对普通新号开放引导（GUIDE_V3_READY）

依据：用户 10-29 定 0.2.14 给普通新号打开新手引导（奕星转达）。

## 改动

- `modules/p0/p0_session.gd`：`GUIDE_V3_READY := true`。
  - 主号的每个请求都带 `x-p0-features: choose_home,guide_v3`。
  - 测试号照旧按 Test options 建号时锁定的开关走：开着建的号带 `guide_v3`；关着建的号只带 `choose_home`，是 legacy 测试号。
- 服务端不改（蒙恬核过）：
  - 引导只在建存档那一刻、按请求头定。建存档的入口是 routes.ts 的 `stateOf` 和 `reset`，两处都用 `newSave(请求头)`。
  - 美西线上 e64d4b33 的步骤表有 12 步，没有跟引导有关的环境变量。

## 影响

- 普通新号：第一个请求就带 `guide_v3`，建档后进 v3 引导。
- 老号：存档里已有 `guide`（含 `end: legacy`）就不受影响。没有 `guide` 的老存档，服务端补成 legacy。
- 重置账号（reset）：新存档进引导，这是预期的。
- Test options：开关只对之后新建的测试号生效。主号不看这个开关，一律带 `guide_v3`。
