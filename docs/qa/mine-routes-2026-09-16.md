## 实现

- 选中农场的 3D 缩略图固定在角色右侧，比例从 0.26 调为 0.195，缩小 25%。
  边缘处预留角色与模型的共同空间；相邻角色和名字拥挤时只在右侧上下避让。
  原始地理坐标、农场身份、访问与存档保持原规则。

  未处理的矿石/怪物保留，返回仍能继续；通路开启不等于资源耗尽，不因此自动重开轮次。
- 第五层只保留精英、出口及电梯，不生成矿石，也拒绝开采第五层矿石的请求。

  农场/轮次/楼层/怪物决定抽取结果，重试、重进和攻击顺序不改变结果，不接受客户端奖励字段。

  蓄力与恢复间隔缩短，击退减少 55%，挥砍不打断蓄力或冲撞。
- 修复换层后相同怪物 ID 沿用已释放模型的问题：重新绑定新楼层的点击模型，拾取时先检查对象有效性。

掉落概率、数量和存档规则以[战斗规则](https://github.com/IndieMiao/sensen-godot/blob/25b7a8a6e0574f9b0c4c97f480238e98d5d9985c/docs/product/mine-combat-2026-09-15.md)为准。
