# 修复点的 3D 收获选择

日期：2026-09-09。状态：客户端实现、headless 回归和独立 v3 包检查完成；实际触控与画面观感待用户体验。

用户已接手手动测试。本轮没有操作真机或模拟器、截图、安装应用、启动图形试玩窗口、修改现有存档或重启连接服务。

## 问题与改动

厨房花园、编织园和石窝修复后，重复收获仍依赖打开抽屉、阅读两项奖励、点击按钮。已有材料取舍发生在菜单中，3D 场景只能展示是否修好，难以让玩家通过观察决定本轮用途。

- 现在三处修复点各自展示两份可直接点选的实体收获：石料或木料、芦苇或种子、沙拉食材或洋甘菊。数量由原奖励配置读取，种子与成熟作物使用不同模型；胡萝卜含可辨认的橙色根部。
- 点击实体后先跑到可达操作点，再播放收获动作并提交原有 `harvest_journey_discovery` 命令。成功时显示实际领取内容，保持场景开放，不弹出抽屉。
- 每轮仍只能选一份，选中时的目标文字包含该限制。服务器接受后，两份可选内容一起移除，保留空托盘；新探索恢复收获。未修复、未解锁与已领取的内容不能直接领取。
- 文字固定在对应物件上，沿用随人物距离改变透明度的方式。拖动不触发收获，平移或缩放后仍按新投影点选实体。托盘加入寻路避让，并在修复、解锁后更新。
- 点击修复点本体仍可查看原面板。领取失败时返回该修复点，显示错误原因与必要的重连入口；权威状态恢复前禁止选另一份，不提前清空模型或增加库存。

变更位于 [JourneyProjects](../../modules/farm/journey_projects.gd) 与 [JourneyPlace](../../scenes/place/journey_place.gd)。没有改动服务端奖励、命令或存档结构；领域版本仍为 12，无须为本轮变更迁移数据库。
