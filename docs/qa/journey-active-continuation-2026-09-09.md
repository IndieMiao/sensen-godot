# 首顿饭之后的连续试玩与居民故事入口修复

日期：2026-09-09（上海时间）。继续当前 Goal：以 60–90 分钟主动游玩为目标，通过模拟器验证玩法、交互和 3D 表现。仅使用模拟器与 Godot，没有操作真机。整体 Goal 仍未完成。

## 试玩与发现

接续[上一轮开局存档](journey-active-start-2026-09-09.md)的版本 24，使用正常界面触控推进到版本 89。没有补资源、改时间或调用测试玩法指令；初始三株作物在上一轮开发期间成熟，不把其生长时间计入本段体验。

本段走通：收获 → 街区沿路采集 → 小馆首次沙拉与共同用餐 → 回田种洋甘菊、胡萝卜与生菜 → 制作首件花箱 → 打开苗圃侧径 → 庭院移动、旋转与保存布置。

随后主动选择了推荐主线之外的编织园：追踪 → 制作编织花箱 → 安装 → 在芦苇和种子之间选择生菜种子 → 回田补种。继续完成苗圃人物故事、叶菜委托和育苗床两阶段建设，在第二轮小馆路线分别选择芦苇包与木料包。自然成熟的洋甘菊分别用于庭院种花和制茶。

**确认并修复的问题：顶部推荐人物故事，但人物面板默认先显示重复委托，故事按钮藏在滚动区域下面。**

- 版本 88→89，顶部显示 `The host's recipe book`，当前 C1/L1 足够完成该故事。点击主理人后，首屏只有沙拉委托、备餐和换委托入口。
- 滚动一次后能够找到故事按钮。问题是优先级与首屏可发现性，不是解锁失败或故事入口缺失。
- `JourneyActivityPanel._resident()` 原先在所有首顿饭后的主理人面板中，先构建重复委托，再构建故事。
- 现在故事的前置条件与材料都满足时，先显示故事；否则重复委托仍在前。故事完成后立即恢复委托入口，不重复显示委托，不改变交付地点。

产品代码只修改 `scenes/place/journey_activity_panel.gd` 的内容顺序。没有修改服务端规则、成熟时间、经济、领域版本或存档结构。

## 时间与玩法结论

- 普通界面试玩区间：UTC `16:36:54.515–16:47:58.000`、`16:50:47.321–17:06:15.553`，合计 1591.717 秒，约 26 分 32 秒。
- 区间内 106 次成功输入，固定截图等待共 212 秒。仍包含模型思考、工具往返、控件检查和汇报；**区间总长不是有效主动游玩时长**，也不能简单减去截图等待便当作主动时长。
- `16:47:58–16:50:47.321` 上下文恢复排除；`17:06:15.553` 暂停后的调查、修改、构建与全部回归排除。暂停期间作物继续自然成熟，不把这段成熟用于证明没有等待。
- 操作者熟悉实现，属于开发者试玩。没有验证陌生新玩家继续意愿、留存，或 60–90 分钟主动内容。

已经观察到材料用途上的选择：编织园的种子或芦苇、采集点的木料或芦苇、洋甘菊用于种花、人物故事或料理。育苗床和编织园让一次制作/建设支持下一轮生产，场景变化与补给用途一致。本段没有发现必须等待才能继续的断点，但不能外推到所有种植与消费选择。

当前优先遗留：

1. **资源路线的空间变化不足。** 第二轮仍补充同一批位置，虽有实体二选一，路线安排与新发现仍有限；下一轮优先检查第三轮是否只剩机械取料，不用重复交付凑时长。
2. **普通目标缺少具体对象。** `A garden together` 等标题不直接说明地点和人物；地图的“新故事”能补充部分信息，仍有认知绕路。工程/修复追踪的指向更清楚，普通故事尚未达到同一水平。
3. **街区远处目的地缺少方向提示。** 本段要通过 `Whole neighbourhood` 才看到远处小馆；尚未证明所有新玩家都会找到该入口。
4. **60–90 分钟主动体验与陌生玩家验证未完成。** 当前仅证明这条开发者路线可衔接，并修复发现的入口优先级问题。
5. **QA 包的 Android 16 KB 兼容提示仍存在。** Android 37 模拟器启动时可确认后运行；没有永久隐藏提示，没有据此断言合伙人发布包也存在相同故障。本轮没有更新发布 APK 或原生依赖。
