## 试玩发现与修复

| 已观察的问题 | 当前行为 |
| --- | --- |
| 普通目标只有文字，只有追踪工程能使用定位按钮 | 普通目标同样可前往对应居民、工作台、厨房、修复点、设施或路线木牌 |
| 从农场或街区前往目标地点后，还要再次寻找对应物件 | 主动选择目标保留具体物件；进入后跑向它，到达后打开交互 |
| 街区缺种目标进入农场后没有定位商品 | 缺种信息跨场景保留，直接打开对应种子商品；普通入口按常规进入 |
| 地图的材料选择提示遮住已准备好的厨房花园修复机会 | 追踪目标、可修复、可交付故事、可施工优先于普通材料提示 |
| 补给站兑换只显示 `Ready.` | 成功显示实际变化，例如 `-2 wood / +2 reeds`；苗圃篮子显示具体种子或花朵 |
| 新增普通导航按钮在刚进入本地目标场景时短暂消失 | 创建物件后立即刷新目标，不再等周期更新才出现 |

停止街区跑动会清除目标上下文。手动改点普通入口也会清除旧目标，避免到达后打开先前推荐的面板。兑换失败保留原状态，不播放获得物品的成功反馈。
