# 点到点跑步移动

日期：2026-09-07。按用户要求，农场及三个旅程地点的角色移动统一改为点到点跑步，速度从 2.5 提高至 3.75，即原值的 1.5 倍。更新包已安装到 vivo 真机。

## 实现

- 共用 `PlayerMover` 改为世界坐标路点：能直达时直接到目标，遇到障碍时通过 Godot AStar 寻路，再移除可直达路段中的多余格点。
- 用引擎的线段/AABB 相交检查阻挡格，防止斜穿水塘、建筑或两块障碍的夹角。蓝图校验仍使用原来的四邻接距离，不影响内容校验合同。
- 自由地面点击保留实际落点，途中改点从当前位置重新规划，不吸回格子中心。农活和场景对象仍保留各自的操作站位。
- 每帧剩余移动距离能跨越转折点，避免因帧率或路点数量导致减速。农场和地点移动时播放已有 `run`，抵达后恢复待机或开始操作。
- 农场路径提示使用同一组世界坐标路点。
