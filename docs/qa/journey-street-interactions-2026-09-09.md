# 街区目标、居民交谈与交付回应

日期：2026-09-09。当前方向：[以好玩为先](../product/fun-first-rework-2026-09-07.md)。

本轮完成街区居民交互缺口及一处交付后作业阻塞的修复。60–90 分钟主动内容、自然新玩家的继续意愿仍未验收。

## 发现与实现

- 同一 v95 存档已有可完成的 `A garden together`，但街区初始视野不一定包含苗圃管理员。走到居民面前后，旧街区面板只显示重复花卉委托，两者还会竞争同一朵花。
- 街区现在使用居民的统一身份打开对话，支持初见、故事、赠礼及已有重复委托。推荐故事保留在重复委托上方；首次共同用餐仍引导到小馆。
- 街区常驻目标明确标出居民或地点，增加图标按钮沿现有道路跑向目标。行走中同一按钮可以停止，掉线不影响停止；开启新路线仍受连接和未确认命令约束。没有用显示标题匹配居民或传送角色。
- 故事和赠礼收到成功结果后收起面板，由居民在原地挥手回应并显示实际成功文案。交谈时相机调整可见区域，双方保留在面板上方，长反馈位于底部按钮之上。
- 模拟器进一步发现：玩家留在修缮师工作点附近时，交付成功但居民一直等待路径。现在仅在前往工作点的路径不可达时，寻找工作点 1.5 米内的可达位置，保留人物碰撞和回家路径规则。
- 修复街区居民标题读取默认地点名称时的空值错误。

主要实现：`modules/farm/journey_progress.gd`、`modules/farm/street_residents.gd`、`scenes/map/journey_street.gd`、`scenes/place/journey_activity_panel.gd`。本轮没有增加服务端规则、迁移或存档补发。

## 遗留与边界

1. 活动人物附近的命中体验：一次按观测到的移动主理人身体位置点击，实际打开了相邻备餐台；明确的对话图标可以正常交谈。保留对应回执，下一轮需区分动态观测时差与真实命中问题。
2. Android 启动：v5 覆盖安装后出现两个 Launcher 窗口，两次地图点击未送到 Godot；冷启动恢复。v6 安装前停止 App 后未复现，但根因尚未确认，不能宣布发布环境已修好。
3. Android 37 QA 包仍有 16 KB 页面对齐兼容提示，Mapbox 原生库报告 LOAD segment 对齐失败。按系统确认后可运行；不等同于合伙人此前无法使用的根因，也不构成发布兼容性验收。
4. 持续玩法仍需增加刷新路线的空间差异、沿途活动与用途选择，并继续观察最早的无聊点。本轮没有解决任意地区在线道路拓扑。
5. 本轮自然续玩的墙钟区间为 UTC 17:25:26.407–17:27:45.349，仅 3 次成功输入。此后全部开发、上下文切换、导出和回归均排除。该区间还包含工具和观察开销，不是经过确认的主动游玩时长；作物此前自然成熟也不计入本轮主动内容。
