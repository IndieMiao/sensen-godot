# 洛杉矶地图 UI 比例调整

2026-09-22，用户要求缩小地图 UI，更贴近已确认的主视觉，并在完成后提供对照检查。

## 调整范围

以360×780逻辑视口为比较基准，仅收紧地图界面的视觉尺寸、间距和标记标签。主要控件保留44逻辑像素触摸高度；圆按钮在44×44命中区域内绘制32×32圆面。

| 元素 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 城市标题字号 | 26 | 22 |
| 筛选栏宽度 | 270 | 220 |
| 筛选栏可见高度 | 46 | 30 |
| 右侧圆按钮可见直径 | 44 | 32 |
| 底部导航高度 | 60 | 48 |
| 底部导航图标 | 23 | 18 |
| 地点信息卡最低高度 | 90 | 72 |
| 地点卡标题字号 | 15 | 13 |
| 地图头像直径 | 46 | 36 |
| 标记标签上下内边距合计 | 12 | 2 |

城市下拉箭头改为随标题自然宽度排列；地点列表收窄并缩小行间距；姓名标签去掉多余白底和投影。标记避让与可见区域同步收紧。地理数据、3D角色与地标美术尺寸、账号和玩法规则未改变。

初次三栏核对发现卡片建筑插画随UI一并缩小后偏小，最后将插画容器调为64×64，使其在72px卡片中保持与设计稿相近的占比。
