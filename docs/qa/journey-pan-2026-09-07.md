# 场景镜头与地图入口真机验收

日期：2026-09-07。对应用户要求的场景小范围拖动、农场斜角视图、稳定半透明入口及地点地面点击反馈。

后续已追加[二级场景拖动与缩放的惯性、弹性边界及回弹](journey-inertia-2026-09-07.md)。当前安装包和镜头边界行为以该记录为准，下文保留本轮验收时的版本。

## 实现

- 自己的农场、访客农场和三个旅程地点共用地面投影平移，偏移半径限制为 1.6 米。拖动可从地块、图标或空地开始，松手不触发农活、移动或地点操作。镜头保持拖动后的位置。
- 农场改用正交相机，水平斜角 14.5 度、俯角参数 48 度，与附近地点的视角接近。相机按 HUD 可用区域取景；四畦全开、短屏手机上仍保留 44 像素以上的地块宽度。
- 普通农场拖动改为镜头平移；单格点击和底部批量农活保留。布置模式中拖家具移动家具，拖空地移动镜头，一次撤销恢复整段家具拖动。
- 地图入口由 108×66 的三行卡片改为 80×54 的透明触区，内部为 32 像素圆形图标及短名称，移除常驻描述、动态避让及入口连线。入口跟随世界锚点，接近显示边缘时渐隐。
- 地点图标保持 44×44 触区、28 像素视觉标记，固定在物件锚点。人物接近时平滑降低透明度，不重新排列或拉连线；重叠触区选择距离点击最近的标记。
- 地点地面点击复用农场落点反馈：可达显示绿色圆环，不可达显示红色叉号及原因。上一轮点到点跑步及 3.75 米/秒速度保留。

- 原生 Godot 测试：366 项通过，0 错误、0 失败。覆盖农场取景、拖动不触发农活、访客平移、地图锚点稳定、入口点击以及现有地点功能。日志：`output/journey-pan/tests-native.log`。
- 原生图形探针：三个地点、三个建设阶段、360×640 / 390×844 / 960×720，共 27 组通过。包括非空场景像素、导航、图标稳定、从图标开始拖动、可达/不可达落点和面板检查。`output/journey-pan/visual-report.json`；截图位于 `output/journey-visual-probe/`。
- vivo V2509A / Android 16：29 次 ADB 触控、29 次设备触摸回执。坐标来自实时 Godot 控件树和相机投影，没有直接注入玩法命令。
- 真机分别验证农场、小馆、苗圃、庭院的平移；场景平移后人物位置未变，也没有产生游戏命令。三个地点均验证了可达和不可达地面反馈，采样中的图标锚点误差小于 0.001 逻辑像素。
- 庭院空地拖动不改变草稿；花箱从 `[-6,5]` 拖到 `[-4,4]` 时镜头不变，撤销后恢复 `[-6,5]`、旋转 3，未保存临时变更。

- 真机当前附近列表没有其他可拜访农场，因此访客农场的拖动由原生测试验证；真机覆盖的是自己的农场和三个旅程地点。
