# 首餐续玩与开场材料目标修复

日期：2026-09-09。沿上一轮新存档 v21 继续，最终 v32；只使用模拟器与 Godot。

本轮修复了工作台、首个花箱和侧径缺木料时的目标用途混乱。
首餐、制作布置、资源路线和侧径已通过普通触控走通，完整 60–90 分钟主动体验仍未验收。

## 发现与修复

首餐后，玩家尚未制作花箱，常驻提示却显示 `Bistro: Find wood for Propagation beds`。
集齐两份木料后，实际下一步又变为制作首个花箱。玩家因此无法从提示建立连续目标。

原因是 `JourneyProgress.next_goal()` 在开场缺木料时调用通用 `_gather_goal()`，
后者优先选择设施的材料用途。现在这三个开场目标各自保留木料用途与当前数量，
用既有材料查找逻辑定位具体物件；资源耗尽时前往苗圃木料路线。
主动追踪的工程、聚会和已备好的首餐仍保留原先优先级。

运行时改动：`modules/farm/journey_progress.gd`。
回归覆盖：`tests/journey/test_goal_navigation.gd`。未修改经济、领域版本和服务端结算规则。
