## 撒点交接

机器可读建议在 [`density.json`](../../../tools/art/source/wild_props_422/density.json)，可执行预览在 `scatter.gd`，本次 gourd 塘实际 103 个摆件的坐标、转角、缩放、默认镜头投影与净距在 `placements-gourd-v1.json`。它是审核样稿，不是修改生产撒点代码。

- 塘边的白 / 黄 / 淡紫花与苜蓿断续成簇，两侧更密；中央开阔地、小路两侧只留少量苜蓿和贴地石子，不均匀铺满。
- 先确定该塘实际使用的资源槽位，再过滤装饰。到 **每个启用槽位中心的距离减去装饰水平包围圆半径 ≥1.5 m**；采集站位 `stand` 另保留 0.45 m。花丛也遵守此规则，尤其亚麻周围不放花。没有移动或限制任何 408 槽位。
- 每塘 2–3 组倒木 + 蘑菇 + 两件蕨类，角落组合；默认镜头左下组的整个投影须在 y≤720。前景可以放在原地面上、可走区外，保持导航、MEADOW 镜头约束不变；小路仍由刘备在可走边界前渐隐结束。
- 水中香蒲每塘 4–7 丛，整丛水平轮廓在近岸浅水内，根部示例 Y=-0.06，低于原水面 Y=0.055；丛间≥2.2 m。对比图仅为核轮廓在同一地面排开，真正塘内摆法全部在水里。
- 主键列 `[278,420,82,300]`（360×800 逻辑像素）只允许低于 0.08 m 的苜蓿；场景接入时还应按实际 UI 控件扩张 6 px 校验。倒木组按所有部件的投影检测，不只看根节点。
- 使用独立种子，拒绝不合法候选，不为凑件数侵入净空。程序可按类型用 MultiMesh 合批，小花、苜蓿、石子关闭阴影；原资源模型和导航不变。

本次使用 gourd / Willow Pond（`pond_san_francisco_01`）原生开场，示例资源为 F1 树林、F2 亚麻、L2 芦苇滩、B1 石堆；同一组实际摆位在默认镜头及全塘图中保持一致。示例共 36 组花、24 组苜蓿、14 组散石、10 株圆灌木、3 组倒木组合（12 件）及 7 丛水中香蒲。左下组合的投影下沿约 667 px，整组在快捷栏上方；最小净距的精确值见验证文件。
