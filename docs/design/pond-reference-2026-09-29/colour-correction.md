# 水色复核与修正

2026-09-29，用户指出首轮水体颜色变化仍与设计稿不符。首轮“更清澈”的结论不足以说明水色还原：可见石床和减少碎高光解决了一部分材质问题，但浅深水的色阶与空间分布仍不正确。

[设计稿／上一版／修正版：标注取样位置与色块](../../../output/pond-colour-2026-09-29/colour-comparison.png)

## 偏差在哪里

1. **深水偏青绿、偏亮。** 设计稿后方水域更偏蓝，代表样本色相约 197°，上一版约 192°；设计稿的深水明度约 54.6，上一版约 58.9。整片水因此缺少后方深蓝的沉降感。
2. **浅水偏暗、饱和度过高。** 设计稿前方浅滩带有受光水底透出的浅青与灰白，样本约 `#6FEAE7`；上一版约 `#12B1C1`，少了大量浅色成分。上一版中段到前方的蓝通道基本停留在 188–193，设计稿对应区域则约为 214–234。
3. **渐变方向错误。** 首轮水深主要由离岸距离决定，四周出现一圈相似的浅青色，中间则保持接近的颜色。设计稿具有宽阔、明亮的前方浅滩，向后方水域逐渐转深；后岸更陡、更暗，并非一圈等宽、等亮的浅水。
4. **水底与倒影抹平了颜色层次。** 首轮灰绿色石床的反射率限制了浅水亮度，又降低了蓝色通道。低分辨率岸石倒影的浅色边缘在深蓝背景上形成可见的阶梯状亮带，干扰了实际水深渐变。

编号 4 与编号 2 的 CIE L* 明度差：设计稿 **31.4**，上一版 **7.2**，修正版 **31.2**。这说明原先被压缩的浅深层次已展开。最近岸样本仍比参考偏暖，前方两个浅水样本之间的局部色差也没有完全相同。

方法：各标记位置取 37×37 像素的小块，排除暖色物件和白色高光后，计算 RGB 中位数，再换算色相和 D65 相对亮度对应的 L*。两张图池形、物件与光影分布不同，这些代表性样本用于分析色阶，不能用来推导整图还原百分比或真实水深。[原始数据](../../../output/pond-colour-2026-09-29/colour-samples.json)由 `tools/dev/compare_pond_colour.py` 生成。

## 实际修改

- 光学深度改为前方宽浅滩、后方深水盆地，并保留沿实际岸线的连续坡度；后岸局部增加水深和柔和遮蔽，避免等亮浅色环。
- 浅／中／深水使用三个连续混合的色阶，分别校准受光浅青、中段青蓝和深蓝；水底透射重新平衡红绿蓝亮度。
- 保留三张水底贴图原有 RGB 石块内容，仅重烘焙 alpha 光学深度。石块布局、真实池形、导航和地点目录没有改变。
- 岸边倒影降低覆盖权重，并以预乘 alpha 进行五点滤波，减弱浅色阶梯边；保留鱼影、焦散变形、波纹及浮漂涟漪。
