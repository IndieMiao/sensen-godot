## 对应这次反馈

| 反馈 | 实现 |
| --- | --- |
| 水不清澈 | 以真实岸线烘焙独立水底图，RGB 为石床，alpha 保存连续光学深度；水底经过折射、逐通道吸收和散射合成 |
| 岸边颜色过渡生硬 | 去掉旧材质的短距离饱和水深带，以指数盆地深度形成宽缓浅滩，再逐渐转为深青蓝；三种轮廓分别生成 |
| 浅水石头 | 每个轮廓有 147–165 块分簇水底石块，带矿物面、明暗及投影，中心留出较干净水域；它们属于水底材质，不产生碰撞 |
| 保留游鱼 | 三条轻微摆尾的鱼影；轨迹从各自实际多边形内部取点，预留整条鱼及摆动范围，观赏鱼不产生奖励 |
| 石头过圆且曝光过高 | 岸石加入宽顶、斜切面、软化边角及矿物微表面起伏；降低暖色石材反照率和镜面反射 |
| 荷叶与花缺少厚度 | 系统鱼塘使用封闭圆盘几何、弧顶、圆唇和可见侧面；花瓣加厚，粉色分层，水底接收偏移柔影 |
| 焦散只是平移 | 周期光网由多组不同方向／相位波形持续弯曲、伸缩，亮度也随波改变；并非仅对 UV 加时间偏移 |
| 树细节 | 原来的三团长树冠改为 13 团圆润树冠，增加渐变树色、树皮、分枝、弯曲收窄的根部与低矮根节；六棵树共两个批次 |
| 高光与波浪太碎 | 取消高频波纹及第二层材质镜面高光；以稳定随机分布的圆润光斑和柔光晕沿波闪烁，保留浮漂涟漪 |

水底和焦散贴图的确定性生成器为 `tools/art/bake_pond_bed.py`（NumPy、Pillow）。三张水底图均为 768×1024 RGBA，光网为 768×768，开启 mipmap；深度 alpha 不做透明边缘修补。水体仍使用单次不透明合成，避免移动端透明排序和屏幕深度取样差异。
