# Journey 全界面游戏化改版

本轮采用用户图 6 的奶油色立体面板、蓝紫边缘与青绿按钮，结合图 5 的背包结构。在原生 Godot 客户端内重做现有界面；真实地理农场、作物、水面、人物、换装和矿井继续使用现有 3D 内容。视觉设计与运行验证分别记录，设计稿不能证明客户端已发布。

## 设计来源

- 用户提供的六张参考保存在 `references/`。图 6 是风格目标，图 5 是背包布局原型，其余图片用于定位当前操作和遮挡问题。
- 按用户要求，经 Sensenjoy API 的 `gpt-image-2` 模型生成农场、背包、次级界面三张协调设计稿，以及面板、按钮和城市插画素材。调用使用 imagegen 附带 CLI；密钥仅从环境读取。
- `prompts/` 保留实际提示词，`generated/` 保留设计板，`assets.json` 记录提供方、实际输出尺寸、SHA256 与透明处理。概念稿中的物品、价格和地图位置为示意，实际客户端使用真实存档和既有规则。

## 实装规范

| 部分 | 本轮处理 |
| --- | --- |
| 面板 | API 生成 PNG 九宫格拉伸；奶油白内面、蓝紫软边。紧凑子卡片使用统一原生主题。 |
| 按钮 | API 生成青绿按钮与统一色相的紫色变体；按下、悬停、禁用和焦点状态一致。 |
| 字体 | 已有 Nunito 750，简体中文使用已有 Noto Sans SC 后备，保留完整中文覆盖。 |
| 图标 | Phosphor Icons Core 2.1.1 的圆润实心图标，MIT 许可证与映射随资源保存；未映射图标使用已有 Lucide。保留现有物品和作物美术。 |
| 农场 | 44px 顶部信息、聚合目标提示、52px 底部操作区；种子仅种田模式展开。允许自由镜头离开角色，真实装扮头像点击回位。 |
| 背包 | 紧凑页签、物品详情条、搜索/分类/排序、五列物品网格；角色页保留真实 3D 装扮和六个装备槽。 |
| 弹层 | 统一注册可见模态界面，联机/语音悬浮入口随弹层收起；连接继续保持。 |

## 验证与发布边界

当前实现状态、截图比较与未解决问题见仓库根目录 `design-qa.md`。原生图库使用隔离的展示数据和拒绝写入的传输；交互测试另使用隔离 HTTP 服务。测试不会出售、消耗或重置真实玩家资产。

本轮只修改客户端 UI 和镜头交互，无服务器领域迁移。设备更新保留 `com.sensen.journeypreview`、原签名、身份和用户已确认的新地理农场。是否上线、安装及对应校验值以最终 QA 记录为准。
