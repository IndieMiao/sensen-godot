# SGODOT-424 海鸥 / 渡轮动作 v1

黄忠。以已过双审并合入的#815 / 996528d3为基线。动画为资产场景，接入由马可波罗/程序负责。

- gull.tscn：284面单网格，原preen/spread形变保持，新增turn_head；idle 8.5s循环，
  实测静止占比67.1875%。不飞、脚点不动、根位移0，不autoplay。
- ferry.tscn：引用原近远档，BodyRig每4s极轻微起伏，Y范围[-.020,+.020]m，根位移0；
  52面旗帜在船尾外侧(11.2,1.48,2.5)，0.80×0.45m旗面，每2s轻摆，深度幅度≤.035m。
  两档及.import与#815字节一致；近档加旗5196面、远档加旗1532面，55m切档同步起伏。
- 三只海鸥独立实例、同一个外链动画库，播放时钟/形变权重各自独立。演示以固定随机种子
  在8.5s的三个区间取offset约2.00/4.95/6.96s；接入每次创建时随机一次，不在每帧重置。
