## 本轮改动

1. 课桌、圆凳、书柜、矮柜改暖木色。图集 `oak / oak_light` 分别改为 BB9C78 / C0A582；这些是底色，经过现有灯光和 ACES 后，受光课桌面六点实测约 EACC9B–EBCE9D，接近要求的 E5C6A0。背光面更深，桌凳仍与地板分出明暗。`wood_mid/oak_edge` 与大厅底座、地板收边共用，保留 v1 色；讲台象牙白面板沿用黄忠原件。
2. 两盏吊灯移到课桌区两侧，局部位置 `[-1.80,2.96,1.25]`、`[2.40,2.96,1.25]`；自身网格不变，随灯移动两盏原局部光，光色、能量、范围不变。默认 43° / 6.72 m 下，两灯与黑板、讲台、后角书柜的屏幕包围盒均无交叠。
3. 后角柜保留原 .90×.65 m 占地和位置，高度 2.30→**1.50 m**，四层减为三层。书本仍用原蓝、绿、砖红等颜色。顶部新增一盆现有 small_plant 实例，底 Y=1.58（地面 .08 + 柜高 1.50），没有新增植物网格/图集。
4. 地板 CF9B66→C89E73，略降橙色饱和度，收向浅蜂蜜色；直木板纹样及 UV 不变。墙、护墙板、窗和灯光环境保持 v1。
