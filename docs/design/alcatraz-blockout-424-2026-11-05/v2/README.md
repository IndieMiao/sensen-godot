主楼不含铁栏、囚室、铁丝网或瞭望哨。静态海鸟和渡轮没有交互。四层花园用较暗灰阶，铺装较亮，台阶和道路带栏杆；码头木板缝下设连续碰撞底板。Map 标记移到码头左侧，避免遮住出生角色。

## 区块、预算与验证

`DockZone`、`TerraceZone`、`SummitZone` 三个 Node3D 分别持有本区模型、碰撞和导航区域，连接同一个私有导航地图。当前整体加载；以后程序可以按区块接入加载策略。

[asset-validation.json](asset-validation.json) 核对 GLB 包围盒、UID 和被测文件字节。当前 **24 个 GLB，30,450 唯一三角面、34,138 摆放后三角面**。真实运行节点统计（包括角色、主海面及独立远景）：**42,502 三角面、46 个 surface**，低于 300,000／80 的上限。surface 是网格表面数，不包含阴影等额外绘制次数。

[verification.json](verification.json) 记录 **Godot 4.7.2 / Vulkan Mobile / gs66 RTX 2060** 的实际检查：

- 三个区块导航存在、完整路线到达半山和主楼、逐段跟随及约 120 m 路程。
- **6,907 个导航格**全部有合理高度的实际碰撞地面；花园／海面／建筑内部不可走。
- 6.72 m 镜头、43° 投影、未缩放的角色及其实测高度；拖拽、双指缩放、保留缩放、恢复和 Map 退出请求。
- 三只海鸟与渡轮无碰撞交互；开场左上检测到桥的橙红像素。
- 三张 360×800、两张 1000×1200 均尺寸正确且无洋红诊断背景露底。
- 含角色／远景的面数和 surface 满足预算；运行资产、场景源码与被测隔离副本逐文件字节一致。

扩大后的场景曾触发 Godot 默认 **4096 个多边形**的路径搜索上限，返回尚未到达主楼的截断路径。本场景的 `find_path()` 改为按本岛导航规模设置搜索上限，并核验目标到达；没有修改共享寻路模块。失败探索日志保留在本机 `output/alcatraz-424/v2/`，不作为最终验收结果。

源文件、生成、隔离导入与复核入口见 [制作说明](../../../../tools/art/source/alcatraz_island/README.md)。新增导入 UID 均由 Godot 生成；旧 v1 退役模型及对应 `.import` 已移出当前套件，历史提交保留。所有 Blender／Godot 调用使用 `flock ~/gs66-render.lock`，检查完成即退出。
