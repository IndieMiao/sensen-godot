## 留白依据与检查范围

使用b1真实360×800布局：主键圆心(300,624)、半径44；切换键圆心(300,544)、半径24；快捷栏(12,708,336,68)。来源固定头、UI文件和已提交实测记录见 [hud_contract.json](../../../../tools/art/source/alcatraz_island/hud_contract.json)。主键／切换键组四周预留12px，检查矩形(244,508,112,172)；快捷栏右半含余量为(168,696,192,104)。镜头仍43°／6.72 m，角色与相机比例未改。

检查导入高件的投影轮廓与预留区交集，包含路灯、标牌、树、废墟、主楼、两塔。渡轮只检查船舱／烟囱等上部结构的实际导入三角形，避免整船大包围盒把低船头上方的空气算成高件。低栏杆、石沿、长椅及地面可出现在该区域。

开场／半山／主楼前和20个每约6.5 m的停步画面全部通过；沿实际跟随行走每约0.5 m检查，共 **234点**，无侵入。另用赵云#802已交的灯、牌与6.3 m树冠外包围复查点位，不用缩小正式件来套占位。当前正式小件尚未换入，之后仍须核实际造型、材质和UI安全区；本轮结论对应上述默认镜头、路线及固定UI布局，未把自由拖镜头或其他UI布局算作已验。
