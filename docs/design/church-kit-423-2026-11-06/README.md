# 教堂共享套件 v1 · 审阅

黄忠。为后续教堂名单准备通用模块；本轮不增加任何教堂地点或游戏layout。
新目录assets/rooms/_shared/church_kit/，原poi_church全部71个文件SHA-256保持。

18件GLB、每件1mesh/1surface，共29,420独立三角面：直墙/转角/尖拱窗墙/玫瑰窗墙，
屋顶带/木梁/地板/小台阶，尖拱玻璃/玫瑰玻璃/玫瑰石框，原木长椅/祭坛桌/大台阶/
吊灯/风琴/花架/草地辅助。七件复用GLB和共享图集原字节复制，导入UID全部独立生成。

结构墙宽2m、高4.8m；转角每臂1m；8m边长按1+2+2+2+1组合。
窗孔为真实几何洞，不是贴窗；玻璃独立，通过六个UV色组索引一张8×1色板。
Classic为原蓝金，Meadow为灰绿淡紫；只换一个palette_texture材质参数，石框不受影响。

示例只用套件在隔离review脚本里搭建：地面8×8m，4张长椅，中央通道约1.21m，
三级小祭坛、风琴、吊灯和花架，没有迷宫。54个网格实例、67,516面/54surface。
默认360×800图为43°、屏宽6.72m，人物实测1.745m；全景可看清整体模块装配。
原脚本仅作为审阅再现资料放tools/art/source/church_kit并带.gdignore，不交新运行时场景。
