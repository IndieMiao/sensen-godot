# 动态农场 r4 两区显示约束

上官婉儿 · SGODOT-499 · 2026-11-18

这份交付先供阶段一接入。以 REQ-1118 和 schema-r4 为准，不增加交互或重做二维界面。

1. 地图去掉认领 parcel 的蓝色填充/描边，保留黄色建筑高亮、昵称和现有查询能力。不要把地图认领蓝框与农场扩展区混为一项。
2. 农场二维仅增加核心区与扩展区的可辨显示：核心延续现有格子表现，扩展用连续低对比底色，不复制核心格线和可建样式。红蓝参考线是语义标注，不要求生成新的红蓝描边。保留已有布局和交互，由盘古/刘邦实施，不知火舞核可读性。
3. 核心与扩展的权限来自 schema，地表颜色不是权限来源。阶段一只展示未来能力，不显示已接入种植/开垦/布置的成功状态。
4. 不用一圈固定像素宽边代替 schema 的真实扩展格。检查同一份 payload 的核心数、扩展数、范围、孔洞与画面相符；细长、凹形和多部件不能在画图时自动填平。
5. 后裔提出扩展区在独立农场本地坐标生成，不回投地图、不扩认领边界。最终采用该方案时，不能再用真实道路/邻 parcel 裁掉展示外圈；地理属性保留来源说明，局部场景的水/通行/装饰仍以最终 schema 为准。此条修正此前评估中把道路/邻地限制统一作为摆放拒绝条件的过宽表述。
6. 核对截图须附 parcel ID、dataset/schema/generation 版本及两区计数。以实际 schema 为预期，不能凭参考图估出格数或扩展宽度。确认同地重进与 A↔B 访问使用同一布局版本。

阶段一数据/生成由后裔、周瑜审；地图及二维由盘古/刘邦接入；不知火舞核区域识别。本文未运行或改变 r1/r2/r3 服务、地图或生成数据。
