# UI语义重构约定

本轮完整重构授权来自用户2026-10-06反馈。保留奶油色、圆角、Nunito和既有场景/图标；信息架构与字体/对比度按本轮目标调整。

1. **标题只回答“是什么”**。数量在右侧数值槽，状态用独立标签，功能/效果另起一行。名称中不可拼接费用、倒计时、容量、按钮提示。
2. **行动前必须知道的信息常驻**：主要作用、实际花费、所得、替换损失、邀请过期、不可撤销后果。普通限制和重复规则进详情/失败toast。技能门槛仍保留可理解的门禁说明。
3. **命令、导航、取消三套形态**：执行主按钮深绿填充，一屏最多一个；信息入口是无填充的文本+右箭头行；取消/返回是安静文本。破坏性确认用专门危险样式，且损失在按钮上方可见。
4. **可读性优先**：通用360宽审阅稿正文14、标题20、说明至少12。复用原稿紧凑组件时，Compact核心标题14、核心效果12、核心动作≥12，分类与数量10–11；仅QuickSlot 辅助物品名、GearSlot 只读标签、Profile ID、社交统计标签、集合／图鉴格 caption允许9，且须有实际截图依据，不推广到全局辅助文字。核心按钮与导航触区≥44；不能靠统一缩小字号补救错误布局。
5. **长内容使用内容区滚动**，费用与执行按钮固定底部；不将标题、正文都缩小。库存仍五列、装备六槽，主要说明集中在选中项详情。
6. **不伪造交互**：分镜快进、假“查看升级后状态”等只在画板审阅导航，不出现在玩家UI；不靠原型按钮增加关系、时间、库存。例外/未定规则在画板外注释。
7. **组件化而非整页截图**：Shared HUD、Sheet、ObjectHeader、ItemRow、Quantity、Effect、Fact、NeedTile、Command、NavigationRow、Toast、InventoryCell、GearSlot。场景图片可复用，完整UI图片不进入交付帧。

8. **未知库存保持未知**：`have:null/undefined` 使用中性 NeedTile/check 与 `Required ×N`，不得改成虚构的0/1，也不得用绿色表示材料满足。费用与执行仍由实际条件校验。

288张主卡与23张独立业务补态已有分批云端写入回执；写入、结构检查、实际截图、原型点击和游戏结算分别记录。本地offline仅Avatar三张正式页同步专属布局，其余含保存失败补态未完整同步全部视觉精修，仅作结构审阅；Figma与实际PNG作为视觉依据。
