# 参考页真实控件补齐

2026-10-06。原 `states()` 只输出标题、说明与列表，虽然保留了 stateExamples 的文字，却没有保留这些参考页真正要表达的操作控件。新增 `figma-plugin/legacy-reference-fixes.js` 仅处理以下 6 张参考页；其他原生状态示例继续用原渲染器。

| 页面 | 原渲染遗漏 | 本次原生示意 |
|---|---|---|
| FISH-2 | 咬钩缩环、Hook 控件；垂直收线条、绿色安全带、鱼影；64% / 100% 进度环 | 原生椭圆/弧形的 Hook 窗口；可编辑收线条与安全带、复用鱼图标；三个进度环变体，按三阶段排列 |
| CTRL-1 | 浮动摇杆外圈/内圈、按压方向、安全框 | 真实摇杆 idle/moving 两态；场景内 40% × 45% 虚线安全框；源场景图仅作背景 |
| CTRL-1-2 | 最远/最近取景差异、回中示意、安全框 | 同一源场景图的 FIT/FILL 取景预览；安全框；回中路径与 0.6 s 标注；明确为参考示意，不宣称精确运行相机投影 |
| HUD-1 | 实际 HUD、Today、主行动圆键、切换键、摇杆、5+Bag 快捷栏 | 复用 HUD、SceneAction 与源快捷格；补独立 Today 字段和摇杆实例；仍保留源尺寸说明 |
| HUD-1-2 | 正常/低/危急/超上限的实际色条、主行动四态、位置芯片 | 四个原生体力条变体；正常、免费、不足、按压四种圆键示例；三种位置事实 |
| STATE-ICONS | 14 种状态只剩文字，无可修改徽标 | 14 个共享状态徽标变体，复用源图标；倒计时用可编辑弧，环态独立；名称/用途在旁边 |

组件补件复用现有字体、颜色与间距 token。新增主件为 ReferenceHook、ReferenceReelMeter、ReferenceToday，以及 ReferenceCatchProgress、ReferenceJoystick、ReferenceEnergy、ReferenceStatusBadge 四组变体。参考页保留纵向滚动查看所有状态；没有添加“继续”或假结算按钮，也不把审阅板当成玩家页面。

`legacy-scene-fixes.js` 同时可使用 ReferenceJoystick。原 farm.html 的显式摇杆是中心 (300,1600)、外圈260、内圈120、偏移(40,-40)，在360页按1/3归一；新版主件140内外圈130/60按2/3缩放，实现外圈86.67、内圈40，与圆形主行动和快捷栏避让。只有源 FARM-1 的按压态明确显示 moving；当前 world 卡使用 neutral，若显式禁用移动则不显示。厨房和地图不进入这条 world-action 分支。

本文件记录源代码补齐，不是云端已执行或视觉通过证明。主代理需要创建新主件并定向重建上述 6 页后验收。
