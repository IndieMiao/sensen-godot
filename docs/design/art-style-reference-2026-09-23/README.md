## 美术风格
- 造型：圆润、厚实、玩具感；倒角大、几何简化；角色 Q 版大头；物件相对地形略放大保证小屏可读；元素间距清晰不拥挤。
- 材质：哑光/半哑光软塑料或黏土质感，低-中细节手绘/渐变贴图，倒角吃高光；水面干净粉蓝半透明；图标像带白边投影的 3D 贴纸。
- 配色（明亮、暖、低饱和粉彩）：奶白 #F7F5EE / 地图米色 #EADFCB #D9CDB8 / 草绿 #A9D982 #7FC66A #DDF4C8 / 水蓝 #9EDBEF #74C7E5 #C8F3FF / 沙土 #DDA36F #E8BE82 / 暖石 #B98565 #C59A76 / 冷石 #8796BF #9B87B5 / 屋顶橙红 #D96E3F #E88A4B / 金色点缀 #FFB13B #FFD36A。
- 光影：柔和全局光、强补光、左上暖主光；短而虚的接触阴影；缝隙 AO；只有发光物有轻微 bloom。
- 描边/后期：不用黑色描边，靠倒角高光、AO、轮廓明暗分离；高亮度、低对比、柔和饱和。
