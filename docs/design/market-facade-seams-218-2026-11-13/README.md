# SGODOT-218 · 两套集市排屋接缝技术修正

给4个通用v2、8个旧金山GLB各加左右两条退后衬墙，遮住4 m开间之间的亮缝。每栋只增24三角，仍为1 surface。原模型不拉宽，原屋顶不外伸；所有原顶点、法线、UV、顶点色、索引、材质和节点逐项完全一致。layout、摆位、碰撞、锚点、导航、远景与程序均不动。

## 做法与预算

主体墙实际宽3.92 m，边缘装饰/檐口最大宽3.96–3.99 m。衬墙从|x|=1.94 m（藏入原墙）向外接到**原模型最外边+3 cm**；加0.1 mm搭接余量，防止直角相接经过float32变换后只接触不覆盖。新包围宽约4.0202–4.0502 m，正立面原几何保持原宽。

原正墙z=1.25 m；衬墙正面左z=1.228、右z=1.230，后退22/20 mm，邻接两条衬墙之间再错开2 mm，避免同色或异色衬墙自己共面。背面z=-1.245，顶到各自檐口下5 mm，颜色为本栋墙色的80%线性RGB。原屋顶所有顶点保留，近景/移动复查没有要求继续外伸；没有修改同平面屋顶造成重叠。

## 平移视频与漏缝检查

[26秒原速视频](market-facade-pan-360x800.mp4)：360×800、30 fps，先旧金山、再通用，各沿西排→内角→北排连续平移12秒，开段各停1秒。镜头目标移动约2.233 m/s；保留原生角度/缩放，独立审阅脚本暂时停用跟随驱动以允许平移，不改正式程序。Godot按固定30 fps录帧，MP4仅裁掉初始化段、重置时间戳，无加速/减速。共780帧。[编码与哈希](video-verification.json) / [帧时序](video-timing.json)。

已查看覆盖全片的52张抽帧及各接缝近景，未见贯通天空的亮缝；不是实机帧率验收。为避免只凭视频抽帧漏掉细缝，又对真实GLB的每处缝横向±2 cm、间距1 cm，高度0.15–6.00 m、间距5 cm发射线。这个高度覆盖共同墙段到低檐下，高低屋顶错层上方的正常开放天际线不被当作墙缝。

每套每个方向4,130条射线（7缝×118高度×5横向点）：

| 变体 / 方向 | 修前缺少附近墙体的射线 | 修后 |
|---|---:|---:|
| 旧金山，正对墙面 | 3,126 | **0** |
| 旧金山，45°/33° | 0 | **0** |
| 通用，正对墙面 | 4,083 | **0** |
| 通用，45°/33° | 534 | **0** |

旧金山在45°采样下原侧墙已遮住大部分缝，因此没有把其修前计数说成可见漏光；正对墙面的测试覆盖更容易穿缝的情况。修后全部方向均有局部实体，防止移动中的子像素采样穿透。[逐点检查](joint-rays.json)。
