1. **全景构图：结构问题已修复，视觉仍有差距。** 保留三穹顶天文台、喷泉前庭、星形广场、咖啡露台、台阶和森林边框；重建穹顶分格与顶饰、石材层次、拱窗、入口、咖啡亭屋顶和细节。原坡地的固定点迭代不收敛，把部分树基底错放了约129像素；改为相机射线与高度场求交后，明确描点的树基底投影误差小于0.04像素。此数值仅衡量树基底，不能当成整图还原率。远景城市、山坡自然细节和手绘材质质感仍低于设计稿，不能称为逐像素复刻。
2. **近景模型：可用作继续开发的真实资产。** 修正咖啡亭屋顶、铺装与方尖碑的反面；圆柱顶盖不再与墙面错误平滑。修正实心盆底遮住水面的错误，使用真实凹槽水盆与分层水面；补充入口构件、拱形窗、穹顶细线与冠饰、屋顶铺装、咖啡亭斜屋面、杯具、凳腿和花池。模型为Blender生成的真实GLB，源脚本保留命名构件；地面、植物与建筑独立，未把设计图贴成场景背景。
3. **手机操作：可运行预览，正式接入另行处理。** 点击行走，自由拖动、缩放、回到角色、总览；行走不自动带动相机，拖动释放不触发行走。重建主台阶、西平台和咖啡露台通路；修正台阶边缘断连、长椅圆形碰撞过大、餐桌把凳子间空隙一起封闭、围墙跨越入口等问题。场外点击停止于可达边界。独立预览使用不透明背景，远景淡出到一致的雾色，避免沿用地图透明窗口而露出Android桌面。当前仅有独立预览与测试入口，没有在线会话、地标传送、奖励或存档迁移。

## 运行与再生成

双击 [打开场景预览](../../../tools/dev/open_landmark_art.command)。它创建隔离预览项目，禁用网络自动登录并使用独立数据目录。不要沿用原文档中直接从游戏主项目运行预览的命令：原项目的 Net autoload 会自行登录。

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python tools/art/build_griffith_observatory.py
tools/dev/open_landmark_art.command
```

`-- --architecture-only` 可更新建筑与咖啡亭，`-- --water-only` 更新喷泉，`-- --navigation-only` 更新通路、地形与平台。完全重新生成时使用上面的默认命令。

- 建模与布局：`tools/art/build_griffith_observatory.py`。
- 面朝向、顶点色与 AO 导出：`tools/art/landmark_kit.py`。
- 真实资产与导航：`assets/landmarks/griffith_observatory/`。
- 运行预览：`tools/dev/landmark_preview.gd`。
- 原版脚本、GLB、布局和shader完整留档：`output/griffith-rebuild-2026-09-23/original/`。
