# 风格化泡沫

按用户要求，仅参考 [Ameye《Stylized Water Shader》第 5 节 Foam](https://ameye.dev/notes/stylized-water-shader/#5.-foam)。已读取 Surface foam、Intersection foam 的文字、节点图和示例视频；没有采用文章其他部分的水色、反射、折射或波浪实现。

## 实现

- 接触泡沫：根据当前 12 个固定地点实际岸石网格与水位 `Y=0.055` 的交线，离线生成 384×512 距离图；同时保留原岸线距离。泡沫贴着真实石头水线和岸边，向水中逐渐破碎、淡出。
- 水面泡沫：少量较淡的碎线分布在距接触边界 0.95m 以内，并避让活跃鱼漂附近。池塘中部不铺满泡沫。
- 共用一张原创 512×512 RGB 泡沫贴图：R 控制圆润的边缘破碎，G 提供水面碎线，B 控制疏密与宽度。缓慢平移加局部扰动，阈值使用屏幕导数柔化。
- 按文章 Overlay 子图的透明度混合思路，泡沫叠入当前水色；泡沫覆盖处提高粗糙度、降低镜面及高光穿透。既有水面参数、焦散、鱼漂波纹保持原设置。

默认接触宽度 `0.14m`、接触不透明度 `0.60`、水面不透明度 `0.16`。`foam_strength=0` 可关闭全部泡沫用于对照。没有新增投影相机、屏幕深度读取或几何；每个水面像素增加距离图与泡沫图两次采样。新接触图只需加载当前地点的一张。

## 资源重建

若岸石几何或地点种子改变，需要重建接触图；水位改变时还需同步导出工具中的水位值。先准备现有离线 pond preview，再执行：

```sh
POND_ADB_PORT=5054 tools/dev/pond_art_godot.sh --headless \
  --path output/pond-reference-2026-09-29/project \
  --script "$PWD/tools/art/export_pond_foam_contacts.gd" -- \
  --out=res://../../pond-foam-2026-09-30/contacts.json
python3 tools/art/bake_pond_foam.py output/pond-foam-2026-09-30/contacts.json
```

Python 需要 NumPy、Pillow。导出工具要求离线项目设置，并检查没有网络启动；生成器只写 foam 资源，不重建目录、导航、石头或水底图。`assets/ponds/art/foam/manifest.json` 记录地点、种子及原始岸石网格哈希。接触图使用线性过滤、不生成 Mip；泡沫纹理生成 Mip。未知自定义地点没有专属接触图时，回退到现有岸线距离。

首轮较尖、过连续的白边已收窄，并加入圆润噪声和疏密变化。最终画面与交付见 [QA 记录](../qa/pond-foam-2026-09-30.md)。
