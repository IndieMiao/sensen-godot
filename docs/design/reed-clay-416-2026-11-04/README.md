# SGODOT-416 · 黏土顶点色 v1.1

【黄忠】按不知火舞 `1aa399b8` 调整黏土颜色。芦苇 v1 已通过，本轮未改芦苇，也未重拍 L1。
只改陶土、土砖、坑底和坑内沿的顶点 RGB，草边与木铲颜色不变。

| 顶点色（sRGB） | v1 | v1.1 | HSV 饱和度相对降低 | HSV V 降低 |
|---|---|---|---|---|
| 陶土主色 / 土砖 | #C48A4D | #B27A5A | 18.57% | 9.18% |
| 陶土亮部 / 土砖亮部 | #D5A063 | #C28D6D | 18.14% | 8.92% |
| 坑底 / 陶土暗部 | #AC713E | #9D674B | 18.33% | 8.72% |
| 坑内沿 | #98663D | #8A5D46 | 17.69% | 9.21% |

主色 hue 从 30.76° 移至 21.82°，偏红褐 / 赭色；比鱼笼珊瑚红 #E07A5F 更暗、更低饱和。
这些是顶点色值，游戏灯光后的截屏色会变化。两张 v1.1 图均附上述改前 / 改后色块和数值：
`SGODOT-416_reed_clay_v1.1_seven_resources_43deg.jpg` 与 `SGODOT-416_reed_clay_v1.1_clay_F2_43deg.png`。
F2 保持原生 360×800、默认 43°，名字条 / 切换键布局不变，外圈间距仍为 21.78 px。

逐字节与批准头 `10bf406e` 对照：GLB 仅指定陶土顶点的 RGB 字节变化，几何、法线、索引、材质、
alpha、木铲 / 草边颜色均不变；552 面、1 surface、1.180 × 1.092 m、含铲高 0.484 m 保持。
两个 .import、芦苇 GLB / blend 及 manifest 其他条目未变。源文件颜色和生成器同步。
20 项颜色 / 不变性检查、51 项资产检查、53 项源检查、20 项 Godot 检查通过。
完整记录见 `SGODOT-416_reed_clay_v1.1_validation.json`，附件清单为 `media-manifest-v11.json`。
