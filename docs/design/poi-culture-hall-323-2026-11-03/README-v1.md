## 源文件

完整源`tools/art/source/poi_culture_hall/culture_hall_v1.blend`含18个家具/灯/展陈摆位、8个壳摆位和运行时挂点，各摆位保留命名部件；模板在同文件“Editable module templates”场景。黄忠的详细源和脚本原样取入`tools/art/source/poi_culture_hall/props/`，需由供应人修订。
