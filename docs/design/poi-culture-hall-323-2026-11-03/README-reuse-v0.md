- 两只壁灯复用 Clothing Store B 的 `KIT_wall_sconce` 原几何，映射黄铜/乳白色块，背板中心贴墙，视觉中心Y=2.25。相对灰盒改的是原点与挂墙方向，地面布局不受影响。新增两盏无阴影暖光，墙上可见暖晕，附开关对照。
