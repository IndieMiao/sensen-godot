# 双层焦散的移动端整合

用户提供 [Veltrynox 焦散文章](https://veltrynox.github.io/caustics.html)及 `PS/CausticsProjector` HLSL 后，要求整合。本文依据用户贴出的代码；没有依赖未提供的 `WaterCommon.hlsl`。

## 与现有池塘结合

当前水面使用正交相机，水底颜色与光程深度来自 `basin_bed` 图集。将双层纹理、形变和 Mip 柔化并入 `pond_water.gdshader`，沿用既有水深、岸线、光照和材质输出。

| 原示例 | 本项目实现 |
| --- | --- |
| 独立体积投影、场景深度采样与位置重建 | 在现有水面 pass 内计算，复用图集深度 |
| 两层各采 RGB 三次 | 两层各采单色一次，不编入色散路径 |
| 调用外部波浪函数获取扰动 | 从已有两次波纹纹理采样的 Alpha 读取平滑扰动 |
| 两层直接取 `min` | 保留 70% 主光纹，混合 30% 交叠光纹，避免只剩碎点 |
| 固定 `_BlurSteps` 作为 LOD，并同时除亮度 | LOD 综合屏幕导数与水深柔化，亮度独立 |

主层 UV 速度为 `(0.016, -0.009)`，第二层为 `(-0.013, 0.011)`；第二层使用旋转及 0.93 倍缩放。两层分别沿平滑扰动的正向和反向变形，使光纹在运动中弯曲、伸缩并改变交叠亮度。

`pond_ripple_field.png` 的 RGB 高度／法线数据与 `7abcbc4` 逐像素一致。生成脚本在 Alpha 中烘焙独立低频带；运行时复用原有采样结果，不增加扰动纹理采样。这样既保留已有高光与 30% 法线，也避免把高频法线梯度带来的褶皱引入焦散。

默认参数：`caustic_scale=0.22`、`caustic_distortion=0.09`、`caustic_softness=1.2`、`caustic_layer_blend=0.30`、`caustic_strength=1.0`。水深衰减仍为 `exp(-depth * 1.35)`。

## 成本与验证边界

相对整合前的弱法线版本，焦散从一次纹理采样增至两次；移除专门用于焦散的七次正弦／余弦计算，增加屏幕导数、点积和一次 `log2` 用于选择合理 Mip。没有增加场景深度采样、投影几何或绘制 pass。这是静态工作量对比，不能由此推算 GPU 毫秒数。

波纹 PNG 从 268,168 增至 346,044 字节。Alpha 不增加采样指令，但 RGB → RGBA 的像素存储并非必然免费；实际 GPU 存储取决于后端格式，不能把 PNG 大小当作显存。512² RGBA8 加完整 Mip 的未压缩数据上限约 1.33 MiB。

旧的 layered 版本保留于 `pond-water-layered-v1-20260930`，弱法线版本保留于 `7abcbc4`。验证图像、Android 录像与运行记录见 [QA 文档](../qa/pond-caustics-mobile-2026-09-30.md)。
