# SGODOT-424 · 远景与双塔 · v1 独立模型预看

黄忠。按上官婉儿派活负责七件资产，主体岛屿由马可波罗制作。
**当前开场验收与最终建议坐标待 v2 坐标系对齐，本文和附件不声称已完成这两项。**
424 核对评论 `a1b86c07`；正交投影约束说明 `ae4cdbf8`。

两塔按真实尺寸：灯塔 15 m，白色石质塔身、暖色灯室；水塔 12 m，锈红木铁结构。
灯塔近 / 远档 3,262 / 830 面（25.44%）；水塔 3,546 / 774 面（21.83%）。
近远档均保留同一底部中心与外包围，水塔远档仍保留开放斜撑；没有监狱铁栏、铁丝网或瞭望哨。

三件远景使用低面数卡片 / 浅浮雕几何：橙红金门大桥 1,524 面，城市天际线 1,201 面，山丘 120 面。
天际线包含泛美金字塔与赛富时大楼的轮廓。全部七件合计 11,257 面、7 surface，低于 4 万面预算。
单次摆放只使用两塔各一个档位，实际绘制比该合计更低；全岛 / 一屏预算仍需在主体场景中量取。

每件独立 GLB，线性顶点色、哑光、无贴图、无骨骼 / 动画。原点为底部 / 外包围中心，Y 向上、+Z 正面。
导入脚本仅打开顶点色 / 哑光、关闭远景投影，UID 全由 Godot 生成。
文件都以 `alc_` 开头，并使用独立 `alc_far_manifest.json`；没有改主体的 layout 或 manifest。

附件：两座塔分别近远档并排、两塔与 1.75 m 人物同框、三件远景轮廓预看，以及实际 GLB 和 Godot 检查报告。
最长边 ≤1500 px，桌面 Mobile/Vulkan；所有生成、导入和实拍通过共享 `flock ~/gs66-render.lock` 串行，完成后退出。
