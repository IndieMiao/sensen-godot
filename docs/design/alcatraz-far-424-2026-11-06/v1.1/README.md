## 实拍方法和结果

隔离工程直接读取该头的 `scenes/landmark/alcatraz_island.tscn`、地形、相机、FarZone、shader、导航与 UI，
只换本包七个 GLB，并按已确认的单档约定移除三张卡片的 `lod_group` 和三组远景 LOD。
不修改宿主脚本、不修改位置或镜头。主体文件和镜头 shader 的 SHA-256 校验记录在 validation。
移除 LOD 的 layout 变更只发生在 `output/` 中，正式合成由马可波罗在其分支完成。

开场仍为出生 `(-22,1,19)`，43° 正交、yaw 14.5°、宽 6.72 m；原目标点和相机位置与 layout 一致。
已拍原生 360×800 图，橙红金门桥在左上上缘清楚可见、未被标题全盖。
另附桥局部 4 倍放大，以及半山、山顶、原生最远 20.16 m 的补图。

桥可见性采用同机位实际渲染的桥开 / 关像素对照；角色动画冻结以避免把人物运动计入差异。
按真实 FarZone shader 测像素，不拿被 shader 改写前的世界 AABB 充当屏幕范围。
全部几何、宿主实例合同、切档及四视角可见面数 / draw 检查结果在 validation JSON，预算包含阴影 draw。

桥实测范围 x=11–118、y=73–121 px；开 / 关差异 1,308 像素，y=55–180 内橙红像素 645 个。
105 项资产检查和 33 项合成检查全部通过。当前白模加本包驻留 46,742 三角面 / 47 surface（含角色、两档塔及 MultiMesh 实例）。
