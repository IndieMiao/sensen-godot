# SGODOT-419 · A v1.2 · 蒸汽离开盖面后显形

黄忠。按上官婉儿派活、不知火舞 `79fe1cff`，只修 Steam；v1.1 的造型、汤、泡沫和两个动画均保持原样。
原锅 GLB、各网格、非蒸汽材质、原有 UID 的哈希未变，动画资源文本逐字相同。

蒸汽改为暖白 `#FFF8F0`，0.11 m/s 向上，寿命 1.8 s，总行程 19.8 cm。
前 0.9 s（9.9 cm）完全透明，此后 alpha 淡入至最高 0.35，再淡出。数量仍为 5，均匀发射、本地坐标、不投影。
按五粒子的完整生命周期相位计算并加入曲线斜率误差裕量，即使所有粒子在同一屏幕像素重叠，合成 alpha 上界仍 < 0.455。

为防止较平镜头再次把白气压在橙盖上，仅 Steam 附带一个轻量的局部视觉脚本和材质 shader：
缓存盖子原顶点，每帧读取宿主相机下的真实盖子上沿；此线上及以下 alpha 为 0，离开上沿后才渐显。
材质参数独立属于每个锅实例，盖子动作、汤面和宿主 UI 均不受影响；不需要哪吒额外传参数。
脚本 / shader UID 由 Godot 生成，随本次提交。

交付四张图：合盖、顶起、落回三帧，以及盖子上方白气的放大。背景为暖中性色，便于检查白气颜色与位置。
额外验证同时覆盖 35° 原预览和 43° 厨房方向：记录实际盖子顶点投影上沿，对比 Steam 开 / 关的 RGB，
核对盖沿以下没有蒸汽、上方白气仍可见。报告见同目录 validation JSON。

模型仍为 2,028 面、2 个绘制材质，Steam 另计最多 10 面；tumble 1.8 s、idle、根节点和盖轴均保持 v1.1。
本轮只交蒸汽修订。哪吒将用新头重拍接入实景，再交不知火舞复验；不将本地预览当作接入验收。
