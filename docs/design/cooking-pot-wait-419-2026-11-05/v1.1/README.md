# SGODOT-419 · A 炖锅翻滚 v1.1 · 独立 3D 叠层

黄忠。按上官婉儿补充及不知火舞 `bd102c55`，锅现在交给宿主单独渲染为叠层，
不再通过推近灶台镜头展示。此版是 #759 的增量，PR 保持草稿。

## 参数调整

- 盖子的平移和倾斜幅度均缩至 v1 的 60%。盖轴最多抬 0.0144 m，含倾斜前沿约 0.01722 m，低于 1.8 cm。
- 锅身仍只颠 0.002 m，根节点不动；`tumble` 保持 1.8 秒无缝循环，不随圆环停顿或加速；`idle` 保持静止冒汽。
- 蒸汽方向改为直上、发散角 5°、速度 0.040–0.052 m/s、寿命 1.2 s，减少在大尺寸叠层里的横向越界。
  数量仍 5、local_coords=true。单粒子 alpha 上界 0.119，五粒全部重叠上界 0.469，整个范围都低于 0.5。
- 造型、颜色、网格、面数、材质和全部 UID 保持 v1 原样；原 GLB 也不改。验证报告附逐文件 SHA-256 对照。

## 独立渲染检查

实际创建 200×180 透明 SubViewport，放在原生 360×800 画布的 `(80,150)`；无拉伸、无底板，
仅由测试宿主加左上暖色主光和环境。运行时资源本身没有灯光、相机或 WorldEnvironment。
加半径 60 px 的细圆环占位，未放倒计时和进度条；真正等锅实渲待哪吒接入。

| 项目 | 全循环实测 |
| --- | --- |
| 锅宽（含把手，静止） | 180.00 px |
| 锅口投影 | (180.00,235.00) px |
| 盖子所有顶点最大屏幕位移 | 8.19 px ≤ 12 |
| 锅身所有顶点最大屏幕位移 | 0.81 px ≤ 2 |
| 全部几何 + 保守蒸汽轨迹边界 | x 89.63–270.37、y 169.29–323.28 |
| 要求占位框 | x 80–280、y 150–330；全部在框内 |
| 结构 / 动画自查 | 312 项通过；2,028 面，蒸汽另计最多 10 面；2 个绘制材质 |

**取景说明**：原锅是高锅。按 180 px 宽直接沿用旧 43° 取景，锅底会超出框；
本独立叠层使用 62° 俯角的透视镜头，水平 FOV 39.9253°，位置 `(0,0.5297685,0.1942029)`，
方向 `(0,-sin(62°),-cos(62°))`，near 0.005 / far 5，keep_aspect=KEEP_WIDTH。
这是本次审阅取景参数，不将相机写入模型；接入可照此复现，仍由不知火舞验画面。
