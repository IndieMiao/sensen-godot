# SGODOT-424 · 草坡 v1.1 · 刘备

不知火舞已在 424 评论 `8e453bd3` 决定套用 #827，并要求只增强草坡。**三处默认镜头的深草 / 普通草平均亮度差现为 22.83%、22.66%、22.74%，均 ≥15%。** 已认可的步道石板接缝与码头木纹保留 v1 效果。

本轮仍使用马可波罗确认有效的 `bf0c31b1` 地形、原镜头和暖光。对比左侧为 #827 已审头 `91c563b16b651c1013d0290e70d611884376ab0f`，右侧为 v1.1；不是拿无纹理白模作为“之前”。每侧原生 360×800，原镜头宽 6.72m / 43°；人物与落点、光照、海面、导航均一致。

**测量定义**：对输出 sRGB 像素求 `Y′=(0.2126R+0.7152G+0.0722B)/255` 的算术平均，差值为 `(普通草均值−深草均值)/普通草均值`。这是屏幕像素亮度指标，不冒称物理线性光亮度。全量数值和样本包围见 [brightness-validation.json](brightness-validation.json)。

样本来自独立 QA 分类渲染，限定深色和普通色内部、内缩1px，剔除遮挡与颜色交界；另渲染统一草色、原光照的控制图，要求两类样本都处于同一日照亮度±0.008 Y′，排除树影、栏杆影和暗面。使用相同像素集合测量前后两个版本，未挑选单个最暗点，也不把树影算成草色差。开场草坡被台阶和棚架遮住较多，因此样本较少；仍保留130个完整可见的深草像素。

## 仅草坡的变化

- 新增三个**草坡显示色**参数：深绿 `grass_deep_color=#527E35`、普通绿 `grass_base_color=#78A044`、日晒浅绿 `grass_sun_color=#A2B95D`。深绿偏饱和，不往灰蓝偏。
- **原 garden / garden_dark / garden_light 保持原色板值，只用于识别 COLOR_0**。新显示色与选色分开，防止改深绿色后漏掉模型原有的绿色顶点；其余分类和朝上法线约束保留。
- `alc_ground_fields.png` **仅 R 通道变化**：原大场叠加独立种子4241107的周期细噪声（sigma=3px、归一化幅度0.025），打碎色块边缘。保留24m / 38.832m的80/20大场混合，形成数米尺度大块；短叶细纹G、预留B通道逐像素不变。
- 原 grass_detail_strength=.13、草地细纹2m、色阶过渡0.41–0.46 / 0.54–0.60均保持；不新增采样次数、法线贴图、几何或额外pass。

三个显示色在 `alc_terrain_detail.tres` 中显式设置；shader 新增同名 uniform，默认值仍对应 v1 原色，方便旧绑定保持兼容。完整合同仍为 `assets/landmarks/alcatraz_island/ground/alc_ground_materials.json`。

## 石板、木纹与宿主保留

`alc_ground_surfaces.png`（石板R/G、木纹B）、它的导入文件和 `alc_dock_detail.tres` **与91c563b16逐字节相同**。shader 的 `else if (path)` 起至文件结尾，包括铺石、木纹、最终ALBEDO混合和粗糙度/高光，原字节保留；所有石板/木纹参数都不改。

四个视角中，草地可见范围及1px抗锯齿边缘之外，前后最大 RGB 差均为 **0/255**。细栏杆后只有部分MSAA采样露出草地，使用分类图与全黑目标控制图之差识别这些边缘，避免把它们误报为石材变化。原开场桥/城市区同样为0差。98项源检查通过，宿主地形、模型、UV、layout、海面与源代码保持固定头原字节。

25项桌面渲染检查通过，场景绘制计数没有增加；配色验证使用 Godot4.7.2 / Vulkan Mobile / Steam Deck VANGOGH。桌面成对截图只冻结QA时钟以排除宿主海面原动画的时间差，未改海面文件。Android正常计时的三视角、完整人物、两次真实缩放按钮及安装包回读，见本目录 Android 记录；不代表物理手机性能验收。

## 马可波罗接入

仍只替换材质及其依赖，不改模型/UV：三件地形使用 `alc_terrain_detail.tres`，dock 使用原 `alc_dock_detail.tres`。本轮必须一起带上更新后的 terrain material、共享 shader、fields PNG 和参数JSON；导入UID保持。

已核对 #792 新头 `b81605af`：palette.json 与bf0c31b1一致，`_add_asset()` 将废墟用SurfaceTool追加到 `alc_ground_terraces` 后，仍在该节点设置 `material_override`。**合批后的节点照常套地形材质即可**，保留原COLOR_0/法线；原石色不会匹配草地键。不要把 `garden*` 识别键改成新草色，也不需要拆模型或重新展UV。
