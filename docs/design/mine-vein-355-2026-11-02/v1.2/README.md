## 实测亮度

数值取自实际 Godot Vulkan Mobile 的 720×1600、43°、zoom=.8 图。亮度口径为 sRGB 编码像素的
`Y' = .2126R + .7152G + .0722B`，不是线性亮度；JSON 另附线性结果。
ID 遮罩按原材质双面显示提取可见灰色岩块本体，剔除矿物条纹并收边 1 像素；
再隐藏两块矿石和它们的阴影，在相同像素位置取地面。表内均为中位数。
铁、石英分别取 2,091、2,100 个像素，JSON 保留 10%–90% 区间、原图 SHA 及岩块 SHA。

| 层段 | 岩块 | 地面 Y' | 岩块本体 Y' | 差值 |
| --- | --- | ---: | ---: | ---: |
| 21–30 | 铁 | 0.68973 | 0.44092 | 0.24881 |
| 21–30 | 石英 | 0.69337 | 0.49302 | 0.20035 |
| 31–40 | 铁 | 0.67573 | 0.44092 | 0.23481 |
| 31–40 | 石英 | 0.67965 | 0.49302 | 0.18663 |

四组均超过 0.15。地面在两块岩石位置略有差异，来自原有地表色彩细节，不采用 palette 色值冒充画面实测。

白脉顶点色由 sRGB `#8E8A9A` 至 `#A7A4B1`，中间色 `#9895A0`，保留淡紫和原有面法线明暗分布。
GLB 回读后的 sRGB 亮度为 **0.54904–0.64932**，带内跨度 **0.10028**；只转换一次到线性 COLOR_0。
本次所有层段使用相同白脉颜色，不依赖 palette 或新增运行时参数。
