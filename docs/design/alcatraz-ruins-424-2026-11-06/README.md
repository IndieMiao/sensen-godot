## 建议点位与整合

[`suggested_placements.json`](../../../tools/art/source/alcatraz_ruins_424/suggested_placements.json)固定参考 #792 v6 **b16c3198**：`ruins_000`世界坐标 **(18.5,3.25,5)**，yaw=0。每件同时提供世界position与`relative_to_ruins_000`，以及rotation_degrees、scale、zone、group、multimesh和collision，便于主体之后移动时重算。

建议13个实例：1段倒拱、3片碎石、3片挂墙藤蔓、5丛野花、1张空白说明牌，共 **3,270个摆放三角面 / 5个MultiMesh批次**。分为西侧靠路的低件、拱券旁、东墙根三处局部组合，藤蔓贴在原墙柱前侧。落地件中心与占地角点均用v6真实地面三角形采样；靠台地边的一片碎石已内收，完整轮廓没有跨到下层地面。

三片藤蔓背面放在原墙柱正面前20mm（world Z=5.245），实际植被深度约55mm；墙形正式细化后必须重新贴墙核对，不能把挂墙件当直立灌木放在草地。说明牌从原靠路候选移至 **(13.25,3.25,6.85)**，避免上楼梯时遮住右下主键。碎石片在拱券旁可以邻接，避免将同一patch堆叠成资源石堆。

废墟本身在主路线右侧，原生6.72m近景只能看到部分靠路低件；**本包不单独证明整条路线每6–7m已满足看点要求**。正式整岛合成时，马可波罗需结合花园/原道具、最新树冠和镜头再核覆盖与遮挡。没有为审阅将废墟或原树挪回路边，也没有新增可走区。
