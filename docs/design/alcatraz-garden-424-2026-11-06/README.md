## 建议点位

交马可波罗使用 [`suggested_placements.json`](../../../tools/art/source/alcatraz_garden_424/suggested_placements.json)。表中包含每件asset、原点、rotation_degrees、scale、zone、group、multimesh、collision，以及每组的默认镜头站位。它是装配建议，**不要用reference目录的旧layout快照覆盖整岛当前layout**。

三层台地各5个新增花色看点，主段站位间距6.5m，靠楼梯最后一段缩为4.1m，配合既有长椅/花坛。橙、紫、白依次换主色，绿篱留成短段，避免整条路封成连续绿墙。有效花带很窄：上一级铺装覆盖部分原草坡，因此花与绿篱沿花带错开，不强行在花后排一整行。

点位脚本直接读v6三个地面GLB的向上三角形，核对每件中心和水平边角均有同高度地面支撑；避开栏杆、旧花坛（按1.7m方坛保守计算）、长椅、灯牌、垃圾桶、灌木和树干。碰到已有物体或上层台阶的候选舍弃，拒绝原因也保留。盆栽放西侧四个端头，尺寸不缩放；花和绿篱的完整水平轮廓留在铺装外。

当前建议 **64个实例**：13丛罂粟、15丛薰衣草、13丛雏菊、19段绿篱、4个盆栽，新增 **11,766 个摆放三角面**，按区块/类型合成6个MultiMesh批次（台地5类、码头1个盆栽批次）。右侧楼梯端一组只补一丛，以附近已有花坛共同提供看点，不为凑数量侵入楼梯净空。

客户端接入建议保留低装饰的远视简化策略：默认6.72m显示，较远机位可隐藏花卉/绿篱/盆栽；原生近景和美术全景检视可显示全部。此阈值最终由亚瑟按整岛预算定，新增6批并不等于全场已经满足60 draw限制。不得给这些装饰挂采集、弹窗或可点提示。
