## 同机位与人物

每间交一张基础款 vs B 款并排，左右各为原始 **720×1600**，43°、宽 6.72 m；不缩放、不裁切，A/B 镜头、灯光、人物位置和姿态一致。

- N1：保留原默认镜头，人物双脚放在地毯内侧 `[2.20,.0837,2.35]`，用实际地毯三角形射线确认支撑。相对 v0 仅将审阅人物向内挪，房间布局不变。
- N2：人物继续站 `[0,.08,2.5]`，位于中心线 X=.04、半宽 .35 m 的十字嵌条内。原默认镜头不变。
- 实际默认形象为白上衣、薄荷绿短裤，H=1.745 m；两幅均使用冻结的同一 idle 姿态。

N1 门头贴片像素为单一浅底色，已检查没有字或标记；正式版继续使用运行时文字，不恢复烤字。
临时换色、贴片、药瓶和检查脚本均在 `output/skin-325-mock/`，原 assets、GLB、场景和布局文件哈希保持。
