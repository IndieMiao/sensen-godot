# SGODOT-325 B 皮肤小样 v0

黄忠，2026-11-03。按上官婉儿 `palettes-B-v0.md` 制作，供用户决定第二款皮肤的配色。
**本次只是小样，没有正式运行时交付，没有新增 variants.json，没有开 PR。**
基线为 `origin/wp-3d-scene` 的 `e5a30a98`，所有临时脚本、图集、门头贴片及药瓶都放在 `output/skin-325-mock/`。

## 对照与机位

- N1 基础款 / B 明亮酒店：复用赵云已验证的 `native-camera-n1-v1.1.json` 默认进门机位，43°、宽 6.72 m；局部灯和壁炉保留。
- N2 基础款 / B 诊所：复用 N2 已验收的 43° / yaw45° / 宽6.72 m，目标点 `[0,1.1,.35]`。
- 每间 A/B 使用同一相机、灯光、人物位置与静止姿态，每幅原始渲染均为 **720×1600**，在并排图内不缩放、不裁切。
- 两间分别沿用原审阅灯光和色调映射；不把换灯光造成的变化算成皮肤差异。N1 炉火预热后固定同一状态用于两幅对照。
- 人物为实际玩家模型，H=1.745 m。另各交一张 B 款全景，使用原房间的全景机位。

**实渲后未调整上述核心色值。** 贴图保留原有 AO / 木纹 / 人字拼 / 砖缝的明暗调制，所以并非把整个材质填成纯色。
现有图集角色的补充映射也在验证 JSON 中逐项列出：

- N1 护墙板、顶线、踢脚、窗框、门套及家具木作统一映射到 #A97B52；黄铜及地毯细边用 #C9A04E。
- N1 圆沙发采样区与地毯位于同一图集格，分别处理中心色块和其余织纹区。奶白扶手椅、画、镜面、玻璃与植物图块保持原像素。
- N2 未单列的护墙板取 **#DCE7DF**，比上墙薄荷白略低一档；顶线、踢脚及龛框归入桦木 #CFB48C。龛内背景沿用沙发的鼠尾草绿 #5F9680。
- N2 三块植物保留区没有重染；叫号屏的三颗色点原图块不变，屏底改绿色，不加数字。
- N1 门头贴片为 #F3ECE2 浅底、#37545A 深字，`HOTEL` 仅为示意字，正式版仍由程序写名称。
- N2 门头为 #F7FBF7 白底、#3E9E6A 绿十字，右侧留空；没有使用红十字。

N2 只在隔离工程内隐藏两个龛原有的陈列，换成三只圆润无字药瓶（左龛两只、右龛一只）。龛的框、背板、搁板及位置保留。
药瓶体色为 #E1ECE3 / #ABCAB6 / #D9E8DD，瓶盖为 #3E9E6A；它们是定色小样，不是正式模型。

## 保持范围

原 `assets/`、场景、模型源与工具均没有修改。已对复制的运行时输入逐文件核对 SHA-256，所有隔离工程中的 GLB 也与原件字节一致。
运行中的临时龛陈列切换只过滤显示物的三角形；原顶点位置、UV、顶点色和家具变换保持，框体法线转存误差单列于 JSON。
N1 全部家具和壁炉保留；N2 的布局、沙发、雕塑、宣传架、饮水机、叫号屏及植物保留。
本次只推本 docs 目录，不把 B 图集、门头贴片、药瓶或临时脚本提交到运行时。
