PRD 评估

1.1 站得住的部分

  • 两层可见空间 + region_id / layout_patch_id / farm_instance_id 分离：数据模型干净；蓝图 revision 冻结让老存档不受道路更新影响。
  • 「拓扑影响个性，不影响经济」把真实地图最大的隐患（地区阶级）从设计上排除，工程上只需要一个公平校验器。
  • 七日账本是确定性夹具，Gate 2 的「守恒错误为 0」可以用一条模拟测试兜住，而不是靠 30 个人跑七天。
  • §11.5 移动端指引全部落在 Godot 4.7 mobile 渲染器和现有桥的边界内。
  • §11.2 要求接口保留幂等键、版本号和服务端时间语义，正好是服务端权威模型需要的全部约束，不用改 PRD。
  • Gate 顺序先蓝图、再劳作、再居民，与「不得先批量做居民」的红线一致。

1.3 PRD 没写但会卡住实施的缺口

  1. 农场归一化尺寸。定了 9/12/16/24 格和 3–7 区块，没定游玩区物理尺寸、田格边长、步道最窄宽度。已按 §6 默认值拍板。
  2. 选择页与固定缩放矛盾。§3.1 只允许 zoom 16 街区级浏览，§4.3 又要三个候选同屏，250–450 米街区在 zoom 16 下不可能。解法：卡片轮播，切卡时 set_camera 飞到对应候选。
  3. 劳作动画来源。清理、翻土、播种、天气照料、收获、挥手至少 6 条。Unity 库能借的只有 dt@basket 和表情类。已拍板：全部占位登记。
  4. 时区。Godot 没有 IANA 时区库。双城后洛杉矶带夏令时，所以 player_day_id 由服务端用 IANA 时区（luxon）计算，客户端只显示。
  5. 演示节奏。作物 4–18 小时、主会话间隔 18 小时，现场跑不了七日。导演模式升为一等交付物，只对服务端标记 QA 的农场实例生效。
  6. 两城的数据与网络。上海 OSM 主路可用但细路稀，候选要人工挑；洛杉矶质量高。服务端要同时被上海和洛杉矶稳定访问，VPS 选址要考虑大陆连通性。
  7. Gate 测试规模。已拍板缩为内部 QA + 5–8 名熟人；正式 Gate 留到融资后。

1.4 小问题

  • §3.1「点击 Avatar 先进入预览」与 §3.3「人数簇→横向列表→选中」是两条入口，MVP 只做列表一条。
  • §4.4 / §6.1 田畦 3 格制下「16 格」不能整除（9→12→15 才对，或改畦长）。
  • 老案的三张概念图和新案的 output/imagegen/current-app-*-v1.png 混在同目录，索引没更新。

关键技术决策

D1

候选高亮在 Godot 透明层绘制，不给原生桥加 GeoJSON 图层

Android、iOS 要写两遍；iOS UDP 桥不适合传大段 GeoJSON（§11.5 明令禁止）；G2 已真机验证 Godot 层与 Mapbox 的相机同步，贴地 mesh 和角色是同一套投影。蓝图携带 WGS84 的 overlay 多边形，运行时投影到浮动原点坐标生成 ArrayMesh，选中态换材质，天然满足「高亮与农场同源」。

代价：pitch 45° 下贴地 mesh 有 z-fighting，用少量抬高 + 关深度写入解决；不行再退到 Android 原生 fill layer。

D2

两层空间用场景栈，地图常驻不销毁

原生 MapView 本来就随 Activity 常驻，只有 Godot 侧在重建；09-04 Demo 的定位闩死锁正是 change_scene 重建地图引起的。§10.3 要求返回恢复相机/选中/滚动，常驻最省。AppRouter 增加 push_instance / pop_instance；push 时地图根节点停 process、隐藏、set_map_visible(false)，pop 反向；换装房也迁到栈上。真机 RSS 放 G0 出口验。

D3

蓝图离线管线：Node/TypeScript 生成，Godot 运行时加载，双城同一条管线

数据来源 OSM 一次性 Overpass 抓取，存 source / license / revision，不碰 Mapbox Streets。Node/TypeScript（tools/geo_blueprint/：geos-wasm 即 GEOS 本体、proj4 做横轴墨卡托、pngjs 出预览，vitest 测试；几何指针收口在一个 geos.ts 封装里）：本地投影 → 道路拓扑修复 → polygonize → 区块筛选 3–7 → 简化合并 → 等比缩放到固定游玩区 → 栅格化四张 mask → 锚点 → 可达性与公平校验 → farm_blueprint.json + map_overlay.geojson + 预览 PNG。

Godot 侧 G0 直接在运行时从 JSON 生成地表 ArrayMesh 与 AStarGrid2D，烘焙成 .res 留到 G4；checksum 由 Godot 按同一 canonical 字符串重算，双语言一致性用测试守。目录按 assets/blueprints/{layout_patch_id}/rNN/，revision 不可变。城市只是管线参数：--city shanghai / --city los_angeles。

D4

权威状态在服务端；服务端用 Node.js，数值逻辑只在服务端算

栈：Node 22 LTS + TypeScript + Fastify + TypeBox（请求/响应的 JSON Schema 即类型）+ Drizzle + PostgreSQL + luxon（IANA 时区）+ vitest + pino。Java 维护资源已不在，后续服务统一 Node。

协议：REST over HTTPS + JSON。MVP 不用长连接：农场是单人的，命令都是请求回包；作物成熟靠 ready_at 倒计时；访问和人数簇是只读拉取。WebSocket 等 IM 或实时功能再加。接口 v1：POST /auth/anonymous、GET /regions、POST /farms、GET /farms/me、POST /farms/me/commands（idempotency_key + base_version + type + payload → version + state + server_time）、GET /regions/{id}/nearby、GET /farms/{id}/snapshot、POST /qa/...（仅 QA 实例）、GET /healthz。

领域层 server/src/domain：State（纯数据）+ Command + Reducer（纯函数，无 IO）。钱包、库存、XP、关系、章节、ready_at、player_day_id、天气脚本推进全在这里；七日账本测试直接驱动 Reducer。存储 PostgreSQL：farms（version、state jsonb、qa）、commands（idempotency_key 唯一索引、base_version、result）、snapshots。apply 走一个事务：SELECT … FOR UPDATE 锁农场行做单写者；幂等键命中直接回放上次结果；base_version 过期返回 409 并带最新 state。鉴权 MVP 匿名 device_id → player_id 签 JWT，日后接 Firebase Auth。

客户端：不算钱、不算 XP、不算 ready_at。只保留一个薄预测器 modules/farm_predict 预测田格视觉状态，好让动作立刻播；回包按 version 覆盖，漂移一律以服务端为准。断网进只读态并显示横幅，不排队离线命令；访客快照按 §11.2 随包兜底。导演模式命令只对 qa=true 的实例生效，正式实例返回 403。内容数据 assets/farm/data/*.json 是单一来源，服务端构建时打进镜像。

部署：阿里云香港 ECS 2C4G，docker-compose 三个容器（app + PostgreSQL + Caddy 自动 TLS）；免 ICP 备案；需要一个域名；代码不用阿里云专属 SDK，配置全走环境变量，将来迁 AWS 只换机器。

D5

农场移动 = AStarGrid2D + 摇杆/点按

Godot 内置 AStarGrid2D 就是 PRD 要的预计算网格，不烘 NavMesh；walkable_mask 直接喂进去。左侧虚拟摇杆 + 点按地面寻路；相机固定 45° 跟随，不开旋转。

D6

劳作 = 网格刷子

右手拖拽在地面投射轨迹，逐格命中、排队播放动作；点按 = 单格；行级工具 = 一次命中整畦 3 格但仍逐格播放。摇杆与刷子按 touch index 分流；靠近对象只显示一个上下文按钮。动作判定走本地乐观副本，结算以服务端回包为准。

D7

内容数据化，居民复用 avatar

assets/farm/data/ 放作物、料理、居民（含 outfit）、章节、天气脚本、对话、请求、事件，两端同读，服务端构建时打进镜像。三名居民 = 固定 AvatarConfig，只做名字、地点布景和台词。

D8

导演模式是一等交付物

独立入口：时间倍率、跳到下一活跃日、指定田况种子、跳章、载入目标账本任意一天的状态快照。产出「D0–D6 十五分钟演示脚本」，融资现场按脚本走。

D9

美术分三档；缺失动画全部占位登记

灰盒（G0）：原语 + 平涂。占位低模（G1–G3）：作物 4×4 阶段用简单 mesh + 颜色；雨用 GPUParticles3D，风用顶点摆动 shader；道具从 Unity _Gensen/InteractiveProps/farm、well、Space/SpaceThemes/Farm 挖。正式（G4 / 融资后）一次统一过线。

动画：assets/avatar/base/anim_placeholders.json 登记每条需要的 clip（clip_id、被哪个动作引用、占位策略、状态）；运行时找不到真实 clip 就按登记表回退（默认 idle + 程序化俯身/摆臂），QA 构建在角色头顶显示占位标记；测试守「数据引用的每个动作，要么有真实 clip，要么在登记表里」。
