## 验证什么

方案 A（原生 Mapbox MapView 垫底 + Godot 透明层渲染角色）的第一道关卡：
**Android 上双 SurfaceView 合成是否成立**——地图在下可见、Godot 角色透明叠加在上、原生手势桥接可用。
相机同步精度（G2）、性能矩阵（G4）不在本关范围。

## 实现摘要

| 层 | 实现 |
|---|---|
| 地图（底） | `GodotMapPlugin.kt`（android/build 内嵌源码，v2 meta-data 注册）：`onMainCreate` 返回 MapView 容器，`shouldBeOnTop()=false` 垫底；Mapbox Maps SDK 11.29.0（streets 样式） |
| Godot（中） | `project.godot` 开 `per_pixel_transparency/allowed`；插件在 onMainCreate 内对 Godot SurfaceView 调 `setZOrderMediaOverlay(true)` + `TRANSLUCENT`（window attach 前，时序合法） |
| 场景 | `scenes/map_poc/`：透明视口 + 一个默认换装角色（idle）+ HUD（状态/缩放/倾角/旋转按钮）；单指拖拽→`panBy`（用地图自身 `coordinateForPixel` 换算，DPI 无关）、双指捏合→zoom、双指拖拽→pitch（Godot 相机同步联动倾角演示） |

Mapbox maven（`api.mapbox.com/downloads/v2/releases/maven`）已实测匿名可下载，无需 downloads token；运行时 pk token 放仓库根 `mapbox_token.txt`（**不入库**，经 preset include_filter 打进 pck）。

## 构建

```sh
# fresh checkout 时先重建 android/build（android/ 整目录不入库）
tools/android/setup_android_build.sh
printf '%s' "<pk.token>" > mapbox_token.txt   # 可复用 Unity 工程 Assets/Resources/Mapbox/MapboxConfiguration.txt 里的 AccessToken

JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" \
  godot --headless --path . --export-debug "Android" build/sensen-map-poc-debug.apk

adb install -r build/sensen-map-poc-debug.apk
```

## 装机验证清单（逐项打勾）

3. [x] **角色叠加在地图上**，材质/idle 动画正常，边缘无黑底色块（透明合成干净）
4. [x] 单指拖拽地图跟手移动；角色固定屏幕中心（G1 预期行为，不是 bug）
5. [x] 双指捏合缩放、"倾角±"按钮：地图倾斜时 Godot 相机同步倾斜（角色透视随动）

## 判定

> **结果（2026-08-29 真机验证）：G1 通过 ✅**（8 项全勾，见上；截图证据显示三层合成干净、
> 手势桥/生命周期/换装房回归均正常）。已进入 G2，见 `2026-08-29-3dmap-g2-camera-sync.md`。

- **通过**：1-6 全勾 → 进入 G2（相机同步协议 + projectionMatrix 校准）。
- **失败模式 A**（地图不可见/Godot 不透明）：改试 host 侧时序（在 GodotFragment attach 后重设 z-order）→ 仍败改 AAR 嵌入形态（原生壳）→ 仍败 = 方案 A Android 路线否决，上会。
- **失败模式 B**（地图可见但 HUD/Godot UI 被压住）：`setZOrderMediaOverlay` 与 window 层关系不符预期，试 `setZOrderOnTop(true)` 并把全部 UI 移入 Godot 层（可接受的降级，因为本项目 UI 本来就在 Godot）。
- **失败模式 C**（角色边缘有黑边/合成脏）：检查 viewport `transparent_bg` 与 MSAA 组合，试关 MSAA 对照。

## 已知边界（本关不修）

- 角色没有投影到地图的影子（需 shadow-catcher 面片，G5 打磨项）。
- 双指捏合在部分机型上以 InputEventMagnifyGesture 到达的灵敏度差异——参数后调。
- 后台/低内存回收的完整生命周期矩阵在 G4。
- iOS 侧完全未动（G3：透明 spike → 引擎 patch → SwiftGodotKit 决策树）。

## PoC 期间的工程约定

- `android/` 不入库；改动只落在 `tools/android/overlay/`（三个文件整文件替换，钉 4.7.2 模板）+ setup 脚本。升 Godot 版本时需重新 diff 模板。
- 转正式实现时，插件应从"模板内嵌源码"迁为独立 AAR + EditorExportPlugin addon（`_get_android_dependencies` 注入 maven 坐标），并把地图操作收进 `MapBridge` 抽象层（MapLibre 逃生通道）。
