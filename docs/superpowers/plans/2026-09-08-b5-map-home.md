## 1. 做了什么

### 服务端（`server/src/http/location.ts`、`db/pg_location.ts`、`memory_location.ts`）
- `PUT /v1/location {lat, lng, accuracy_m?}`：每人一行最新位置（`user_locations`），不存轨迹；越界 400。
- `DELETE /v1/location`：停止分享。
- `GET /v1/friends/locations`：**只给互相关注的人**（`SocialStore.mutualFollows`，Pg / Memory 都实现），24 h 没更新的不下发，最多 200。单向关注、陌生人一律不给——比 E2「降精度」更严，陌生人「附近的人」本期不做。
- 删号级联 + 数据导出登记（`locationAccountModule`）。测试 `test/http/location.test.ts`（3 例）。

### 客户端
- `modules/net/location_api.gd`（`Net.location`）：`report / stop / friends`。
- `scenes/app/pages/map_page.gd` 重写：首次显示才实例化 `map_poc.tscn`（`demo_cohorts = false`），之后只在 Tab 显隐时 `resume / suspend`；本页不画纸色底与标题栏，壳（`AppShell`）在地图 Tab 也把自己的底关掉——原生 MapView 才能从底下透上来。好友位置每 30 s 拉一次交给地图；定位回传按 30 s / 25 m 节流上报，只在本页可见且登录时（When-In-Use）。
- `map_poc.gd`：`@export demo_cohorts`（关掉随机路人 / 洛杉矶夹具 / 便签气泡 / Fly 按钮，人数按好友算）；`set_friends(items)` 按 user_id 增量增删改 pawn，装扮用服务端 `avatar`；好友与洛杉矶夹具是绝对坐标，home 纠正时不跟着搬；`signal location_changed`；`suspend / resume` 顺带 `stop_location / start_location`。
- iOS 桥定位：`tools/ios/MapUnderlay.swift` 加 CoreLocation（`LOC|1 / LOC|0` 开关，`LOC|lat|lng|acc` 回传），`MapBridgeIOS` 解析并发 `location_update`；`MapBridge.stop_location()` 基类空转。
- 导出预设加 `NSLocationWhenInUseUsageDescription`（正式文案等 SSLAUNCH B8）。
- QA 钩子：`SENSEN_QA_MAP=1`（进地图 Tab 截图）、`SENSEN_QA_FAKE_LOCATION=lat,lng`（桌面 / 无 GPS 时模拟一次定位并走真实上报路径）。
