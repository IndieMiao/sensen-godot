## 命令

- `claim_blueprint {blueprint: "sheep_pen"}`：`UNKNOWN_BLUEPRINT`、`BLUEPRINT_CLAIMED`，再按顺序查：卖货次数（羊圈 0）、
  委托单数 `CONDITION_NOT_MET {requests_done, min_requests}`、等级 `CONDITION_NOT_MET {level, min_level}`、金币 `NOT_ENOUGH_COINS {coins, need}`。
  两个条件都不够时报的是委托单数。成功扣 1,200 金币、背包 +1 张羊圈蓝图。同一批里先交第 15 单再买可以（交单先加 `requests_done`）。
- `place_building {building: "sheep_pen", x, y, rotation}`：沿用 C-150/C-181，`NO_BLUEPRINT`、`NOT_ENOUGH {item, have, need}`、
  `BUILDING_OVERLAP`、`CELL_OCCUPIED`、`BUILDING_LIMIT`。
- `feed {building}`：野草药少于 3 份 `NO_FEED {item: "wild_herb"}`，体力不够 `NO_ENERGY`，地上满 4 份 `GROUND_FULL {max: 4}`；
  成功扣 3 份野草药、1 体力，30 分钟后一份羊毛落地。
- `pick_up {drop}`、`sell {item: "wool"}`：同鸡场、牛棚。

## 客户端

- Scott：问候卡里羊圈蓝图一个键 `Buy Sheep Pen Blueprint · 1200 coins`。还不能买时键是次要键、第二行写原因，点一下飘同一句：
  委托单不够 `Need N more requests`（1 单时 `Need 1 more request`，照 LOCK-10 `Need N more X` 的写法），再看等级 `Farm Lv3 needed`，
  再看金币 `Need N more coins`。顺序和服务端报错一致。买到后飘 `Received Sheep Pen Blueprint ×1`，键消失。
- 摆放：`Build Sheep Pen`，摆放栏 `Cancel · Rotate · Build`，四个朝向；材料不够时 `Need N more Timber`/`Stone`。
- 喂食：人在投喂槽前（槽中心或补草站位 1.1 米内）主键 `Feed`、第二行 `1 Energy`；野草药不够 `Need 3 more Wild Herb`，键上放不下时退成
  `Need 3 more`，点一下飘整句。点院内地面走过去喂时走到补草站位 (1.5,2.5)；喂过的羊走到 (0.5,3.5) 吃。
- 羊、羊毛的走动、产出、走近自动拾取全部复用 `ParcelLivestock`。
- 物品：`Sheep Pen Blueprint`（配方卡图标）、`Wool`（代码画的一团羊毛，等图标美术）。`Wool` 单复数同形（`P0Logic.PLURALS`，同 `Milk`）。
- 委托板：标题 `Wool Bundle`。
- 以上英文都是作者草拟，按 C-45 由 PM 定稿。
