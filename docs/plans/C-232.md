## 服务端判定（`server/src/parcels/fishing.ts`）

- `cast_line {bait}`：服务端用 `hash32(地块:时间:第几竿)` 定种子，按种子抽档次、定咬钩时刻，存进 `fishing.cast`；扣 5 体力。
  水里已有一竿且没过最晚交结果的时刻：`ALREADY_CASTING`；过了就先按脱钩收掉再投。
- `reel_line {hook_ms, inputs}`：`inputs` 是从提竿起每 50 ms 一位的按键（1 按住、0 松开）。服务端用同一个种子、同一套模拟重放：
  涨满给鱼（鱼种按种子在这一档里挑），掉光或到时脱钩退 3。记录没走完、多交了位：`REEL_INPUT unfinished`；
  记录的时长长过服务端从咬钩到现在的时间（+250 ms）：`REEL_INPUT too_fast`；咬钩前：`TOO_EARLY`；提竿晚过窗口或过了最晚时刻：按脱钩算。
  客户端不报结果也不报鱼种，请求里带的 `outcome`、`fish` 不读。
- `cancel_line`：咬钩前全退、鱼饵不用；咬钩后按脱钩。
- 结算完 `fishing.cast` 清掉：同一竿再交 `NO_CAST`；整批重发由 `base_version` 挡住（HTTP 测 8 个并发只成 1 个）。
- “人在码头沿边”和别的动作一样由客户端限定（服务端没有码头几何）。
- 存档字段 `fishing`（v1 上追加的可选字段，版本号不变）：`cast`、`casts`、`caught`、`gifted_at`、`bought {day, counts}`、`last`。
  旧存档没有这一项，读写都不补；换数据集不动它。

客户端 `modules/dynamic_farm/parcel_fishing.gd` 照同一份规则一字不差地再算一遍。共用用例
`tests/dynamic_farm/fixtures/fishing_cases.json`（41 条命令用例、162 局收线重放、64 次档次抽签）由
`tools/dev/dynamic_farm/fishing_cases.ts` 按服务端规则生成，服务端 `server/test/parcels/fishing.test.ts` 和客户端
`tests/dynamic_farm/test_parcel_fishing.gd` 各跑一遍。

## 码头接口（SEN-C-233 模型根节点，C-233#72）

`scenes/aquatic_park/aquatic_park_pier.tscn` 根节点：

- `Entrance`（Marker3D）：进码头的出生点；
- metadata `walk_polygon`：能走的地方；
- metadata `stand_polygon`：沿边能站着钓的一条带；
- metadata `fish_edge`：沿边的开放折线（内弯 → 圆台 → 外弯）；
- metadata `water_polygon`：线能落的水面；
- 子节点 `Bay` 的 y：水面高度（没有时读 metadata `water_y`，再没有按 −1.45）。

都是根节点本地 x/z 米制 `PackedVector2Array`。四条轮廓缺一条或模型还没合入时，`parcel_pier.gd` 换成一段直码头替身（同样四条轮廓）。

## 客户端

- 地图：`town_entry.gd` 的 `pier()` 是第二枚图钉（同华盛顿广场那枚：UiMapDestination + 短名、地点卡、Go），
  P0 海岸鱼塘图标 `pond_coast.svg`，位置 Aquatic Park 市政码头根部（37.8066, −122.4242）。一次只开一张地点卡；
  Go 先走地图行程（C-188），iris 合上后打开 `parcel_pier.tscn`。
- 码头（`scenes/dynamic_farm/parcel_pier.gd`）：农场镜头（43° 俯角、14.5° 偏航、同一人物比例，LOCK-24 ①），拖动是摇杆、
  点甲板走过去、两指缩放。点水面：走到离点击处最近的 `fish_edge` 点，朝点击方向投 1.5–5 m（落点退到水面上为止）。
  到了就锁住人物，P0 的钓鱼表现（姿势、竿、线、漂、上鱼弧线）和面板接手。左下鱼饵键：背包有鱼饵才出现，点一下换下一种，
  最后回到不挂饵。第一次进来发 `visit_pier`，飘 `Received Starter Rod ×1`。
- 面板（`scenes/dynamic_farm/parcel_fishing_panel.gd`）：P0 的单键流程（Cast → Hook → 按住收线），外观沿用 P0FishingPanel
  （收线条避开人物、Hook 键弹跳）；后端换成地块存档。
  P0 面板的按键和提示经 L10n 翻译，码头 `_ready` 把语言切成 en、离开时还原（同 `parcel_profile.gd`），
  中文系统的手机上也是英文（W-801 V-773）。
- Jasmine 柜台（`parcel_counter.gd`）：鱼按售价卖（背包格子里有就能卖）。到过码头后货架多出鱼竿、鱼饵：鱼竿一次买一根、
  买了这一行就不再出现；鱼饵步进器最多到当天剩的数；不到 4 级是灰键 `Farm Lv4 needed`，当天买满是 `Sold out today`；
  第三行写效果（鱼竿 `Short` / `Longer` / `Longest bite window`，鱼饵 `Faster bites`、`More Rare fish`）。货架超过 2 行时显示 2.5 行、可滚动，
  抽屉相应加高。
- 物品名和图标都是 P0 的（`Pond Crucian`…`Sea Bass`、`Starter Rod`/`Reed Rod`/`Carbon Rod`、`Worm Bait`/`Spinner Lure`）。
- 玩家可见英文按 PM 在 C-232#28 的定稿（C-45：简练、不加副标题、不写计算说明）。顶栏胶囊第二行 `San Francisco` 保留：
  其它地点（华盛顿广场驿站 parcel_outpost.gd）的位置芯片也是“地点名 / 城市”两行。
