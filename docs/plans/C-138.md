# C-138 胡萝卜 7 段生长，土块分干/湿（占位造型）

依据：所有者在 SEN-C-134#5 第 3、4 题的回答，参考图 SEN-C-134 attachment-1052 胡萝卜一栏（LS-01..07）。

## 阶段怎么切

- 7 段按参考图命名：翻土（Tilled soil）、播种（Sowing）、出苗（Emergence）、长叶（Leaf growth）、露肩（Root shoulders）、
  根变粗（Root thickening）、成熟（Maturity）。
- 第 1 段“翻土”就是翻过、还没播种的土块本身（参考图 LS-01 也是空土）。播种后立刻进第 2 段，玩家一按 Sow 就能看到种子。
- 播种到“根变粗”这 5 段平分从播种到成熟的时间（胡萝卜 60 秒，每段 12 秒）；到 `ripe_at` 进“成熟”，和能收获是同一刻。
  没有选“7 段都平分”的切法：那样成熟样子会比能收获早出现，播种后头一段又和空土一样，像没种上。
- 阶段只从存档里的 `planted_at` / `ripe_at` 算出来，不存进存档：存档格式不变，升级前已经在长的胡萝卜按已经长了多久落到对应阶段。
  种子、生长时间、收获数量和售价都没改（`assets/farm/data/dynamic_farm.json` 未动）。

## 土块

- 每块耕地画成单独的 1×1 土块（沿用主农场翻土块的造型和颜色，宽 0.92 格，块与块之间有缝），湿土是同一块、颜色更深。
- 还没有浇水玩法（规则在 SEN-C-137 定），游戏里一律显示干土。开发设置 `sensen/dynamic_farm/preview_wet_soil=true` 时全部显示湿土；
  模拟器 QA 包用 `GATHER_QA_WET_SOIL=1 tools/dev/dynamic_farm/gather_qa_apk.sh …` 打开它。以后接浇水时，按格传干/湿即可
  （`ParcelCropArt.sync` 的 `soil` 参数本来就是逐格的）。

## 代码

- `modules/dynamic_farm/parcel_crop_art.gd`：新的动态农场土块和作物渲染，每种土和每个阶段一个 MultiMesh。主农场的 `CropField` 不再被
  动态农场使用，本身没改，主农场不受影响。
- 占位造型拼自主农场胡萝卜网格（`crop_plant_mesh.gd` 的 `C` 叶丛和 `C_detail` 根，只读）加一组种子小点；SEN-C-139 的正式模型替换
  `_stage_mesh` / `_soil_mesh` 即可，阶段逻辑不用动。
- `tools/dev/dynamic_farm/crop_stages_probe.gd`：在本地存档上种出 7 段并排的一组胡萝卜；带设备时间参数时只写存档，推进模拟器 QA 包里查看。

## 模拟器核对（mac-mini，AVD Sensen_P0，arm64，headless，SwiftShader 软件渲染）

QA 包（`gather_qa_apk.sh`，p-3139010，本地存档，不连服务器）干土、湿土各一个。用探针写入按模拟器时间错开播种的存档，打开后截图：
前排 翻土 / 播种 / 出苗 / 长叶，后排 露肩 / 根变粗 / 成熟；湿土包同一画面土色更深。录屏 110 秒，能看到各格依次长到成熟。
