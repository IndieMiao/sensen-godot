# C-98 动态农场正式出包配置（邀请账号登录）

需求出处：C-95#5 拆解第 3 张；所有者 C-95#3“公开包(非tailscale) 但是有限邀请, 只有拿到账号的玩家才能测试”。
服务端材料 C-96（`ACCOUNT_SIGNUP=closed`、游客只读、不能重选），入口 C-97（`https://farm.sensenjoy.cn/dynamicfarm/v1`）。

## 出包

`tools/android/build_worker_apk.sh --dynamic-farm-release NEW_DIR`，在原有暂存流程上新增一个变体 `dynamic-farm-release`：

| 项 | 正式包 | 0.4.1 预览包（`--dynamic-farm`） | 内部包（`--dynamic-farm-internal`） |
| --- | --- | --- | --- |
| 包名 | com.sensen.dynamicfarm.cardigan | 同左 | com.sensen.dynamicfarm.internal |
| 显示名 | Dynamic Farm | Dynamic Farm Preview | Dynamic Farm Internal |
| 版本 | Android 预设（0.4.2 / 2026112401） | 同左 | 同左 |
| 用户目录 | DynamicFarmCardigan | 同左 | DynamicFarmInternal |
| Journey 地址 | 固定 `RELEASE_TARGET`，不接受参数 | `http://127.0.0.1:9`（关闭） | `APPROVED_TARGETS` 里的测试服 |
| `online_qa`（Net 不自启、不匿名登录） | 开 | 开 | 开 |
| `dynamic_farm/own_farm` | 开 | 无 | 开 |
| `dynamic_farm/account_restore` | 开 | 无 | 开 |
| `dynamic_farm/reselect` | 无 | 无 | 开 |
| `account/invite_only` | 开 | 无 | 无 |

权限、签名配置（暂存预设一律 `package/signed=false`）、架构、导出过滤沿用 Android 预设，和 0.4.1 相同。
包名、用户目录相同且 versionCode 更大，所以能直接覆盖安装 0.4.1。正式签名（与 0.4.1 同一证书）和外发归 C-99。

读回（`worker_apk.py verify/check-unsigned --variant dynamic-farm-release`）解析包里的 `project.binary`：
两个地址必须正好是 `RELEASE_TARGET`，三个开关为真，不能有 `reselect`、`fake_claims`、`local_farm_save`；
`invite_only` 或正式地址出现在其它任何变体里都拒绝。

## 登录

沿用现有登录面板（`scenes/account/account_panel.gd`）。`sensen/account/invite_only` 为真时：
- 登录页只显示邮箱、密码和 Sign in；不显示 Create an account、Forgot password?、Apple / Google。
- 切到注册或找回密码的请求一律回到登录页。
- 说明文字改为新文案（见下）。

没有账号时：地图照常浏览和 3D 预览；点地块显示“Sign in to claim a home.”和 Sign in 按钮，不能认领，也不能进自家地块。
