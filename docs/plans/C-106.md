# C-106 UI v3: dynamic farm map and sign-in panel

Design: C-85 page ⑤ Map and ④ Sign in, D-201 (package sha256 6d77ca71…, boards attachment-768 / -767), approved by
the owner in Q-124 (C-85#71 "通过"). Components and tokens: C-105 at 09be1f1c (tokens v3, `UiGlassButton`,
`UiTagPill`, kit command buttons, C-86 art). Dynamic farm package only; English only; no claim, sign-in, save or API
change.

## Map (`scenes/dynamic_farm/dynamic_farm_map.gd`, pieces in `map_ui.gd`)

- Top row: glass Back key, glass "San Francisco" chip (flies to the dataset's area as before), account chip at the
  right: signed in = avatar + name, signed out = lime "Sign in", checking / signing out = avatar + • • •.
- One hint capsule under the top row replaces the old top panel's status line and the bottom card's empty-state line.
  With nothing selected it shows the next step (C-35 / C-61 guide) instead of the selector's idle "Tap a building to
  preview a farm.", so a player without a home reads "Tap a building to choose your first home." once (C-88#5).
  Progress lines ("Finding parcel…", "Zoom in to choose a farm.", "Loading dynamic farm…") show there too.
- Parcel card: paper card with the header band, the C-86 parcel / home hero, tag "Parcel" / "Your home", address,
  cell counts, owner line with a dot (Not claimed grey, Your home green, Claimed by … red, You already have a home. /
  Sign in to claim a home. grey), the guide's step on the home's card, the overlapping parcels as a one-pick list, the
  same keys (Make this my first home, Enter my farm, Preview in 3D) and the internal give-up as a red text link.
- Claim confirm and sign-out confirm: centred dialogs over the modal scrim (claim with the parcel hero). While the
  claim is sent the card steps aside and a glass "• • • Claiming…" toast shows; claim / give-up failures show on a
  white toast with a red bar. A failed map / parcel / farm read shows on a white card with Retry. The kept-account
  notice (C-110) is a white toast with an amber bar and Retry under the top row.
- Side keys: locate (C-86 art) at the right over the card with My home (C-86 home art) above it, Market / Carpenter
  above those; the C-128 profile key at the left, level with locate. Credits (Mapbox, OpenStreetMap, DataSF) stay
  at the bottom left.

## Sign-in panel (`scenes/account/account_panel.gd`, look in `account_v3_look.gd`)

- `AccountPanel.open(host, mode, reason, true)` builds the v3 look; only the dynamic farm map passes it. The main farm
  (city select, map_poc) keeps the classic look.
- Blurred scene under a light scrim, 312 wide paper card near the top with the header band, the sign-post hero, the
  step's name in a tag pill and ✕ (hidden behind the login wall as before). 46 high white fields, focus and error
  outlines, an in-field "Show" key on each password field (the hidden "Show passwords" box still drives them),
  "Forgot password?" right-aligned above the lime primary key, the error line under it (its two lines still reserved,
  C-78), step links as text links, providers under an "or" rule as full-width keys, the 6-digit code as six boxes
  over the same field, the primary key reading • • • while busy, errors about no field (no network, rate limit,
  Google / Apple unavailable, code cooldown) on a bottom toast with a red bar.
- Every mode, field name, action id, validation and request is unchanged; Enter submits the primary key by id.

## Choices the board left open (author defaults)

- A tap on the signed-in chip opens the existing "Sign out on this phone?" confirm (now the v3 dialog), not the whole
  account panel: the map's sign-out keeps its guest continuation (C-100) and ownership refresh unchanged.
- "Already have a home" and an unclaimed parcel keep the existing Preview in 3D key (the board's small card drew a
  greyed claim key instead); a too-small parcel still clears the selection, so its line is in the hint.
- No "Sensen Farm" wordmark (C-85 README §5.5: placeholder, final wordmark not in this card); profile step keeps the
  gender drop-down (five options) and adds no "Later"; account / password / delete steps take the v3 shell and keys
  only (their list style is C-108's settings page).
- The chip's avatar is the existing player portrait (the board's stand-in); there is no per-account avatar yet.
