# C-35 0.4.2 串联与测试包：认领→盖房→种收

把 C-31～C-34、C-73、C-74 串成前 10 分钟：打开地图 → 认领第一块地 → 进入地块 → 放 cottage → 清障开垦 → 种萝卜 → 收获。
不新增玩法、不改已批规则和数值。

## 版本

`export_presets.cfg` 的 `Android` 预设：`0.4.1 / 2026112301` → `0.4.2 / 2026112401`。依据 C-29 规则
（`tools/android/README.md`：名称保持 0.4.x；versionCode 为改版当天 `YYYYMMDDNN`，NN 从 01 起），实际外发只有
0.4.1 / 2026112301（C-36#95），2026112401 大于它和 2026092405，可以覆盖升级。包名、签名、权限、其它导出参数不改。
