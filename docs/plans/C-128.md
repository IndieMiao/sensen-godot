# C-128 老界面接线：个人主页、设置、换装接回动态农场包（0.4.4）

所有者 11-25 原话（C-82#50 转录）：“我需要在0.4.4看到地图农场3D空间的主要界面都已经调整过, 以及老的界面(个人主页,设置,换装)等已经重新接线回来”。
本卡只接线，不做三页的新设计（C-108，0.4.5），只做英文。

## 入口

动态农场地图左下角新增一个圆形“个人”键，和右下角的定位键同一高度、同一样式（farm-dev 定位键的圆键、浮起阴影、白色图标），
图标用项目里现有的 lucide `user-round`。没有放进顶部面板：顶部面板在 360 宽的屏幕上已经接近排满（C-123 正在处理
`Loading…` 撑宽面板的问题），实测再加一个 `Profile` 文字按钮，按钮行最小宽度 381，超出可用的 312；放在标题旁边会把
`Dynamic Farm` 挤成两行。圆键不改顶部面板，也不和 C-115（去掉 Market / Carpenter、加联合广场圆钉）改的那几行重叠。
点开后在地图上盖一层（`scenes/dynamic_farm/parcel_profile.gd`），结构照 P0 的 HUD 头像入口：

- 个人主页：P0 的全屏 `P0ProfilePage`（清单 197 锁定的全屏个人主页）。
- 设置：个人主页右上齿轮，P0 的 `P0SettingsPage`。
- 换装：个人主页 `Edit look ›`，现有换装间（`scenes/dressing_room`），经 AppRouter 压栈到地图上。

‹ 和安卓返回键逐层返回，个人主页再返回就回到地图。打开期间地图面板隐藏、地图镜头不接手势（与市场、木匠同样处理）。

## 每页显示什么（默认值，知会）

只显示动态农场里有数据、有作用的部分，按 P0 原有的做法“没数据的块不显示”（`P0ProfilePage` 头注释）：

- 个人主页：顶栏（‹ Profile ⚙）、穿搭预览和 `Edit look ›`、名字（已登录用账号昵称，未登录 `You`）。
  技能、农场卡、收集、Voice Profile 不显示：动态农场没有这些数据。`P0ProfilePage` 新增 `blocks` 参数，P0 默认照旧全显示。
- 设置：只有 Legal 组：`Licenses ›`、`Version`（读到包版本时才显示）。
  `Licenses › Mapbox` 进 Map data，其中 `Share anonymous map usage` 是地图 SDK 自己的开关，改了立即生效（`MapUsage`）。
  不显示：Test options（P0 测试账号）、Language（只做英文）、Notifications（P0 作物提醒）、Home city、Blocked players、
  账号组与 Sign out / Delete account（登录、退出仍在地图顶部面板；删号涉及删除数据，不在本卡加）。
  `P0SettingsPage.settings` 新增 `show_tests` 参数，Version 传空串时不显示该行；P0 调用不变。
- 换装：现有换装间原样。Done 保存穿搭（本机存档，格式不变），地块里的玩家和个人主页都跟着保存的穿搭；
  回到个人主页时显示 `Look saved`（P0 现有文案）。Back 放弃改动。

没有新增文案：入口是图标键，三页都是 P0 页面和换装间原有文案。

## 只做英文

动态农场包里 Journey 的中文表仍在加载，默认语言是 zh_CN（地图自己的标签关了自动翻译）。
P0 页面和换装间会被翻成中文，所以这层打开期间把语言设为英文，关闭时恢复原值。

## 打包

设置 › Licenses 用 P0 的许可清单和原文（`assets/p0/legal/`），这些不是资源文件，已加进动态农场包的 `RAW_FILES`。

`tests/dynamic_farm/test_parcel_profile.gd`（无头，真实地图场景、AppRouter、Avatar）：入口、三页打开和返回、
设置里没有不适用的行、Map data 开关生效、换装 Done 保存后穿搭读回一致、`Look saved`、返回键逐层、语言恢复。
