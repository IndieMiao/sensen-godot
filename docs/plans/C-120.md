# C-120 装上即建号对外开放前的加固

作者：张衡·森。来源：C-100 代码审核 V-259 和独立复核 V-260 的建议（C-100#40、C-100#43）。放弃重选按钮的处理由所有者在 Q-156 选定 hide。
本卡不改 `PARCEL_GUEST_WRITES` 的默认值（仍关，正式 compose 仍写死 `"0"`），也不改闲置回收的范围（仍只收游客，Q-129）。

## 1. 匿名建号额度：三层

新安装第一次 `/v1/auth/anonymous` 要三层都还有额度才建出玩家，从细到粗依次扣：

| 层 | 口径 | 默认 | 环境变量 |
| --- | --- | --- | --- |
| 每个网络 | IPv4 按地址，IPv6 按 /64（C-100 原样） | 10 / 小时 | `ANONYMOUS_SIGNUPS_PER_NETWORK_HOUR` |
| 每个地址段 | IPv6 按 /48；IPv4 仍按地址 | 50 / 小时 | `ANONYMOUS_SIGNUPS_PER_BLOCK_HOUR` |
| 合计 | 整个进程 | 1000 / 小时 | `ANONYMOUS_SIGNUPS_PER_HOUR` |

- 不设或空为默认值；只能是 1–1000000 的整数，其它值进程拒绝启动。启动日志打印 `anonymous_signups=10/50/1000`。
- 已有安装再次登录不占任何一层，仍只受每个安装每小时 10 次的登录限制。
- 先扣后建，每层的计数是原子加一，所以并发的第一次登录不会超过任何一层。
- 从细到粗：某个网络超出自己的 10 个以后，后面的请求不再占 /48 和合计的额度，一个来源刷不光别人的额度。被粗的层拒绝的请求已经占了细的层，偏保守。
- 换转发头绕不过：网络取 Fastify 的 `req.ip`，只信 `TRUSTED_PROXIES` 转发来的地址（C-100 原样）。
- 限流存储每层最多 5000 个 key 的问题：合计层只有一个 key，挤不掉；所以无论 /64、/48 的计数是否被挤掉，一小时新建的匿名玩家数都不超过合计上限。
- 选 /48 而不选 /56：/48 是常见的“一个站点”分配，一个 /48 里有 256 个 /56，按 /56 汇总时手里有 /48 的来源仍能放大 256 倍。默认 50 = 5 个满额的 /64，移动网络同一 /48 下的多台设备一小时 50 个新装足够；不够时调环境变量。
- 合计 1000：正式服只跑一个 app 进程；开放后量起来时运维调大。合计用满时这一小时所有新安装都会收到 429，客户端回到地图时会重试。
- IPv4 不加按 /24 的汇总：IPv4 地址本身就贵，而运营商 NAT 常把大量用户放在同一个 /24 里，误伤大；合计上限兜底。

## 2. 闲置判定：最后活动时间记到玩家身上

C-100 的判定是 `GREATEST(players.last_seen_at, 现存 token 的最大 last_used_at)`。token 被删掉（退出这台设备 `DELETE /v1/auth/token`、退出全部设备 `DELETE /v1/auth/tokens`、换安装密钥、90 天未用过期、账号相关的撤销）后，这段活动就没了。

现在所有删 token 的地方都走同一条语句 `deleteTokensSql`：删 token 的同时把删掉的 token 的最大 `last_used_at` 写到 `players.last_seen_at`（取较晚的）。删除和记录在同一条语句里，回收语句读到的要么是 token 还在，要么是玩家身上已有记录，不会两头都没有。登录时签发新 token 淘汰旧 token 的那两处不用记：同一事务里 `last_seen_at` 刚设成现在。内存存储同一口径。

- 判定条件和临界值不变：最后活动时间严格早于“现在减 N 天”才收。
- 没有迁移：只改写已有列 `players.last_seen_at` 的值（它现在是“最后一次登录或最后一次用已删掉的 token”）。回退到旧镜像时，旧代码照常读这一列，只会比原来更晚收回，不会更早。

## 3. 游客不显示“放弃重选”（Q-156 hide）

- `ClaimController.guest`：没有账号（本安装的游客或未登录）时为真。地图在登录完成、账号切换（登录、退出）后按 `Net.account.signed_in()` 同步。
- `can_give_up()` = 内部包开关 `reselect`、不是游客、有家。按钮只在它为真时显示；`abandon()` 也先看它，游客不会发出这个请求。
- 不加任何提示文案；绑定账号后按钮出现。服务端规则不变：游客调放弃仍返回 401。
