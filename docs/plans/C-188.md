# SEN-C-188 地图移动表现：头像沿曲线移动

依据：所有者 SEN-Q-283（“在地块之间的移动可以按照 187 的方案以头像的形式进行曲线移动”）；SEN-C-187 第 2 版设计 D-437
（故事板 attachment-1657、动效参数 attachment-1658、原型 attachment-1660）；PM 在 C-188#13 定的两条（只用在真正出发的路线上；
头像锚在现有圆钉和家位置的右上角，偏移放配置）。

## 实现

- `scenes/dynamic_farm/map_travel.gd`：地图上的头像和出行表现，只是 Godot 叠加层（不改 Mapbox 原生层、不加请求、不写存档）。
  头像位置只记在本次运行内存（`MapTravel.at`，冷启动在家；换家或没有家时回到家）。
- `assets/map/map_travel.json`：全部参数。动效说明表 4 的数值原样照搬；另加了表里没单列、但时间线上有的数
  （头像弹起 1.1 倍/上移 6、目的地浮动 ±2 周期 800、收口前停 120、顶部淡入 120、落位 0.6→1、跳过 120、取消 200、减少动效 120）。
- 锚点（PM C-188#13，可调）：`token_offset_pin` = (+16, −52)，相对圆钉的地理点（圆盘底边中点），头像尾尖落在圆盘右上；
  圆钉被放大（选中 1.6、到达弹跳）时偏移跟着放大。`token_offset_home` = (+12, −35)，相对家的中心点。
  收口和波纹圆心 `iris_center_pin` = (0, −20)，即圆盘中心；家用中心点。
- 路线：两端是两处头像的尾尖；二次贝塞尔，拱起 = 两点距离 × 0.18，拱向屏幕上方；底层白 7px 90%、上层 #7DAA32 3px，虚线 9/6。
  每帧按地图投影重算，拖动和缩放时跟着走。
- 去 Washington Square：Go → 地点卡淡出缩到 0.94（160）→ 有一端出了安全区就用现有 `fly_to` 框住两点（zoom 15–18）→
  画线 360 / 头像弹起 160 → 沿弧线小跳行走 clamp(0.9+0.8×km, 1.2, 2.4) 秒，圆钉上下浮动 → 到达：圆钉弹 1.18（220）+ 白色波纹（420）
  → 停 120 后以圆钉为圆心收口 380（#E7F0DF）→ 开房间。房间在出发时就用线程预载；收口时已就绪直接推入，没就绪就在同色底上显示
  现有 Loading（`loading_overlay.gd` 新增 `loading_backdrop`）。
- 回到地图：圆形从该圆钉展开 320，顶部栏和提示在最后 120 淡入，头像 0.6→1 落位在该圆钉右上。
- Enter my farm（家地块卡）：开始读农场的同时，头像从所在处走回家（已在家就不走）；读好后在家收口 380 再进农场（替代原来的硬切）。
  读农场失败：出行取消，头像回到出发处，卡片和错误提示照旧。
- Preview in 3D（别人的地块）不变，没有路线和收口（C-188#13 第 1 条）。
- 行走中点屏幕任意处：120 内走到终点再接到达；行走中按返回（系统返回或左上 Back）：头像沿线退回出发处（200），房间预载丢弃；
  到达之后返回键等场景打开。App 退到后台时，行走中的出行直接取消。
- 减少动效（`UiMotion.reduced`）：不画线、不走、不弹、不浮动、不框镜头，头像直接在终点，收口和展开换成 120 淡入淡出。
- 入口图标、地图圆钉（LOCK-24）和统一入口徽章都不改；圆钉只在出行时临时上浮、弹跳，结束复原。
