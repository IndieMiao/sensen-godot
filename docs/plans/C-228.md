# C-228 · 0.4.7 蓝图册实现

依据：所有者 SEN-C-214（“目前建造是纯线性的 靠屏幕左下角的按钮, 改为更加灵活的使用蓝图”），拆解方案第 3 版第 9 张；
设计稿 SEN-C-227 D-555（README §2–4、图 1、2、4），所有者 SEN-Q-344 按建议通过：R1、R2、D1–D5。
锁定组件范围开工前写在 C-228#10。

## 做了什么

- 左下原 `Build <名字>` 键原位改为 `Blueprints` 键（180×48 泥塑侧键不变）：蓝图卷图标 + 文字 + 右端奶白圆片写包里蓝图总张数（0 张不画）。
  显示条件（R2）：自家地块已加载，包里有蓝图或院子里有建筑；蓝图册打开和摆放时隐藏。张数变化时圆片弹一下（1→1.15→1，200 ms）。
- 蓝图册 `scenes/dynamic_farm/blueprint_book.gd`：背包同款 UI v3 ModalPanel（`Blueprints` 标签、头图、✕、遮罩、返回键关闭）。
  每种包里有蓝图的建筑一张 248×128 卡，按规则表 `buildings` 的顺序，不因能不能盖换位置；超过屏高 80% 纵向滚动。
  卡片：蓝图纸底 + 建筑缩略图 + `×N`、名字、材料 NEED-TILE S、一个键：`Place` / `Need N more <材料>` / `Farm Lv%d needed`。
  灰键只抖动并闪缺的那一格，不发命令。没有蓝图时只写 `No blueprints`。
- 缩略图 `scenes/dynamic_farm/blueprint_thumbs.gd`：每种建筑一个 SubViewport，用摆放预览同一个模型、户外 43°/14.5° 正交镜头渲染一次并缓存。
- 点 `Place`：蓝图册淡出 120 ms，进入这种建筑的摆放预览（任意一张，不再由规则表第一种决定）；左上头像下方深色玻璃芯片写正在摆的建筑名。
  `Rotate` 模型 160 ms ease-out 转过去（格子立即按新朝向判定）。`Build` 成功回到农场；`Cancel` 和系统返回键回到蓝图册原滚动位置。
  镜头和人物保持现状（R1）。
- 蓝图不再进快捷栏（D4），仍在背包里。
- 引导文案（草稿，按 C-45 由 PM 定稿）：`Tap Blueprints to place your first home.` / `… your well.` / `… your coop.`。
- 头图 `assets/ui/v3/hero/hero_blueprints.png`：C-227 设计包 `src/shots/hero_blueprints.png`（256×256，attachment-2114 的入库尺寸）。

`server/test/parcels/farm.test.ts`「blueprint book: any blueprint in any order (C-228)」三种顺序盖五种建筑；没有蓝图、压到别的建筑 / 耕地、
木材或石头不够时整批拒绝、传入存档不变（含批里前一条已成功也不保留）。

## 默认值（可配置）

| 参数 | 值 | 位置 |
|---|---|---|
| 卡片尺寸 / 间距 | 248×128 / 10 | `blueprint_book.gd` `CARD` / `CARD_GAP` |
| 面板最高 | 屏高 80% | `MAX_SCREEN` |
| 蓝图纸色 / 格距 | #4F7FB3 / 12 px | `PAPER_COLOR` / `PAPER_GRID` |
| Place → 预览淡出 | 120 ms | `dynamic_farm.gd` `BOOK_FADE_MS` |
| 张数弹跳 | 1.15，200 ms | `COUNT_BUMP` / `COUNT_BUMP_MS` |
| Rotate 转动 | 160 ms ease-out | `building_placement.gd` `TURN_MS` |
| 缩略图渲染尺寸 | 184×224 | `blueprint_thumbs.gd` `SIZE` |

## 没做的

- 蓝图册底部 `Arrange` 键、整理模式、移动和收回：C-229。
- 设计稿里“镜头 350 ms 缓动到起始位置、模型淡入 160 ms”沿用现有摆放进入方式（镜头直接对准、模型直接出现），未加缓动。
- 已到等级上限且没有更高等级能放开的类型（如多出的小屋蓝图）不进蓝图册，没有可显示的键。
- 引导文案按存档里还缺什么出（原有逻辑就是读存档）；牛棚、羊圈没有引导条，未新增。
