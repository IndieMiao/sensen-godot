# C-32 地图：认领第一块地与地块三色（0.4.2，安卓）

规则出处：q(339)、q(341)、q(342)（所有者答复 C-30#8、#10、#11）。接口按 C-31 的 `docs/plans/C-31.md`。

## 分工

| 文件 | 做什么 |
| --- | --- |
| `modules/dynamic_farm/map/claim_api.gd` | 调 C-31 的 `/parcels/mine`、`/parcels?ids=`、`/parcels?bbox=`、`/parcels/claim`、`/parcels/mine/abandon`，结果整理成 `{ok, status, code, …}` |
| `modules/dynamic_farm/map/claim_controller.gd` | 记服务端回答的归属，推给原生的 own/claimed/selected 状态通道和认领者名字图层；不自己判定能否认领 |
| `modules/dynamic_farm/map/fake_parcel_server.gd` | C-31 未合并前的假服务端，状态码与 C-31 相同；只在 `sensen/dynamic_farm/fake_claims` 打开时用 |
| `scenes/dynamic_farm/dynamic_farm_map.gd` | 底部卡片按钮与文字 |
| `tools/android/overlay/ParcelMapController.kt`、`ParcelPayload.kt` | 地块按 feature-state 上色；认领者名字改为按地块标注 |

选择逻辑（`selection_controller.gd`，C-28 在改）本卡不动。

## 三色

| 状态 | 地图上 |
| --- | --- |
| 自己的 | 整块地块绿色填充 `#3E9B55`（42%，选中时 60%）加绿色边线 |
| 别人的 | 红色填充 `#D2493F`（36%，选中时 55%）加红色边线，地块上标对方昵称（无昵称时写 “Claimed”） |
| 可认领 | 点中建筑时沿用 C-28 的黄色建筑形状填充；没被认领的地块平时不画 |

选中自己或别人的地块时，客户端清掉黄色建筑高亮，免得黄色盖在绿/红上。

名字图层原来是按中心点画的点图层，但 C-31 的归属查询不返回中心点，所以改为在地块面上用
`match block_id → 昵称` 的文本表达式标注。昵称只作为字符串字面量放进表达式，不会被当成表达式执行
（`ParcelPayloadTest`）。原来的蓝色圆点图层删除。

## 卡片

| 情况 | 底部卡片 |
| --- | --- |
| 无主，自己还没有地 | “Make this my first home” → 确认行 “Claim this parcel? You can only have one home.” + “Claim” / “Cancel” |
| 自己的 | 文字 “Your home”，按钮 “Enter my farm”（暂时打开同一个三维预览，进入自家地块由 C-33 接） |
| 别人的 | 文字 “Claimed by 昵称”，只保留 “Preview in 3D” |
| 无主，但自己已有地 | 文字 “You already have a home.”，没有认领按钮 |
| 内部测试包且是自己的 | 另有 “Give up and choose again” |
| 未登录 | 文字 “Sign in to claim a home.” |

未登录时读不到归属，卡片照样显示 “Sign in to claim a home.”；第一次读自己的地失败时，选地块会重读一次。
归属列表最多留 1000 条（保留自己的地和当前选中），远低于原生 3000 条上限。

其它提示：“Claiming…”、“Someone just claimed this parcel.”、“Could not claim. Try again.”、
“Could not give up this home. Try again.”。全部新文案待所有者批复。

## 内部包与正式包

“放弃并重选”入口只在 `sensen/dynamic_farm/reselect=true` 时显示。`project.godot` 不设这一项，
由内部测试包的打包配置写入；正式包没有入口。服务端另有一道：没设 `DYNAMIC_FARM_RESELECT=1`
时放弃接口一律 403。
