## 地图显示（`tools/android/overlay/ParcelMapController.kt`、`ParcelPayload.kt`）

| 图层 | 改前 | 改后 |
| --- | --- | --- |
| 地块填充 `gensen-parcel-fill` | 自己的绿、别人的红，整块地 | 永远透明，只留给点选用（不能删、不能 `visibility:none`） |
| 地块边线 `gensen-parcel-line` | 自己/别人/选中时描边 | 删除 |
| 建筑块填充 `gensen-parcel-building-fill`（DataSF） | 深褐 16% | 平时透明；自己的地块里的建筑绿 55%（选中 75%），别人的红 50%（选中 70%） |
| 建筑块深色边线 `gensen-parcel-buildings` | 深褐 1.3px | 删除（截图 703 的“深色带框层”） |
| 选中高亮 `gensen-selected-building-fill` | 黄 65% | 不变（只在可认领时出现，C-32 规则不变） |
| 选中描边 `gensen-selected-building-line` | 橙色 2.5px | 删除：描边一半画在楼外，会超出建筑块 |
| 地址、认领者名字 | 文字 | 不变 |

颜色全部是填充，填充只画在多边形内部，所以任何颜色都不超出建筑块。颜色和透明度是作者默认值，在 `ParcelPayload.kt` 顶部集中定义。

建筑块的颜色按地块编号查：`["match", ["get","block_id"], [自己的地块…], 值, …, 默认]`，地块状态一变就整层重设一次。
`match` 是按编号直接查表，归属列表再长也不会每栋楼逐条比较。原来的 feature-state 只能给地块层用（建筑块是另一个数据源），
所以不再写 feature-state。

透明而还要能点中：两层的透明度都写成依赖要素的表达式（地块层沿用一直以来的 feature-state 表达式，建筑块层是上面的 `match`），
不写常数 0。改前没被认领的地块就是这样透明又能点中的（C-28/C-32）；常数 0 有被 Mapbox 移出点选索引的风险，未在设备上试。

Mapbox 底图仍是默认 Streets，只在地块图层装上时隐藏它自带的地点图标层：`poi-label`（商店、学校等）、`transit-label`（车站）、
`airport-label`、`natural-point-label`（山峰等）。路名、街区名、道路编号牌照常显示。地块图层清掉时恢复原来的可见性。

只对 DataSF 建筑源（`config.json` 当前用的）上色。备用的 Mapbox 建筑源没有地块编号，选中高亮照旧，自己/别人不上色。

## 视角操控（`modules/dynamic_farm/map/geo_native_camera.gd`）

数值都取自 farm-dev 地图 `map_poc.gd`：

| 操作 | 做法 |
| --- | --- |
| 拖动后抬手 | 继续滑，速度按 `exp(-4·dt)` 衰减，平滑系数 0.35，低于每秒 2 像素停 |
| 双指缩放后抬手 | 缩放继续，同样衰减，低于每秒 0.05 级停；双指里最后抬起的那根手指不会把地图甩出去 |
| 双击 | 0.3 秒内、相距 32 像素内的第二次点击，以画面中心放大一级，0.25 秒；第一次点击照常点选 |
| 双指上下移动 | 每根手指每像素倾斜 0.1°，0°～70°；一指上一指下（竖向捏合）不倾斜 |
| 按下 | 停住惯性、双击缩放和飞行 |
| My home、San Francisco、定位键 | 像 farm-dev 的回家键一样飞过去（`MapFlight`，三次缓入缓出，最长 1.2 秒）；进地图第一次取景仍是直接跳 |

双指缩放仍以两指中点为锚（改前就是这样），farm-dev 是以画面中心；其余同 farm-dev。

倾斜后：拖动时按下的那块地面一直跟着手指（与 farm-dev 的“抓地拖拽”相同），每一步最多移动一个视距。
`screen_geo` 按 Mapbox 的相机算（视场 36.87°，相机离中心 1.5 个画面高），单测拿同样摆放的 Godot `Camera3D` 对照，误差小于千分之一。
点选本来就由原生 Mapbox 按它自己的倾斜相机做，所以倾斜后点哪栋就选哪栋。
取景框（按画面范围读认领者）：倾斜时远端可能接近地平线，范围限制在以中心为准、认领接口允许的跨度内，只读近处。
