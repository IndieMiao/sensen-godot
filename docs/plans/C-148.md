# C-148 动态农场体力（0.4.5）

依据：所有者在 SEN-C-137#15 第 3 题答“照搬p0”；拆解见 SEN-C-137#20 第 1 张。数值来自
`assets/p0/p0_content.json`（energy、blessing、day、crops.crop_carrot.energy）和 `server/src/p0/rules.ts`。

## 数值（`assets/farm/data/dynamic_farm.json` 的 `energy`，可调）

| 项 | 值 | P0 出处 |
|---|---|---|
| 上限 | `max_base` 200，农场每级 `per_level` +10（等级在 C-152 做，现在按 1 级） | energy.max_base；homestead.energy_steps |
| 恢复 | 每 `regen_ms` 240000（4 分钟）+1，按服务端时间算，下线也回，满了停 | energy.regen_ms；rules.ts settleEnergy |
| 新手期 | 首次进入自家地块后 `blessing.days` 7 天，恢复快 `regen_mult` 1.5 倍（2:40 一点） | blessing |
| 休息 | 有小屋，每个玩家日一次，+`rest_amount` 60，不超过上限 | energy.rest_amount；reducer.ts rest |
| 玩家日 | 当地时间 `day.utc_offset_hours` −8（旧金山标准时间）的 `day.rollover_hour` 4 点换日 | day.rollover_hour |
| 价格 | 清障碍 2、开垦 2、外围采集 2（`costs`）；播种按作物（`crops.crop_carrot.energy` 3）；收获、出售、领蓝图、放房子、休息 0 | 卡片目标；crops.crop_carrot.energy |

玩家日用固定 −8 小时，没跟夏令时：夏令时期间换日在当地 05:00。P0 按家城时区（IANA）换日，Godot 没有时区库，
客户端要算同一个日子，所以这里用固定偏移，写在配置里可改。

## 存档

地块存档 `farm.energy = { value, at, rested_on }`：`value` 当前体力，`at` 上次结算的服务端时间（满条时就是结算时刻），
`rested_on` 最近一次休息的玩家日 `YYYY-MM-DD`，没休息过为 `null`。和 C-58 的经济字段一样是在 v1 上追加的可选字段，
不改版本号：没有这个字段（C-148 之前的存档、刚认领的空农场）按满体力读，其余内容不动；第一次有命令写入时才写进存档。
接口返回的 `parcel.farm` 总带 `energy`（缺的按满补上，只补显示不写回）。换数据集（C-136 rebase）不动体力。

## 命令

- 每批命令先把体力结算到服务端当前时间；每条命令先做它自己的检查，再看体力；不够返回
  `422 { code: "NO_ENERGY", index, detail: { need, have, next_in } }`，整批不写，`farm_version` 不变。
- 新命令 `{ "type": "rest" }`：没有小屋 `NO_HOUSE`；今天休息过 `RESTED_TODAY`（`detail.resets_at` 下次换日）；
  满体力 `ENERGY_FULL`。服务端不知道人站在哪，只核实小屋已经盖好；“在小屋门口”由客户端限定。

## 客户端

- `modules/dynamic_farm/parcel_farm.gd` 照服务端 `server/src/parcels/energy.ts` 再写一份；
  `tests/dynamic_farm/fixtures/energy_cases.json` 的 20 个用例在服务端测试和客户端测试里各跑一遍，结果都要等于文件里记的。
- 顶栏：P0 HUD 的体力条（LOCK-06）。它从 `UiHud` 拆成独立组件 `UiEnergyChip`，P0 HUD 改用这个组件，外观不变。
  点它打开 P0 的体力面板（LOCK-09），只列 Rest 和新手期（吃饭在 0.4.7 做）。
- 主行动键：要花体力的写价格 “2 Energy”；不够时变琥珀色写 “Need 2 Energy”（LOCK-10 缺口写在按钮上），
  按下不发命令，弹 P0 的体力卡（LOCK-09）。体力卡的 Rest 块写 “Show home”，点了只把镜头转到小屋。
  收获不写价格（LOCK-02：0 体力不写价）。
- 休息：小屋门那一排格子的主行动键是 “Rest”，第二行写实际能回的 “+60 Energy”；按下走到门口再发 `rest`。
  今天休息过写 “Rested today”，满了写 “Energy full”（P0 的文案）。
- 花掉和回来的体力飘字 “−2 Energy” / “+60 Energy”（P0 的两种颜色）。

LOCK-10 的适用范围写在 SEN-C-148#9。
