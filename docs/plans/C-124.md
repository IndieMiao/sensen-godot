# C-124 建筑源复用加固

承接 C-118 审核 V-290、V-293 的两条建议。C-118 的复用（同一地址、源还在就不重新下载）保持不变。

## 一直加载中时，超时和 Retry 换新源

- `selection_controller.gd`：建筑层 45 秒没加载完（`buildings_source_timeout`），或玩家点 Retry 重载地图时，
  下一次设源的配置里带 `refetch_buildings: true`，只带这一次。超时后切去 3D 再回来，也由回来的那次带上。
  其它地图错误的自动重载不带，正常暂停、恢复也不带。
- `ParcelPayload.kt` 解析这个可选布尔值；`ParcelBuildingsSource.plan(..., refetch)` 在源还没加载完时返回 REPLACE，
  已加载完的仍然 REUSE。

## 换源后旧源的迟到事件不算到新源

- 建筑源编号改为 `gensen-buildings-datasf-<n>`，每加一份新源 n 加一；复用时编号不变。
  `markLoaded` / `markFailed` 只认当前这份的编号，被换掉的旧源发来的完成或出错事件不改变新源的状态，
  也不会再向游戏报建筑源出错（旧编号已不在当前的源表里）。
- 日志：`DYNAMIC_BUILDINGS_SOURCE ADD/REUSE/REPLACE loaded=… refetch=…`，旧源事件记为 `STALE LOADED` / `STALE FAILED`。
  `tools/dev/dynamic_farm/crash_repro.sh` 汇总时多一行重新下载次数和被忽略的旧源事件数。
