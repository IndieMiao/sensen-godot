# C-250 · 码头场景显示体力

刘邦·森，2026-11-28。卡片目标与验收以 SEN-C-250 为准；本文只记做法。

## 来源

- SEN-C-232 已知差距（docs/plans/C-232.md「码头上没有体力显示」，C-232#111）。
- 锁定组件范围：C-250#6（LOCK-06 只复用）。

## 做法

- `scenes/dynamic_farm/parcel_pier.gd` 顶栏：返回键、地点胶囊之后加一枚 `UiEnergyChip.new(true)`，即农场顶栏的
  奶白泥体力胶囊（C-186），结构、颜色、文案原样；两段泥连接条搭在地点胶囊右边。没有新的玩家可见文案。
- 数值：`energy_now()` 照 `ParcelFarming.energy_now` 用地块存档按服务端时间结算（`ParcelFarm.settle_energy`、
  `max_energy`、`next_tick_in`），第三行 `+1 in m:ss` / `Full` 同 `ParcelFarming._refresh_energy`。
- 刷新：每帧 `_process` 跟一次（倒计时在两次回包之间本地走）；`_adopt` 收到新存档时立刻跟一次，所以投竿扣 5、
  脱钩退 3、收线前全退 5 都在回包当帧显示。
- 变色：`next_cost` 传 `fishing.cast_energy`（5）：不够投一竿时琥珀，0 时红，其余同农场。
- 码头上点胶囊不弹体力面板（LOCK-09 不在本卡）。

## 测试

`tests/dynamic_farm/test_parcel_pier.gd` 加：胶囊在顶栏地点之后、是泥胶囊、360 宽屏放得下且不压地点胶囊；
初值等于存档（满 `Full`）；第一竿投出后当场少 5、第三行变 `+1 in`；收线后跟存档；4 / 0 / 5 体力时琥珀 / 红 / 正常。
