# C-105 UI v3 framework: tokens, kit reskin, dynamic farm HUD / quick bar / bag / NPC card, base motion

Spec: `docs/design/ui-v3-2026-11-24/README.md` (C-84 D-177, owner Q-121 "按方案定稿"); tokens
`docs/design/tokens/tokens-v3.json`. Dynamic farm package only; English only; no gameplay or save change.

## What changed

- `tools/ui/gen_theme.gd` reads tokens-v3 over v2. v2 names in `ALIASES` take the v3 value (paper, ink, lime action
  colour, danger, scrims, card / sheet / cell / pill radii), so every kit screen recolours. All v3 tokens get their own
  constants; collisions with a v2 name of another meaning keep the v2 value and give v3 a `_V3` suffix (P0 HUD avatar,
  quick slot size, cream float pills stay).
- Implementation choices (author, per §2.1's contrast rule): `COLOR_PRIMARY_INK` #4A7318 for text in the action colour
  (lime text would be 1.9:1); white-on-lime buttons and the CTA bar carry the §2.1 outline (Q-121 item 1) except when
  disabled; the bag shows at least 3 × 3 slots and no "+" slot (there is no bag expansion in the game).
- New kit pieces: `UiMotion`, `UiGlassCapsule`, `UiGlassButton`, `UiTagPill`, `UiBagSlot`, `UiModalPanel`, `UiNpcCard`,
  `UiGainFloat`; `UiCommandButton.bar` (CTA) and M-01 press on command buttons; glass quick bar and slots.
- Dynamic farm: glass top bar (back, name, coins), glass quick bar, bag as the v3 modal panel with the quick bar hidden
  while open (M-16, C-L4 / V-239 note 2), v3 gain floats, Jasmine / Scott in the v3 NPC card (copy unchanged).

- Quick bar geometry: LOCK-04 / 05 structure kept (five 52 × 68 slots with names, Bag end, pins); v3 look only.
- Main farm (P0) screens: recoloured through the aliases only, layouts unchanged.
