# 419 等锅蒸汽补开 · 排版规格 v1（不知火舞 11-09，SGODOT-449）
依据：哪吒红色测试（449）：渲染和遮罩都正常，看不见是因为「框顶 y150 到盖顶约 y195 只剩约 29 px」+「粒子太小太淡」，红色只占 x186–193 / y159–198 一条约 8 px 宽的细线。
现状：419 规格 v1 锅占位框 x80–280 / y150–330，锅口 (180,235)，火候环以锅口为中心（y175–295，金区 r40–52）；HUD 位置条底约 y92（360×800）。蒸汽 v1.2 已在 farm-dev，Steam 节点关着。

## 1. 选「框顶上提」，不选「锅沿两侧」
- 两侧：锅身左右到框边各只剩约 30 px，而且正好是火候环左右两段（x128–232 外沿），蒸汽会糊在环上、和金区抢眼。
- 上提：只给蒸汽单独加一个竖条区域，锅、环、倒计时、进度条的位置都不动。

## 2. 蒸汽区域
- **x 130–230，y 110–195**（360×800 逻辑像素）。锅占位框其余部分不变，只是蒸汽可以往上越过原框顶 150，到 110 为止。
- 上沿 110 离 HUD 位置条底（约 92）≥ 18 px；不碰右上调试键（正式包没有，不躲）。
- 镜头不动（0.42 / 0.28）；Queue 抽屉打开时锅下沉 14，蒸汽区域一起下沉 14。

## 3. 粒子（黄忠改，上官婉儿整合）
- **大小**：出盖时每团在屏幕上直径 22–26 px，上升过程中长到 34–40 px。（红色测试里现在不到 8 px 宽。）
- **数量 / 节奏**：每 0.6 s 冒一团，同时在画面里 2–3 团；每团寿命 1.7–1.9 s（和原来的循环约束一致），上升 60–80 px，左右漂 ±10 px，不出 x130–230。
- **透明度**：盖内 α = 0（照 419 v1.1 约定，不从盖子里穿出来）；出盖沿后 0.2 s 内淡入；**越过火候环那一段（y 170 以下）α ≤ 0.5**，不压金区和针；环上方升到 0.6；到 y 120 前淡出到 0。
- **颜色**：中心 #FFF8F0，外缘一圈 1–2 px 软边用冷灰 #D9DEE3 约 40%。等锅背景上方是奶油色墙和白色水槽，纯白蒸汽贴在白水槽上会看不见，必须靠这圈冷灰边读出来。

## 4. 验收（哪吒接入后实拍，360×800，带 HUD）
1. Common 一环、Legendary 两环（第二环在转）、Queue 抽屉打开，各一张，截在两团同时可见的时刻。
2. 3 s 录屏一段，看节奏、上升、淡出。
3. 判定线：手机正常亮度下，看得出「锅在冒热气」；蒸汽经过环时，金区和针都看得清；蒸汽不出 x130–230 / y110 以上；Queue 抽屉打开时跟着锅下沉。
4. 新文案 0，新界面元素 0（不改 197 LOCK-20 的锁定属性；锅占位框的上沿放宽只针对蒸汽，验收后记 197 说明）。
