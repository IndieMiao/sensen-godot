来源：q(165)，驿站只读的 Trip fares，亚瑟实现，0.2.6。旧金山 Union Square Travel Post 用的是 post_office 房间套件，套件里没有费用板；亚瑟现在拿后墙的 world_map 占位，默认镜头里它右半边出屏（我按取景代码算过：屏幕 x 332–395，屏宽 360）。走小道具流程：上官婉儿出设定 → 不知火舞审 → 刘备做 → 上官婉儿技术检查 → 不知火舞验收 → 合 wp-3d-scene → 整合 PR 进 farm-dev → 亚瑟接入。

## 位置（亚瑟实拍确认，275 评论 6e82f3fd）
- **左墙（门所在的墙），“Post Office”大招牌正下方**，挨着柜台左端。模型轴心（背面中心）放在 **(−3.21, 1.65, −1.65)**，**yaw 90**（板面朝 +X）。板占 z −2.10～−1.20、y 1.325～1.975；板顶比招牌底边（y 2.46）低 0.485 m。
- 墙面：这一段是实墙，内表面在 x −3.21（射线核过，没有窗洞）；板前 8 cm 内没有别的物件。
- 实拍（亚瑟用同尺寸纯色板，进门默认镜头，360×800）：
  - 屏幕 x 141–175、y 290–337，在招牌下方，板顶比红底下沿低 14–16 px；
  - 柜台上的绿萝和显示器都在板下方，板面不被挡；
  - 离 Sigrid 名字条横向 51 px。
- 站位（建议，亚瑟定）：柜台左端前方、公共一侧，例如 (−2.2, 0.08, 0.35)，面向左墙。不要放进柜台和左墙之间那条 0.53 m 的缝里（杂志架在 z −0.28～0.38）。
- 亚瑟接入时把 use_fee_board 的锚点从世界地图挪到板中心，点击点和名字条都锚在 board_center。

## 尺寸
- 板宽 **0.90**、高 **0.65**、厚 ≤ 0.07（含框）。比不知火舞说的 0.6 × 0.45 大一号：这个房间按角色比例取景时，一屏宽 360 px 只有 6.72 m，0.6 m 宽的板只有约 23 px，太小了。0.9 m 也还比后墙的世界地图（1.6 × 1.15）和时钟（直径 0.78）小。
- 木框宽约 0.05，圆润倒角；顶上可以有一条薄的檐线或标题条。板面比框凹进约 0.01。
- 板面上 **7 行**浅色横条（对应 Trip 1–7；每行高约 0.03，行距约 0.065，长短不一，像时刻表的行），每行左端一个小圆点（红、芥末黄、青绿、米白轮换）。**不写字，不放数字和符号**（同布告栏的空白纸条口径）。顶角可以有两颗小螺钉或一个黄铜色小夹子。
- 轴心在**背面中心**（贴墙的那一面的中心），+Z 朝前（板面朝 +Z）。摆放：位置 (−3.21, 1.65, −1.65)、yaw 90。
- 面数 ≤ 800。

## 材质与配色
- 和驿站其他家具一样，用 post_office 套件的共享贴图 `room_albedo_ao.png`（RoomKit_SharedAtlas），**UV 落到现有色块上，不加新贴图，也不改贴图集**：
  - 木框：sorting_cabinet / postal_counter 用的深木色块；
  - 板面：postal_blue_door 用的深蓝绿色块；
  - 横条：post_office_sign 字母用的米白色块；
  - 圆点：贴图集里现有的红、芥末黄、青绿色块（world_map 上有的那几种）。
- 哑光，无木纹、无照片贴图、无黑描边。

## 资产与交付
- 文件：`assets/rooms/post_office/fare_board.glb` 和 `.import`（导入设置照套件其他 glb）；一个 mesh、一个 surface。
- 挂点（空节点）：`board_center` (0, 0, 板面 z)、`mark` (0, ≈0.45, 0)。
- 不改 layout.json（套件本身不变）；由亚瑟在 P0 驿站的 `post.anchors.json` 里用 `props` 加进来（同农舍保温柜的做法），点击和名字条用上面的挂点。
- 截图：用 post_office 房间实景，按默认镜头（43°，套件偏航）拍一张，板挂在上面的位置，旁边站一个角色；正面一张；侧面一张看厚度。另附 validation：导入后的尺寸、面数，以及板和墙、招牌、柜台、杂志架没有交叠。
- 分支进 wp-3d-scene，我做技术检查，不知火舞验收。
