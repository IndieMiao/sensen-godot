# SGODOT-294 温室 Greenhouse：设定与制作规格 v1.1（含不知火舞审阅意见）（上官婉儿，2026-10-10）

设定页 greenhouse_sheet_v1.png（Sensenjoy 生成，参考了农场套件和 290 摆件设定）只用来定造型和配色方向。尺寸以本文为准，不要从图里量。画面由不知火舞审，我看不到图。

## 尺寸与位置（来自代码与内容表）
- 占地：盖住 4×4 块地。地块每隔 2 格一块，一格 0.65 m，所以整块（含床沿）约 **4.55 × 4.55 m**（p0_farm_facilities.gd `_block_rect`）。模型按 **4.55 m 见方**做，轴心在**地面中心**（占位版的 root 在块中心、y = 床面 BED_H 0.15，接入时程序会处理这个高度差）；+Z 朝前。
- 高度：屋檐约 1.6 m，屋脊约 2.4 m（角色 1.745 m 要站得进去，从 43° 看下去屋顶不能挡住整块地太多）。占位版是檐高 1.45 m、屋顶约 1.67 m，正式版可以高一点。
- **没有墙、没有门、没有地梁**：只有四根角柱和柱脚。设定图上每条边中间画了地梁，**不要做**，看着像围栏，玩家会以为进不去。要表现底座的话，只在柱脚两侧各伸出 ≤ 0.4 m 的短木，每条边中间完全空开。地块和作物在温室里面，模型不能挡住地块。

## 拆分（关键：屋顶要能单独变淡、放置预览只用底座）
交付**三个 glb**，共用同一个轴心（地面中心），拼在一起要严丝合缝：
1. `assets/farm/art/greenhouse_base.glb`：角柱、柱脚（以及柱脚两侧 ≤ 0.4 m 的短木）、檐梁、藤蔓、挂着的水壶。不透明，顶点色，一个 surface，共用 FarmArt.material()。**放置预览只用这一个**：正俯视时屋脊和椽条会横在格子上、挡住绿红格色，#278“预览不画屋顶”就是为了避免这个。所以只有 base 也要完整好看，俯视时是四根柱子加一圈檐梁。
2. `assets/farm/art/greenhouse_roof.glb`：屋顶框条（屋脊、椽条、山墙框）。不透明白木，顶点色，一个 surface。人在里面时可以淡到 50%（可选，由程序控制）。
3. `assets/farm/art/greenhouse_glass.glb`：只有玻璃面（两片坡面加两个山墙三角，侧面不做玻璃）。一个 surface，浅薄荷色顶点色。**透明度由程序控制**（平时约 25%，人在里面约 10%），模型里不烘透明度，也不做双面几何。

## 面数与风格
- 面数：base ≤ 1.5k、roof ≤ 1k、glass ≤ 0.5k，**合计 ≤ 3k**。
- 风格和 assets/farm/art、290 摆件一致：低面、圆润倒角、平涂顶点色（每种材质 2–3 色）、哑光、无贴图、无黑描边。设定图里的木纹和柔光照 290 的做法，改成平涂顶点色。
- 玻璃不要画反光贴图；高光由程序或材质处理。

## 挂点
- 空节点 `roof_center`（屋顶内侧中心，给程序判断“人在里面”和以后挂特效用，可选）。
- manifest 记录：bounds、triangles、surfaces、footprint 4.55 m、eave_height、ridge_height。
