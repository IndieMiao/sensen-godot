# Editable stove pots

`stove_pot.blend` is generated by `tools/art/build_stove_pot.py` in Blender 5.2.2.
Named meshes preserve the hollow pottery profiles, solid small ears, closed ring
handles, copper belt, domed shell, honey-wood knob and hollow steam outlet.
Runtime copies alone are merged; editable objects keep their variant/lid parent.
Blender uses `(x,-z,y)` for Godot `(x,y,z)`. The source is excluded from auto-import.

`spec-v1.1.md` is the delivered authoritative brief. `atlas-swatches.json` records
unchanged atlas provenance and the permitted auxiliary palette decision.
`review-fixture.json` snapshots the relevant props from farm-dev `a53e7e00`;
it is evidence for the isolated review, not a change to game anchors.
`reference.json` identifies the actual inspected reference files and review.

From repository root:

```sh
blender --background --factory-startup --python-exit-code 1 --python "$PWD/tools/art/build_stove_pot.py"
python3 tools/art/prepare_stove_pot_review.py
godot --headless --path output/stove-pot-282/project --editor --import
blender --background --factory-startup --python-exit-code 1 --python "$PWD/tools/art/verify_stove_pot.py"
godot --path output/stove-pot-282/project
```

Preparation requires NumPy for the exact old-kettle fixture extraction. The
renderer needs a real desktop display (Vulkan Mobile). The isolated project
contains only room/Avatar dependencies and a separate user directory. It does
not load gameplay/autoloads, production saves, or network accounts.

The verifier checks the approved fixture by default. `-- --original-deluxe`
intentionally tests the unchanged Deluxe room and reports nine kettle overlaps.
The fixture extractor writes only under `output/`, verifies all 1,144 removed
triangles against the original translated kettle, and retains every source
binary byte for the other geometry/materials/UVs. Do not ship its entire
`kitchen_fittings.glb` blindly; room integration belongs to a separate change.

See the [review README](../../../../docs/design/stove-pot-282-2026-10-15/README.md)
for camera, dimensions, import-name repair and integration observations.
