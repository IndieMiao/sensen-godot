# 名厨招牌 Chef's Sign：设定与制作规格 v1（上官婉儿，2026-10-13）

来源：方案 §7.7 / §8.3.1，Homestead Lv10 解锁，效果是全部菜金区 +5 个百分点，“农场门口挂招牌，访客可见”。走小道具流程：上官婉儿出设定 → 不知火舞审 → 刘备做 → 上官婉儿技术检查 → 不知火舞验收 → 合 wp-3d-scene → 整合 PR 进 farm-dev → 哪吒把占位换成正式模型。目标 0.2.5。

设定页 chef_sign_v1.png（Sensenjoy 生成）只用来定造型和配色方向。**尺寸以本文为准，不要从图里量。** 画面由不知火舞审，我看不到图。

## 位置（不知火舞定，哪吒接）
- 锚点 `chef_sign`：农舍正门前小路的左侧（面向农舍看），离门台阶约 1–1.5 m，占一个不是田也不是路的格子。不挡围栏内可走的范围，不压摆件和设施。
- 牌面朝默认农场镜头（43° / 偏航 14.5°），从默认视角能看清。

## 造型
- 门边独立的吊牌立柱：一根立柱，加小方脚；顶端一根横臂伸向一侧，约 0.5 m；一块圆角木牌用两段短链（或两个环）吊在横臂下。
- 牌面：只放图形标识，厨师帽加交叉的刀叉或叉勺，奶白和暖金两色，底色是深暖红或青绿，细金边。**不写任何文字**（名字条已经写了 `Chef's Sign`）。可以加一颗小金星或月桂点缀。
- 木作 / 石作两款，配合 Lv10 的 a / b（q(112)）：
  - a 木作：整体暖木。
  - b 石作：横臂和吊牌不变，立柱下面换成浅灰石墩。
  - 两款的吊牌和标识完全相同（可以共用同一份几何）。

## 尺寸与位置约束（米；一格 0.65 m，角色身高 H = 1.745 m）
- 轴心在**立柱脚底中心**，+Z 朝前（牌面朝 +Z）。
- 总高 1.6–1.8 m（横臂顶），**不高过门廊屋檐**；门牌 sign.glb 高约 0.77 m，招牌要高过它一截，所以吊牌的中心大约在 1.25–1.35 m。
- 吊牌约 0.60 × 0.45 m，**底边离地 ≥ 1.00 m**；厚度约 0.05 m。
- 横臂伸出的一侧：从默认镜头看朝农舍门的方向（落位时由哪吒按 yaw 转），吊牌投影不能压到门前小路的格子。立柱连同脚，投影 ≤ 0.30 × 0.30 m，落在锚点格中心。
- 碰撞：只算立柱（≤ 0.30 m 见方），吊牌下面可以走过（底边 ≥ 1.0 m，比角色矮的部分不挡）。

## 资产
- 文件：`assets/farm/art/chef_sign_a.glb`（木作）、`chef_sign_b.glb`（石作）。每个文件一个合并的 mesh、一个 surface。
- 面数：每款 ≤ 1.5k。
- 风格：和 assets/farm/art、290 摆件一致：低面、圆润倒角、平涂顶点色（每种材质 2–3 色）、哑光、无贴图、无木纹、无黑描边；共用 FarmArt.material()。
- 挂点：空节点 `board_center`（吊牌中心，以后可以挂高光或闪光，可选）。
- manifest：bounds、triangles、surfaces、footprint 0.65、board_bottom（吊牌底边高度）、collider（立柱）。
- 生成脚本可以并进 build_decor_assets.py，要能复现；Blender 源文件里对象要命名。

## 交付与验收
- 截图：43° 默认镜头两款各一张，旁边站一个角色作尺度；正面看牌面一张；正俯视一张，用真实的格子或田块看占地。
- 推到 wp-3d-scene-liubei-chef（或刘备自己的分支），开 PR 合到 wp-3d-scene。上官婉儿按真实资产尺寸做技术检查，不知火舞看图验收。

## 不知火舞审阅（282，v1 通过）——建模必须照做
1. **尺寸按本规格，不要照设定图的比例**：总高 1.6–1.8 m，吊牌 0.60 × 0.45 m，底边 ≥ 1.0 m。设定图 Scale 视图里牌底只到角色胸口、立柱偏矮，是生图的误差。
2. 设定图边缘的红色噪点是抠图残留，不是设计的一部分，不要做。
3. 链子两端做成真实的吊环或螺栓，挂在横臂和牌框上，不能悬空；牌框要有厚度（约 0.05 m），43° 斜看时图形读得出来。
- 牌面图形用**叉和勺**（设定图上的样子），保留；规格原文写的“刀叉”以此为准。外加一颗小金星。
- 配色：深暖红牌面加暖金边，木作和石作都用这一套。
