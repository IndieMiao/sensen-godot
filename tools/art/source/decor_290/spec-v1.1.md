# SGODOT-290 摆件 10 件：道具设定与制作规格（上官婉儿，2026-10-10）

设定页：decor_sheet_v1.png，用 Sensenjoy 生图生成，参考图是农场套件的 house_cottage / windmill / barn 预览和农场概念图。画面由不知火舞审阅，我自己看不到图。本页是文字规格，以这页为准，设定图只用来定造型和配色方向。

## 共同规格（全部 10 件）
- 风格：和 assets/farm/art 农场套件一致。低面、圆润倒角、**顶点色**、无贴图、哑光（roughness ≈ 0.9），共用 FarmArt.material()，不另建材质。
- 单位是米；**轴心在脚底**、落在占地格中心；+Z 朝前（和 manifest 的 front 一致）。
- 一格 0.65 m；模型投影不超出占地格，四周各留约 0.03 m。
- 每件导出成**一个合并的 mesh、一个 surface**（FarmArt.mesh_for 要求只有一个 MeshInstance）。
- 面数：每件不超过 2k；风车、喷泉不超过 4k。
- 不投影的细碎部分（花、叶）可以很小，但不要单独分 surface。
- 文件：assets/farm/art/deco_<id>.glb；manifest.json 记 triangles / surfaces / bounds。生成脚本加进 tools/art/build_farm_assets.py 或另建 build_decor_assets.py，要能复现；Blender 源文件里对象要命名。
- 角色尺度基线 H = 1.745 m。

## 交付与检查
- 交付：上面 10 + 1（风车叶）个 glb，加 manifest 条目、生成脚本、一张 Godot 内加载的总览截图（10 件排成一排，旁边站一个角色作尺度）。
- 我做技术检查：命名、轴心、尺寸、面数、surface 数、挂点（glow / seat_0 / seat_1 / 风车叶转轴）。
- 不知火舞看截图，判断像不像设定、和农场搭不搭。
- 接入：苏烈在摆件的 art() 里按 id 用 FarmArt.instance / batch（Path、Fence 多片用 batch）。

## 不知火舞审阅意见（290 评论 b491b80c，v1 通过，建模必须照做）
1. 风格：设定图是带木纹、石斑的黏土渲染。建模**去掉纹理**，每种材质用 2–3 个平涂顶点色，和农场套件一致。
2. Scarecrow：图里双臂展开约 1.4 m，超出规格。缩短手臂或斜向下约 30°，**两手总宽 ≤ 0.85 m**。
3. Windmill：叶片**直径 ≤ 1.24 m**（2×2 占地）；顶帽做圆锥或小斜顶，**不要带瓦的房顶**。
4. Fountain：**不做水柱**，只做两层石盆和平的水面；两层台阶要清楚，俯视时和鸟浴盆分得开。
5. Fence：交付**单段 0.65 m**，两端各半根立柱，能首尾拼接；保留白色尖头竖板。
6. Pergola：顶上的条板**统一沿短边方向**排；3×2 要做成明显的长方形；藤蔓贴着立柱和顶板，不要悬空。
7. Stone Path：**厚度 ≤ 0.04 m**，贴地。
另外：Birdbath 的小鸟俯视时也要认得出。
**尺寸只按上面的规格表，不要从设定图里量。**
验收截图：43° 和正俯视各一张，10 件排成一排，旁边站一个角色作尺度。
