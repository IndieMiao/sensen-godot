# 渔具铺鱼竿架 Rod Rack · 规格 v1（SGODOT-214，小道具流程）

上官婉儿 · 2026-10-15。依据：不知火舞 218 6daee7fe、58fb89c2。
- Stark 稿里左墙那排“插浮漂的木杆”不是鱼竿陈列。P0 卖的是 Reed Rod，所以换成立着的鱼竿，浮漂放回木桶。
- 设定页 rod-rack-sheet-v1.png 只定造型和配色，尺寸以本规格为准。
- 这件是 214 新房间 tackle_shop 的一件布景，随整间一起做，不单独出 PR。

## 造型
- 落地木架：
  - 底座是一个暖橘棕矮木箱，上面一排圆孔；
  - 高约 1.1 m 处一根横木扶杆，把鱼竿立住。
- **4 根鱼竿**，立着、略微散开：
  - 竿身是芦苇 / 竹子色（浅麦黄，带深一点的节环）；
  - 手柄是软木棕，靠近手柄处装一个灰色金属小卷线轮；竿梢细；
  - 其中一根竿梢夹一个红白小浮漂。
- 架旁地上一只矮木桶，装 3 个红白 / 蓝白浮漂。这就是稿里那些浮漂的去处。
- 不写字、不贴标签、不要描边和木纹贴图。

## 尺寸
- 架子：宽约 0.9 m、深约 0.35 m、底座高约 0.4 m，扶杆高约 1.1 m。
- 鱼竿：高约 1.6 m（含底座插入部分）。
- **不能挡左墙的圆舷窗**：竿梢低于舷窗下沿；如果舷窗太低，架子就放到舷窗旁边，而不是正下方。落位按 214 新房间的真实墙体核。
- 面数：架子 + 4 根竿 + 木桶和浮漂 ≤ 1200。用 tackle_shop 的贴图集色块。

## 位置
- 左墙，原来浮漂木杆的位置〔机〕，在 Old Kai 角落（左前）后面一点；不压 Kai 的站位（npc_kai / stand_kai）和他的名字条。
- 不可点，只是布景。

## 流程
- 不知火舞审本设定 → 随 214 整间派刘备（或赵云）→ 我做技术检查 → 不知火舞验收。

## 审核结论（不知火舞 214 38882f82：看图通过，随 214 整间派）
- 鱼竿上的导线环只做成竿身上的小凸点，不单独建模，省面数。
- 卷线轮哑光，specular 0.28。
- 架旁这只浮漂桶就是 Stark 稿左墙原来那只，不另加。加上右前角 Rafa 旁边那只，全屋一共两只浮漂桶。
