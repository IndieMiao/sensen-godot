# 需要用户亲自做/确认的事（由奕星统一转，不直接联系用户）

当前只是独立媒体QA补丁，未注册App ID、未建证书/描述文件、未签名、未安装或上传。11-21首版是否带语音仍由用户定。

| 项目 | 用户要做/确认什么 | 当前是否必须现在操作 |
| --- | --- | --- |
| 测试范围 | 确认允许受控iOS↔Android语音/麦克风测试及可用时间；指定可用iPhone、Android和耳机。我们只用隔离QA包与测试身份 | 执行前需要；今晚写代码不需要 |
| Apple App ID | 决定由本人或有权限管理员注册独立 `app.gensen.voiceqa`；团队不得先在后台创建。此次native QA不要求加Sign in with Apple等无关能力 | 确定真机QA方案后才做；先由奕星报用户 |
| Apple账号/证书 | 复用已有Gensen团队与有效Apple Development签名身份；只有后台确认缺失/失效时，再由本人或管理员建立所需证书/profile。不要求无故新建证书/重登账号 | 用户若遇Apple登录、2FA、钥匙串确认，亲自在系统界面完成；不把密码/验证码/私钥发聊天 |
| 设备注册与信任 | 执行前核设备型号/系统与当前标识。若设备尚未在所用profile覆盖范围内，由有权限管理员经批准注册；本人解锁、确认信任/Developer Mode等系统提示 | 不能按历史UDID直接装，也不先动用户设备 |
| 权限与音频配合 | 在QA包里实际点允许/拒绝、打开该QA包设置；按约定插拔/蓝牙/受控中断，协助主观回声/啸叫判断 | 设备窗口到时操作；截图/录像不上传私人系统页或录存真实语音 |
| 登录测试账号 | 本轮原生媒体可由团队在隔离服务签短期测试grant，不需要用户提供Google/Apple密码；完整账号游戏候选仍沿488计划使用用户批准的测试账号 | 两件分开，不为本原生补丁额外索取个人账号 |
| TestFlight | 本隔离媒体QA当前不上传。若后续决定经TestFlight发任何QA/正式候选，先由奕星报用户确认，再按指定build安装；完成全包加密申报 | 当前不操作、不因已有账号就自动上传 |

团队负责的事项不转成用户凭据任务：运维准备devserver独立环境/namespace `p0-ios-voice-qa-1118`和测试issuer；核无生产复用、Egress关闭、TLS/无重定向；将准确WSS origin和issuer摘要交冻结。此轮未部署，执行许可另报。亚瑟提供隔离补丁/发布拒绝检查，周瑜审，蒙恬按批准基线出包，大乔排资源窗口。

首批不含法国已定，无需French encryption declaration。11-21内容定后仍需对最终IPA做全包ASC问卷，再定ITSAppUsesNonExemptEncryption；用户无需现在为本补丁填写法国文件或提交商店表单。
