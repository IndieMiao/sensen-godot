# 明天语音测试步骤

**11月18日15:00开始，预计35–45分钟。** 团队14:30先检查环境。App ID按您已授权的A方案由团队准备。

请准备iPhone、约定的安卓设备和一副常用耳机。两台设备分开放，避免啸叫。团队陪您操作，不需要在聊天里发密码、验证码或证书。

| 顺序 | 请您做什么 | 约用时 |
| --- | --- | --- |
| 1 | 打开我们确认版本的黄色QA测试App。按提示点“Start media QA”。输入现场给您的测试码。 | 2分钟 |
| 2 | 点“Join”申请麦克风，第一次提示先点拒绝。再从测试App打开设置，允许麦克风后返回。 | 5分钟 |
| 3 | 第二轮先重开App，再点“Join”。若提示访问本地网络，点允许。先不开麦。按提示开麦，说“测试一二三”；再听另一端说同样的话。告诉我们是否清楚、有回声。 | 4分钟 |
| 4 | 按提示静音对方，再恢复。然后屏蔽对方，双方确认都听不到；解除屏蔽后再确认恢复。 | 5分钟 |
| 5 | 第三轮先重开QA App。通话时回桌面、锁屏再回来。确认后台没有继续传声，重新加入后能正常通话。 | 4分钟 |
| 6 | 插拔或连接耳机，分别试说话和听声音。有时间再做一次约定的系统中断。 | 5分钟 |
| 7 | 点“Leave”，再点“Stop QA”。确认麦克风指示消失。告诉我们还有没有杂音或声音未恢复。 | 2分钟 |

每轮都先点“Start media QA”并输入测试码。每轮最长10分钟。到时会自动停止；需要继续时，我们指导您重开App。失败时先停住告诉团队，不用反复点按钮。预留5–10分钟处理偶发问题，总时长最多约45分钟。

**团队负责**装包与版本核对、环境/证据、短时断网或租约测试、清理。注册按已授权的A方案办理；签名和安装由团队另按设备窗口安排，需要您解锁或确认时会当场提示。测试结束不改您的正式游戏数据，也不关闭GeoFarm服务。

这次先验证隔离语音，不是正式上线。11月21日再决定首版是否带语音。
