# Coast Kit · SGODOT-426

赵云制作的可复用海岸套件，适用于后续海边地标。15 个独立 GLB，单件 28–344 三角面，每件一个 `_mobile` 网格、一个 surface，哑光顶点色，无贴图 / 骨架 / 动画。可编辑源和生成器见文末。整套不包含示例 layout 或游戏接入场景。

## 模数、方向与原点

- 单位为米，Y 向上；主模数 **2 m**。直岸石 / 墙 / 码头沿局部 **+X** 延伸。
- 岸石入口方向沿 +X 行进时，**+Z 是水，-Z 是陆地**；转角件的水侧随转向变化。
- 直件原点在两端中点的底部。角件保留同一模数构造基点，**不是 AABB 中心**；不要按包围盒重新居中。散石和浮标以底部中心为原点。
- 甲板顶面 Y=1.20；岸石低 / 高峰值 Y=0.80 / 1.20，**六种岸石的端口截面完全相同**，端口最高点 Y=0.75。高低变化在模块内部，允许直接混拼。
- 几何、端口点位和材质设置见 [manifest.json](manifest.json)。`ports.profile` 是局部米制坐标，不是整段示例岸线的摆放表。

## 首尾拼法

沿有方向的链条，将前一件的 **out** 对到后一件的 **in**：端口位置重合、两个 `outward` 相反、Y 轴向上。保持 scale=(1,1,1)，旋转采用绕 Y 的 90° 整数倍。六种岸石可任意高低 / 直角混搭；不要反接 in→in，否则陆侧、水侧会颠倒。

| 件型 | in 中心 | out 中心 | 转向 |
|---|---|---|---|
| 岸石直段 / 墙 | (-1,0,0) | (1,0,0) | 沿 +X |
| 岸石外转角 | (-1,0,0) | (0,0,-1) | +X → -Z |
| 岸石内转角 | (-1,0,0) | (0,0,1) | +X → +Z |
| 码头直段 / 系缆桩段 | (-1,1.2,0) | (1,1.2,0) | 沿 +X |
| 码头尽头 | (-1,1.2,0) | 无 | 终止链条 |

例如第一段直件在原点，第二段放 (2,0,0)。若第二段换成外角，其后直件放 (2,0,-2)、绕 Y 转 +90°；若换成内角，其后直件放 (2,0,2)、绕 Y 转 -90°。这些是端口用法示例，不是示例岸线 layout。

每类接口按原截面拼接：岸石→岸石、墙→墙、码头→码头。它们共享 2 m 模数，但岩坡截面、墙的压顶、甲板截面并不相同；组合海岸时在墙 / 岩岸旁预留 2 m 码头口或台阶口，用陆地承接后侧，不要把所有件当作同一个端面替换。

岸石接口的六点截面，以 `(水侧深度 z, 高度 y)` 表示为：

```text
(-0.60, 0.00), (-0.60, 0.65), (-0.15, 0.75),
( 0.10, 0.64), ( 0.45, 0.33), ( 0.60, 0.00)
```

断面、峰值和浅裂缝都在模块内部变化，连接截面不受影响。只验证带方向的 out→in 配对：36 组岸石、1 组墙、6 组码头，端口顶点最大错位小于 0.000001 m。甲板木板自身没有透空缝，板间差异由顶点色区分；支柱位于段中，不会在接头重复叠桩。

## 码头、下水台阶与浮标高度

- 码头所需步行高度为 H 时，模型根部放在 **Y=H-1.20**。三种码头顶面相同，尽头封边留在 2 m 格内。
- 台阶从局部 Z=-1 的 Y=1.20 端向 +Z 下降，末级 Y=0.15。顶部边宽 2 m，可以与码头直段 / 系缆桩段的走面齐接。举例：码头在原点，台阶放 (2,0,0)、绕 Y +90°，两件的 Y=1.20 走面边恰好重合。
- 下水台阶以岸上步行高度设根部 Y=H-1.20；水位决定实际露出的级数。末端是下水端，不是跨层楼梯的通用接口。
- 浮标水线局部 Y=0.30，水面为 W 时放 **Y=W-0.30**。当前为静态件。

## 色板与导入

配色来自马可波罗恶魔岛色板 `b81605af`，岸石使用 `rock / rock_light / rock_shadow / rock_warm`，墙和台阶用 `stone*`，码头用 `wood*`。浮标使用同表的奶油底和暖橙；系缆桩为哑光深青。散石保留已有恶魔岛碎岩几何，缩放、换色后导入本目录，来源路径 / SHA 记录在 manifest，不回写原件。

顶点颜色已转为线性值。若接入方覆盖材质，设 `vertex_color_use_as_albedo=true`、`vertex_color_is_srgb=false`、`roughness=0.94`、`metallic=0`、`metallic_specular=0.15`。

全部 `.import` 保留 Godot 生成的 UID、`nodes/root_script=null`、`gltf/texture_map_mode=1`、`meshes/light_baking=1`；自动 LOD、切线生成、shadow mesh 和动画导入关闭。**最终导入完成后再同步 `.import`，提交后冷导入 / 同步应保持 git status 干净。**
