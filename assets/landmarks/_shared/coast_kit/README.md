# Coast Kit · SGODOT-426 · v1.2

赵云制作的可复用海岸套件，适用于后续海边地标。15 个独立 GLB，单件 96–368 三角面，每件一个 `_mobile` 网格、一个 surface，哑光顶点色，无贴图 / 骨架 / 动画。可编辑源和生成器见文末。整套不包含示例 layout 或游戏接入场景。

## 模数、方向与原点

- 单位为米，Y 向上；主模数 **2 m**。直岸石 / 墙 / 码头沿局部 **+X** 延伸。
- 岸石入口方向沿 +X 行进时，**+Z 是水，-Z 是陆地**；转角件的水侧随转向变化。
- 直件原点在两端中点的底部。角件保留同一模数构造基点，**不是 AABB 中心**；不要按包围盒重新居中。散石和浮标以底部中心为原点。
- 甲板顶面 Y=1.20；岸石低 / 高峰值 Y=0.80 / 1.20，**六种岸石的端口截面完全相同**，端口最高点 Y=0.75。高低变化在模块内部，允许直接混拼。
- 几何、端口点位和材质设置见 [manifest.json](manifest.json)。`ports.profile` 是局部米制坐标，不是整段示例岸线的摆放表。

## 首尾拼法

沿有方向的链条，将前一件的 **out** 对到后一件的 **in**：端口位置重合、两个 `outward` 相反、Y 轴向上。保持 scale=(1,1,1)，旋转采用绕 Y 的 90° 整数倍。六种岸石可任意高低 / 直角混搭；不要反接 in→in，否则陆侧、水侧会颠倒。

| 件型 | in 中心 | out 中心 | 转向 |
|---|---|---|---|
| 岸石直段 / 墙 | (-1,0,0) | (1,0,0) | 沿 +X |
| 岸石外转角 | (-1,0,0) | (0,0,-1) | +X → -Z |
| 岸石内转角 | (-1,0,0) | (0,0,1) | +X → +Z |
| 码头直段 / 系缆桩段 | (-1,1.2,0) | (1,1.2,0) | 沿 +X |
| 码头尽头 | (-1,1.2,0) | 无 | 终止链条 |

例如第一段直件在原点，第二段放 (2,0,0)。若第二段换成外角，其后直件放 (2,0,-2)、绕 Y 转 +90°；若换成内角，其后直件放 (2,0,2)、绕 Y 转 -90°。这些是端口用法示例，不是示例岸线 layout。

每类接口按原截面拼接：岸石→岸石、墙→墙、码头→码头。它们共享 2 m 模数，但岩坡截面、墙的压顶、甲板截面并不相同；组合海岸时在墙 / 岩岸旁预留 2 m 码头口或台阶口，用陆地承接后侧，不要把所有件当作同一个端面替换。

岸石接口的六点截面，以 `(水侧深度 z, 高度 y)` 表示为：

```text
(-0.60, 0.00), (-0.60, 0.65), (-0.15, 0.75),
( 0.10, 0.64), ( 0.45, 0.33), ( 0.60, 0.00)
```

断面、峰值和浅裂缝都在模块内部变化，连接截面不受影响。只验证带方向的 out→in 配对：36 组岸石、1 组墙、6 组码头，实际导出端口顶点最大错位小于 0.000001 m。木板按 #830 v1.1（5f9b59b8）统一为名义 1.8 × 0.18 m、邻行错开 0.9 m，板缝宽 0.012 m。图案在 2 m 模块内裁切为 11 行、28 块；两端闭合截面不变。甲板顶面分区赋顶点色，不叠共面面片、不增加 pass；含缝名义宽 0.18 m，实木面宽 0.168 m（边行 0.174 m）。四根细桩位于段内 (X=±0.66, Z=±0.72)，不会在接头重复叠桩。

## 码头、下水台阶与浮标高度

- 码头所需步行高度为 H 时，模型根部放在 **Y=H-1.20**。三种码头顶面相同，尽头封边留在 2 m 格内。
- 台阶从局部 Z=-1 的 Y=1.20 端向 +Z 下降，末级 Y=0.15。顶部边宽 2 m，可以与码头直段 / 系缆桩段的走面齐接。举例：码头在原点，台阶放 (2,0,0)、绕 Y +90°，两件的 Y=1.20 走面边恰好重合。
- 下水台阶以岸上步行高度设根部 Y=H-1.20；水位决定实际露出的级数。末端是下水端，不是跨层楼梯的通用接口。
- 浮标水线局部 Y=0.30，水面为 W 时放 **Y=W-0.30**。当前为静态件。

## 双色板、湿带与导入

九种岸石 / 散石共用既有网格，通过一个 `rock_palette` 材质参数切换两套颜色，未复制 GLB、未增加 surface / pass，也没有新增纹理：

| 参数 | 值 | 含义 |
|---|---|---|
| rock_palette | 0 | 暖沙色，保留 v1 的岩石 RGB 色板 |
| rock_palette | 1 | 冷灰褐，默认；#801 v3 的 #777A75 / #93958B / #515B59 基准 |
| water_level | 默认 0.15 | 世界坐标水面 Y，按使用场景设置 |
| wet_height | 默认 0.25 | 水面以上渐淡湿带的高度，米 |
| wet_strength | 默认 0.38 | 线性颜色压暗幅度；0 关闭湿带 |

[coast_cool_gray.tres](coast_cool_gray.tres) 和 [coast_warm_sand.tres](coast_warm_sand.tres) 使用同一个无纹理着色器。木板底色 #A3815D、边缘亮色 #B89972、侧面及支撑暗色 #795F47、板缝 #69543F；每块在底色线性 RGB 上作 ±14% 明暗变化，和 #830 同一参数口径；护岸墙和码头不受岸石色板选择影响。

湿带按实际世界水位计算，移动模块、缩放或使用 MultiMesh 时仍对齐水面；岸石、散石、护岸墙和码头在水面以下及其上方 0.25 m 渐暗。材质保持不透明并写深度，未增加湿带几何或透明 pass。#824 浪花仍保留其原透明材质，在水面上方约 0.018 m 单独叠放、关闭投影；本包不依赖或修改 #824 文件。

13 个需要换色 / 湿带的模型在 Godot 导入时由 [coast_kit_import.gd](coast_kit_import.gd) 将材质写到 Mesh surface，提取 Mesh 给 MultiMesh 也能保留。浮标、台阶 GLB 沿用已通过的原字节。**保留导入材质**；如需按水域或实例调整，使用本目录材质，例如：

```gdscript
var material := preload("res://assets/landmarks/_shared/coast_kit/coast_cool_gray.tres").duplicate() as ShaderMaterial
material.set_shader_parameter("rock_palette", 0) # 0 暖沙，1 冷灰褐
material.set_shader_parameter("water_level", sea_y)
mesh_instance.material_override = material # 也适用于 MultiMeshInstance3D
```

同一条岸线共享同一套色板、水位和湿带设置。顶点 RGB 是线性颜色；13 个着色器模型的 `COLOR.a` 是面类型标签（1/8、2/8、3/8、4/8 为岩石面色，6/8 为可湿固体），不是透明度。着色器不写 `ALPHA`。材质 roughness=0.94、metallic=0、specular=0.15。导入后不要用通用顶点色材质覆盖这些 shader 材质，否则换色和湿带不会生效。

全部 `.import` 保留原 Godot UID、`nodes/root_script=null`、`gltf/texture_map_mode=1`、`meshes/light_baking=1`；自动 LOD、切线生成、shadow mesh 和动画导入关闭。最终导入完成后再同步 `.import`，提交后冷导入 / 同步应保持 git status 干净。Shader / 导入脚本的 `.uid` 同样由 Godot 生成并保留。
