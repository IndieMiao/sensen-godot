# 街道家具 v1.2 + 观景扩展 v1.1 · SGODOT-429 / 431

黄忠。21件可复用家具（原16件 + 5件观景扩展），适用于后续地标、集市广场和室外POI。
全部独立GLB、每件1mesh/1surface、单件136–728三角面，合计8,285面；顶点色、哑光、无贴图。
本目录新增件不依赖恶魔岛或教堂资源，不修改任何既有文件，不含灯光、碰撞、骨骼、动画、layout或地点注册。

## 模数、原点与安装

米制，Y朝上；默认原点是底部中心，+Z朝前。挂墙牌例外：原点在背面中心，牌面朝+Z。
栏杆转角原点在弯点地面，两个1m臂沿+X/+Z。所有家具占地均收在2×2m单元内。
2m是街道摆放/拼接模数，不把小件一律放大到2m；家具保持适合1.745m角色的实际尺寸。

## 材质与来源

所有GLB由street_kit_import.gd统一绑定street_matte.tres：vertex_color_use_as_albedo=true，
roughness=0.90，metallic_specular=0.15。颜色在线性COLOR_0中；palette.json记录原始sRGB值。
暖石CBB48F/D9C4A3、青绿35696A/608F99来自恶魔岛正式色板bf0c31b1；
木长椅（椅面与靠背木板）、伞桌桌面/凳面及木杆按#830 v1.1改为木A3815D、亮B89972、暗795F47，
保留板间轻微深浅变化；这两件的铁件深褐保持不变。其他件的暖色饰边保留原色。
深褐金属5D4C38、奶油F0E1C2与Grace Cathedral同一暖色体系，伞布用奶油/鼠尾草绿。
几何全部新制；Blender命名部件、脚本、每件provenance在tools/art/source/street_kit_429/。
生成器只借用既有建模基础函数，不写回旧资产。

每份.glb.import含Godot生成的独立uid、nodes/root_script=null、texture_map_mode=1、light_baking=1。
根脚本null与EditorScenePostImport材质绑定脚本是不同设置。本套件无PNG，不需要手机纹理格式条目。
导入脚本.gd.uid一并交付；已有UID保持稳定。交付前会在全新.godot缓存中以etc2_astc=true复导，核对文件不漂移。

## SGODOT-431 观景扩展

新增5件共2,329面/5surface；原16件GLB、材质、色板与导入UID均保留原字节。
新件同样底面原点、Y向上、单位缩放、单surface哑光顶点色。无贴图、无字母/数字、无灯光、碰撞或动作。
望远镜镜头朝-Z略抬，双目端在+Z、目镜高1.40m；投币盒改为0.14×0.32×0.08m的竖向块，
与立柱同色#5D4C38，正面只有0.10×0.018m横缝，没有浅色面板、圆点或箭头。
方位圆盘Ø1.60m、高14.5mm，四向箭头加小船、灯塔图形；主色箭头沿-Z，摆场景时按所需方向整体旋转。
长凳棚架占地2.00×1.40m、高2.46m，坐面0.715m，朝+Z；棚顶为有间隙的木条，保留街道套件统一木色。

### 平台与旧栏杆拼接

- lookout_railing_2m：底部中心原点，接点(-1,0,0)/(1,0,0)，上下栏中心Y=0.93/0.23m，与原railing_straight_2m一致。
- lookout_semicircle_2m：弦中点的底面为原点，弦宽2m，向-Z伸出1m，台面Y=0.12m。两接点为(-1,0.12,0)/(1,0.12,0)。
- 若目标地面顶高为F，平台根放Y=F-0.12；直段、旧端柱根都放Y=F。此时曲栏、直栏上栏中心同为F+0.93。
- 观景直段与弧栏统一为#5D4C38全铸铁圆管，管半径0.032m与原street_kit栏杆一致。
弧栏中心半径0.95m；旧端柱放弦端X=±1，覆盖最后5cm中心偏移，拼缝射线已核无空隙。每个接点只摆一根端柱。
- 台面是实面几何，本包不带碰撞/导航。决定接入时由场景负责人依据实际顶面另配。
