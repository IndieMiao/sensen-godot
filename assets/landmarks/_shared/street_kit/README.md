# 街道家具套件 v1 · SGODOT-429

黄忠。16件可复用家具，适用于后续地标、集市广场和室外POI。
全部独立GLB、每件1mesh/1surface、单件136–652三角面，合计5,970面；顶点色、哑光、无贴图。
本目录新增件不依赖恶魔岛或教堂资源，不修改任何既有文件，不含灯光、碰撞、骨骼、动画、layout或地点注册。

## 模数、原点与安装

米制，Y朝上；默认原点是底部中心，+Z朝前。挂墙牌例外：原点在背面中心，牌面朝+Z。
栏杆转角原点在弯点地面，两个1m臂沿+X/+Z。所有家具占地均收在2×2m单元内。
2m是街道摆放/拼接模数，不把小件一律放大到2m；家具保持适合1.745m角色的实际尺寸。
模型内已应用比例，导入节点单位缩放。下表为实测包围，顺序宽X × 高Y × 深Z。

直栏杆接口位于局部(-1,0,0)/(1,0,0)，中心间距2m；端柱独立摆在裸露端点，同一接缝只摆1根。
转角接口为(1,0,0)/(0,0,1)，沿Y旋转90°拼接。示例后沿长4m = 左角1m臂 + 直段2m + 右角1m臂；
左转角(-2,0,-5)保持0°，中段(0,0,-5)，右转角(2,0,-5)转-90°，两处接口逐点重合。
沿转角另一臂续接直段时，先对齐接口点，不能按含端柱的1.1m外包围累计。

木椅实测坐面0.718m、石椅0.715m；两椅朝+Z，靠背在-Z，座宽1.80m。
伞桌含两只装饰凳，桌面1.12m、凳面0.715m，伞顶2.86m、伞直径2m；本轮不挂可交互seat点。
两款路灯的灯面为不透明暖色，模型自身不带灯或发光；后续如需照明由场景按预算设置。
饮水台有凹盆、排水点和水嘴，只是静态道具。两款牌面无字无实际图标，左侧圆形浅青块是预留图形位，
整个可用牌面约1.01×0.44m；背面安装平面和建议中心见kit_manifest，不在本轮加入运行时内容。

## 材质与来源

所有GLB由street_kit_import.gd统一绑定street_matte.tres：vertex_color_use_as_albedo=true，
roughness=0.90，metallic_specular=0.15。颜色在线性COLOR_0中；palette.json记录原始sRGB值。
暖石CBB48F/D9C4A3、暖木BB8B52/D0A56C/9A7046、青绿35696A/608F99来自恶魔岛正式色板bf0c31b1；
深褐金属5D4C38、奶油F0E1C2与Grace Cathedral同一暖色体系，伞布用奶油/鼠尾草绿。
几何全部新制；Blender命名部件、脚本、每件provenance在tools/art/source/street_kit_429/。
生成器只借用既有建模基础函数，不写回旧资产。

每份.glb.import含Godot生成的独立uid、nodes/root_script=null、texture_map_mode=1、light_baking=1。
根脚本null与EditorScenePostImport材质绑定脚本是不同设置。本套件无PNG，不需要手机纹理格式条目。
导入脚本.gd.uid一并交付；已有UID保持稳定。交付前会在全新.godot缓存中以etc2_astc=true复导，核对文件不漂移。

## 审阅示例

隔离脚本摆6×12m（即12×6m长边朝纵深）小广场一角，全部16种均有实例。
24件家具加铺石地台、背景地面和挂墙牌的临时支墙：7,372面/27surface，未计角色/影子额外绘制。
默认镜头360×800、43°、屏宽6.72m、yaw8°，角色1.745m；另附全景和16件加人件表。
没有把示例保存为可上线场景或layout。

铺石用刘备#830的54b76f78版本assets/landmarks/_shared/ground_detail/ground_paving.tres；背景草地用同版ground_grass。
13份依赖通过git读取后只放在output的审阅工程，逐字节核对。它们不随本PR复制进运行时目录，也不被改写；
将来实际使用广场地材时，应以#830合入后的共享地材为依赖。本次支墙也是只供挂墙牌展示的无细节审阅网格。
审阅图及验证见docs/design/street-kit-429-2026-11-06/。
