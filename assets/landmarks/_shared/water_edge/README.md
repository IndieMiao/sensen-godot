# 通用水岸浪花件 · SGODOT-430

刘备制作。将 #824 的柔边浪花整理为与 SGODOT-426 海岸套件配套的独立面片；不包含海面材质、碰撞、导航或游戏接入。5 个 GLB，共 224 三角面，每件 1 surface，沿用原版 512×128 RGBA 贴图。颜色、强度、速度只需改 `.tres`。

## 件表和坐标

米制，Y 向上，岸石直段沿 +X、+Z 为水侧。**浪花局部 Y=0 是水面原点**，放置 Y 为水位 W + 0.018 m；XZ 原点、旋转与对应岸石一致。转角是构造原点，不是包围盒中心，不要重新居中。

| 文件（省略 .glb） | 三角面 | 对齐与用途 |
|---|---:|---|
| water_edge_straight | 40 | 2 m 直岸，端口 (-1,0,0) → (1,0,0) |
| water_edge_outer | 40 | 2 m 格外角，端口 (-1,0,0) → (0,0,-1) |
| water_edge_inner | 40 | 2 m 格内角，端口 (-1,0,0) → (0,0,1) |
| water_edge_pile_ring | 64 | 单个 Ø0.22 m 码头桩的水线环，桩轴为原点，环外径 0.70 m |
| water_edge_steps | 40 | 2 m 宽下水口，原点与 coast_water_steps 相同；浪花位于 Z=0.68…1.18 |

岸石参考 #831 `d72d74f4c0ccbcc922c5691cb8b6866eca1ca8f9`。参考水位为岸石根部以上 **0.20 m**；六种高低岸石的末端断面相同，此水位与岸面交于水侧约 0.509 m。浪花横断面水侧距离为 0.40 / 0.64 / 0.88 m，V 边缘全透明。内角最小半径 0.12 m，无自交。

直件接直件位置偏移 (2,0,0)。外角后接直件偏移 (0,0,-2)、绕 Y +90°；内角后接直件偏移 (0,0,2)、绕 Y -90°。前一件 out 对下一件 in，不反接。9 组方向组合验证端口误差 < 0.000001 m。接头不做端部淡出，UV 在 0/1 周期相接，所有件共用时钟。

码头桩环放在 `coast_dock_*` 的局部 X=0、Z=±0.72 两根桩轴，再施加码头的水平变换；Y 独立按水位设置。与岸线浪花重叠的近岸桩省略桩环，避免叠层。台阶参考水位比根部高 0.20 m，此时末级 Y=0.15 淹没、水接于 Z≈0.75。台阶两端属于开放过渡口，分别把相邻岸石与下水口端部淡出，不能硬接不同断面。

## 材质参数

默认 `water_edge_material.tres` 已由 GLB `.import` 绑定。换地标时复制 `.tres` 后赋给 MeshInstance3D / MultiMeshInstance3D 的 `material_override`；同材质同网格可合并 MultiMesh。不要设置 `next_pass`。

| 参数 | 默认 | 含义 |
|---|---|---|
| foam_texture | water_edge_soft.png | #824 原贴图，字节未改；无损、带 mipmap |
| foam_color | (1,1,1,1) | 乘原贴图的柔和偏白颜色；A 乘透明度 |
| intensity | 0.8 | 强度 0…1，不提高到硬白边 |
| cycle_speed_hz | 0.25 | 每秒周期数；默认 4 s 一循环，设 0 完全静止 |
| drift_uv | 0.018 | 沿岸 UV 往返幅度；2 m 直件约 ±3.6 cm |
| breath_amount | 0.06 | 一周期内仅从 100% 降到 94% 的缓慢透明变化 |
| end_fade_uv | (0,0) | 起 / 终端淡出长度，占 U 比例；模块接头必须为 0 |
| render_priority | 1 | 在海面后绘制；沿用 #824 |

自由岸线末端可复制材质，将单侧 `end_fade_uv` 设为 0.12；台阶口约 0.10。封闭桩环保持 (0,0)。不要给每段独立时间相位，否则接头会不一致。

水位改变时所有面片 Y 随 W；本套岸石断面与台阶口的 **XZ 接触带是按上述水位设计**，不是任意水位自动投影。若新地标的水位大幅不同，应先核对接触线，调整实例位置 / 尺寸或另做几何适配，不能只改 Y 后声称自动贴岸。桩环适配实际桩径后检查与其他浪花的间距。

## 湿带与手机开销

0.2–0.3 m 湿带由岸石自己的**不透明材质**在水线上方表现；本套只占水面上的一层，不额外铺透明湿带。避免重叠面片、重复桩环或双层浪花。实例关闭 cast_shadow，GI disabled；shader 也禁阴影，无深度写入、无深度预通道。

与 #824 一致：每像素 **1 次 RGBA 采样、1 个透明 pass、最多 1 层浪花**，不采样屏幕 / 深度、不新增法线或投影 pass。慢速摆动在 vertex 阶段计算，fragment 只读一次原图。动画多了少量顶点算术，不声称与旧材质 GPU 耗时完全相等。纹理无损导入，无须平台专用压缩格式，512×128 mip 链解码约 0.333 MiB。
