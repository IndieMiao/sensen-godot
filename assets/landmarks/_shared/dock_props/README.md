## 放置与材质

米制，Y 朝上，原点位于承重底面中心。售票口、候船棚开口、救生圈和渔网正面朝 +Z；跳板沿 +X 伸展。大小已烘进网格，实例缩放保持1。
每件一个 `<件名>_mobile` mesh / surface，顶点色采用线性RGB；无纹理、灯光、相机、骨骼、动画和碰撞。
`dock_props_import.gd` 在导入时给唯一 surface 绑定本目录 `dock_matte.tres`：roughness0.94，specular0.15，顶点色直接作 albedo。
12 个 `.glb.import` 的 UID 与导入脚本 UID 均由 Godot 生成，`nodes/root_script=null`、`gltf/texture_map_mode=1`、`light_baking=1`。

木板色沿用 #830：主色 **#A3815D**，亮 **#B89972**，暗 **#795F47**，板与板之间有小幅交替。铁件 **#5D4C38**；奶油边 **#F0E1C2**；屋面灰蓝 **#748B9C**。无烤字或文字几何。售票亭只有0.96 ×0.23m空白图形牌位；信标使用绿色信号玻璃（#328B62，玻璃亮部#81C9A1，仍为单surface顶点色），不附实时灯。
候船棚座面0.715m，仅为布景，没有交互或座位挂点。

## 接 426 码头尽头

对接 `coast_dock_end`（已合并 #831 版本）：它沿 +X，顶面局部Y=1.20m，末端中心 `(1,1.2,0)`。
跳板长2.40m、宽1.20m，走面局部Y=0.10m；两个接口为 `(-1.2,0.1,0)` 与 `(1.2,0.1,0)`。
若码头根节点在原点且不旋转，将跳板放到 **(2.2,1.1,0)**，保持相同旋转与单位缩放。若码头有变换T，则跳板根位置取 `T * Vector3(2.2,1.1,0)`，旋转沿用T。
426端头两侧矮墩之间净宽1.46m，跳板每侧留0.13m；扶手内侧实际约1.066m。真实导入网格的接缝12条垂直射线均落在Y1.20m。
其他船高需围绕靠岸接口调整跳板变换，并另核坡度；本次只交水平接口验证。具体源文件SHA与接口坐标在生成源目录 `dock_connection.json`。

## 审阅和复现

源与命名部件：`tools/art/source/dock_props_436/`，12个独立 `.blend` 与生成脚本。
审阅：`docs/design/dock-props-436-2026-11-06/` 的件表、360×800默认43°图、validation JSON。
小渡口主体约10.4 ×6m，用426码头、430浪花、432海湾、434城市/山丘/桥远景和428地面；它们只在隔离审阅工程中实例化，不是本套件运行时依赖。
432海湾固定取 #837 `74cbc529`；其余取基线 `206ab822`，所有依赖逐字节核对。海面Y0.20，浪花Y0.218；只保留一层海面，海湾材质在预览实例内设render_priority=-100。
没有交付新游戏场景或layout。桌面RTX2060 / Godot4.7.2 Vulkan Mobile实渲，不能用来代替真机性能结论。
